# Deploying

Static files hosted on Cloudflare Workers at `https://open-textbook.org/`.

## One-time setup

1. **Cloudflare API token** (My Profile → API Tokens → Create Custom Token): `Account → Workers Scripts → Edit` scoped to the account.
2. **Account ID**: Cloudflare Dashboard → Workers & Pages sidebar.
3. **GitHub Actions secrets**: `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`.
4. **Custom domains** (Dashboard → `open-textbook` Worker → Domains & Routes): attach `open-textbook.org` (apex). Done in the dashboard so the API token needs no zone permissions.

## CI pipeline (`verify.yml`)

- **PRs into `dev`:** run `plan`, `generated`, `build`, `content`, `solvers`, `otkd`, `workflows`, and `gate` (`all checks`); `preview` is skipped and the gate announces it. Never tags or deploys.
- **The release PR into `main` and `main` itself:** rerun the full gate including `preview` (all browser/figure/theme/print audits) and, on `main`, the full `otkd-*` checks; `main` then tags, releases and deploys. Deploy downloads the `build` artefact and stamps `BUILD_TAG`/`BUILD_COMMIT` onto root assets without rebuilding.
- **Post-merge delay:** GitHub may take ~2 minutes after a merge before firing the `main` push run. Do **not** manually dispatch `verify.yml` immediately — both share concurrency group `verify-refs/heads/main` (`cancel-in-progress: true`). If no push run appears after a few minutes, dispatch with `gh workflow run verify.yml --ref main`.

### Release tags

`scripts/next-tag.sh` generates `yy.<day-of-year-000>.<increment>` in `Europe/London` (e.g. `26.325.1`), reading existing tags from the GitHub API. Tested in `tests/test_release.py`.

### Protecting `main`

```bash
scripts/protect-main.sh          # require `all checks`, block force-push/deletion
scripts/protect-main.sh --check  # report current state
```

### Local deploy

```bash
cp .env.example .env             # set CLOUDFLARE_ACCOUNT_ID and CLOUDFLARE_API_TOKEN
scripts/deploy.sh                # build, guard, deploy
scripts/deploy.sh --built        # deploy existing site/
scripts/deploy.sh --dry-run      # build and verify without uploading
```

## Rolling back

From GitHub: **Actions → rollback → Run workflow** (inputs: `version_id` optional — blank uses previous version; `confirm` must be `rollback`). Runs in `production` environment with `cancel-in-progress: false`.

From a laptop if GitHub is unavailable:

```bash
npx wrangler versions list
npx wrangler rollback <version-id> -y
```

A rollback changes live hosting only, not `main` — fix forward and push so `version.json` and `main` agree again.

## Headers, caching, and offline

- **`wrangler.jsonc`:** static assets from `site/`; `workers_dev: false`, `preview_urls: false` (single canonical origin).
- **`site/_headers`** (generated by `engine/src/textbook/headers.py`, verified by `tests/test_deploy.py`): sets CSP, `nosniff`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`. Sets **no** `Cache-Control` (Workers defaults to `public, max-age=0, must-revalidate` + `ETag`) and **no** HSTS (set at Cloudflare zone Edge Certificates). Rules allow one splat and duplicate headers concatenate; detach with `! Header` to override.
- **PWA (`assets/sw.js`, `assets/offline/offline.js`):** two caches — persistent `site` cache (navigations network-first, content-addressed assets cache-first, 6-month `MAX_AGE`) and build-versioned `runtime` cache (unhashed assets cache-first, Pagefind network-first, purged on activate). `offline.js` prefetches the open chapter (skipping `saveData`/`2g`) and lets readers download a full book from Settings using `assets/manifest.json`. Checked by `node tools/dist/cli.js offline site`.
- **Budget check:** `node tools/dist/cli.js budget site /gcse-maths/higher/chapter-1/section-1.1/learn/` (target: < 1.7 MB, ≤ 16 requests, document < 350 kB, ≤ 7 render-blocking stylesheets).

## Checking a deploy

```bash
curl -s  https://open-textbook.org/version.json
curl -sI https://open-textbook.org/ | head -20
curl -sI http://open-textbook.org/ | head -3            # 301 -> https
curl -sI https://open-textbook.org/gcse-maths/higher/nope/ | head -3  # 404
curl -s  https://open-textbook.org/robots.txt
curl -s  https://open-textbook.org/sitemap.xml | head
```

## DNS (`www` redirect & CAA)

- `deploy/dns/open-textbook.org.zone` holds proxied `www` (`cf_tags=cf-proxied:true`), SPF/DMARC, and CAA records for Cloudflare's custom-domain CAs (never import apex `A`/`AAAA`/`CNAME`).
- A Cloudflare Redirect Rule 301-redirects `www.open-textbook.org` → `https://open-textbook.org` preserving path and query string.
