# Decisions

Active architectural and product decisions (newest first). Open work lives in `.agents/todo.md`.

| Date | Decision | Rationale / Constraint |
|---|---|---|
| 2026-11-23 | **Matrix (G) replaces the old layout; layouts are pure geometry over one DOM** | `collection.yaml → layouts` lists ids, each with `assets/stylesheets/layouts/<id>.css`; the Layout choice stays hidden until there are two. Font family belongs to the colour bundle, size and measure to the layout. A parsed contract (`tests/test_layout_contract.py`, fixtures per rule) replaces testing every colour x layout pair: a layout that cannot carry a colour cannot break contrast. Sheets are layered, declared once in `themes.css`: `palette, base, shell, layout, book, chrome`; layers invert `!important`, so each was re-checked. |
| 2026-10-28 | **Correlation & regression are given, not hand-computed** | A-level 14.4 tests interpretation of $r$ and the fitted line; banks still compute exact values to verify the given numbers. Derivation lives in `numerical-methods/averaging/regression/`. |
| 2026-10-26 | **Solvers live in `solvers/` under one ABI (`solvers/ABI.md`)** | `ot-solve` (Rust → wasm) and `otkd` (`open_textbook.otkd`) share a fixed `f64` arena, status codes, manifest, and replayed selftests. `scripts/build-solvers.sh` / `scripts/build-otkd.sh` rebuild to compare; CI verifies vendored bytes and deploy installs no compiler. Versions come from git tags (`hatch-vcs`). Simulated numbers are verified by kernel selftests rather than `claim()`. |
| 2026-10-21 | **Single disclaimer source (`engine/src/textbook/legal.py`)** | Surfaced in three places: each book's About page, home page `:::disclaimer` disclosure, and `/terms/` (+ `/acknowledgements/` compiled from `sources.yaml`). Retains statutory carve-outs (`research/legal/disclaimer-and-terms.md`). `pipeline.check_links` skips `portal.root_page_slugs()`. |
| 2026-10-18 | **Books declare their own page structure and depth** | `book.yaml → section_pages` drives scaffold, nav, URLs, and lint with no per-book exemptions. `curriculum.yaml → deeper` + `:::deeper <slug>` handle authored depth pages. `docs/assets/data/` and `images/` copy verbatim. |
| 2026-10-17 | **Figure arithmetic assertions live in data (`claim()`), not parsed prose** | Figures declare `{expression, values, answer, shown}` and `python -m textbook.working` proves them with SymPy exact rationals while keeping prose formatting free. Undeclared figures are reported by `tools readout`. |
| 2026-10-16 | **Figure kit is a 6-layer library; `assets/figures/` is shared** | `assets/figures/kit.js` exports text, frame, draw, controls, interact, drag. Generic tools in `assets/figures/` mount in every book (no book may shadow a slug). `draggable()` throws without a backing keyboard control; `exercise()`/`practice()` claim internal consistency only, not CAS proof. |
| 2026-10-11 | **Use `sympy.stats` + explicit `approx` tolerance; no `scipy`** | Keeps exact rational/symbolic results without a heavy compiled dependency. Revisit only if an independent statistical oracle is required. |
| 2026-10-11 | **Background effects are opt-in and never CSS animations** | CSS animations cannot idle-pause (180 ms/s idle CPU); only explicit render loops (WebGL/canvas) with reduced-motion and idle-pause are allowed. None currently shipped (`tests/test_backgrounds.py`). |
| 2026-10-11 | **All six theme bundles are original (`original: true`)** | `clean`, `editorial`, `harbour`, `neon`, `phosphor`, `glass` are authored in-repo (CC BY 4.0 content / MIT engine) with no third-party palette licences or attribution dependencies. |
