# 15.3 Operations with algebraic fractions — Practise with help

Work each problem before revealing support.

## Warm-up: remember

1. Expand $(x+2)(x+3)$.
2. Factorise $x^2-9$.
3. Solve $2x+5=13$.

<details markdown="1">
<summary>Answers</summary>

1. $x^2+5x+6$. 2. $(x-3)(x+3)$. 3. $x=4$.

</details>

## Practise with help

**1.** Simplify $\frac{1}{x}+\frac{2}{x+2}$.

<details markdown="1">
<summary>Hint</summary>

Use common denominator $x(x+2)$.

</details>

<details markdown="1">
<summary>First step</summary>

$\frac{x+2}{x(x+2)}+\frac{2x}{x(x+2)}$.

</details>

<details markdown="1">
<summary>Full working</summary>

Combine numerators: $\frac{3x+2}{x(x+2)}$, with $x\neq0,-2$.

</details>
