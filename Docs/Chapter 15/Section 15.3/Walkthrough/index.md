# 15.3 Operations with algebraic fractions — Learn

**Prerequisites:** simplify fractions, factorise expressions, and find common denominators.

**Objectives:** add, subtract, multiply, and divide algebraic fractions, then simplify and state restrictions. This section teaches operations with algebraic fractions.

For addition and subtraction, use a common denominator. For multiplication, multiply numerators and denominators. For division, multiply by the reciprocal, which is the fraction turned upside down.

**Example 1.** Simplify $
rac{2}{x}+
rac{3}{x+1}$.

Use common denominator $x(x+1)$.
Rewrite the fractions: $
rac{2(x+1)}{x(x+1)}+
rac{3x}{x(x+1)}$.
Add the numerators: $
rac{2x+2+3x}{x(x+1)}$.
Collect terms: $
rac{5x+2}{x(x+1)}$.
The original denominators require $x
eq0,-1$.

**Example 2.** Simplify $
rac{x}{3}\div
rac{2x}{5}$.

Multiply by the reciprocal: $
rac{x}{3}	imes
rac{5}{2x}$.
Cancel the common factor $x$: $
rac{5}{6}$.
Here $x
eq0$, since the divisor must not be zero.

> **Watch out.** Adding denominators is not a valid fraction method. Use a common denominator and combine only the numerators.
