# 15.2 Simplifying algebraic fractions — Practise with help

Work each problem before revealing support.

## Warm-up: remember

1. Expand $(x+2)(x+3)$.
2. Factorise $x^2-9$.
3. Solve $2x+5=13$.

<details markdown="1">
<summary>Answers</summary>

1. $x^2+5x+6$. 2. $(x-3)(x+3)$. 3. $x=4$.

</details>

## Practise with help

**1.** Simplify $\frac{x^2-4}{x^2+4x+4}$.

<details markdown="1">
<summary>Hint</summary>

Factorise the numerator and denominator before cancelling.

</details>

<details markdown="1">
<summary>First step</summary>

$\frac{(x-2)(x+2)}{(x+2)(x+2)}$.

</details>

<details markdown="1">
<summary>Full working</summary>

Cancel one factor $x+2$: $\frac{x-2}{x+2}$, with $x\neq-2$.

</details>
