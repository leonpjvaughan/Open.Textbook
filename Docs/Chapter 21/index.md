# Chapter 21: Circle geometry and circle theorems

## The chapter problem

A circular window has a chord across it. Two points on the circumference see that chord at angles of $38^\circ$ and $x^\circ$. A radius meets the chord at right angles. Predict a possible value of $x$ and one fact that could help you find it. There is no need to know the answer yet.

## By the end of this chapter you will be able to

- name and use the centre, radius, chord, diameter, circumference, tangent, arc, sector and segment;
- use circle angle theorems to calculate missing angles;
- use tangent and chord properties to calculate lengths and angles;
- construct clear proofs that use circle theorems and known angle facts.

At the marked Progress checks, return to the window problem and use the new facts you have learned.
