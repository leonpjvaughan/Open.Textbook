# 1.1 Place value and ordering numbers — Problems

Independent practice. Keep your working neat: the method matters as much as the
answer. Higher-only items are marked **H**.

1. Write the value of the digit $8$ in $5\,082$.

2. Write the value of the digit $3$ in $0.136$.

3. Work out: (a) $7.4 \times 10$; (b) $7.4 \times 100$; (c) $7.4 \div 100$.

4. Work out $0.06 \times 1000$.

5. Insert $<$, $>$ or $=$.
   (a) $0.45 \Box 0.5$ (b) $-8 \Box -12$ (c) $1.10 \Box 1.1$

6. Write these numbers in order, smallest first:
   $0.505,\ 0.55,\ 0.5,\ 0.0505$.

7. Write these temperatures in order, coldest first:
   $-6\,^\circ\text{C},\ 2\,^\circ\text{C},\ -1\,^\circ\text{C},\ 0\,^\circ\text{C},\ -3\,^\circ\text{C}$.

8. A bank balance is $£42$, then $−£15$, then $−£3$. Put the balances in order,
   smallest first.

9. True or false? Explain each answer.
   (a) $0.7 > 0.65$ (b) $-2 > -1$ (c) $0.30 = 0.3$

10. **H** Write a decimal that is between $0.3$ and $0.31$.

11. **H** The digits $4,\ 0,\ 7$ are used once each to make a number with one
    decimal place. List all the possible numbers and write them in order.

12. In the anchor problem the cans cost 65p and sell for £1.20. Write a sentence
    using $<$ to compare these two amounts, and a sentence using $>$ to compare
    £1.85 with £3.00.

<details markdown="1">
<summary>Answers and concise solutions</summary>

1. $80$.
2. $0.03$ (three hundredths).
3. (a) $74$ (b) $740$ (c) $0.074$.
4. $60$.
5. (a) $<$ (b) $>$ (c) $=$.
6. $0.0505 < 0.5 < 0.505 < 0.55$.
7. $-6 < -3 < -1 < 0 < 2$.
8. $−£15 < −£3 < £42$.
9. (a) True: $0.70 > 0.65$. (b) False: $-2$ is further left than $-1$, so $-2 < -1$.
   (c) True: $0.30 = 0.3$.
10. Any number such as $0.305$ (equivalently, $0.3 < 0.305 < 0.31$).
11. One decimal place means one digit after the point, so the number has two
    digits, then a point, then one digit. The distinct numbers are
    $4.7,\ 7.4,\ 40.7,\ 47.0,\ 70.4,\ 74.0$, so in order
    $4.7 < 7.4 < 40.7 < 47.0 < 70.4 < 74.0$.
12. $65\text{p} < £1.20$; $£1.85 < £3.00$, so equivalently $£3.00 > £1.85$.
</details>
