# 1.1 Place value and ordering numbers — Guided problems

Work each one first. Reveal a hint only if you are stuck, and the full working
only to check.

## Retrieval starter — from memory, no notes

1. Write down the value of the digit $6$ in $4\,362$.
2. Work out $3.4 \times 10$.
3. Which is larger, $0.7$ or $0.68$?

<details markdown="1">
<summary>Answers</summary>

1. $60$ (six tens).
2. $34$.
3. $0.7 = 0.70 > 0.68$.
</details>

## Guided problems

**1.** Write the value of the digit $5$ in each number: (a) $2\,531$; (b) $7.05$;
(c) $0.512$.

<details markdown="1">
<summary>Hint</summary>

Name the column the $5$ sits in: ones, tens, tenths, hundredths?
</details>

<details markdown="1">
<summary>Full working</summary>

(a) hundreds, so $500$. (b) hundredths, so $0.05$. (c) tenths, so $0.5$.
</details>

**2.** Work out: (a) $6.2 \times 100$; (b) $53 \div 10$; (c) $0.4 \times 1000$.

<details markdown="1">
<summary>Hint</summary>

Moving digits: each multiply by 10 shifts one place left; each divide by 10 shifts
one place right.
</details>

<details markdown="1">
<summary>Full working</summary>

(a) $620$. (b) $5.3$. (c) $400$.
</details>

**3.** Insert $<$, $>$ or $=$: (a) $0.6 \Box 0.58$; (b) $-4 \Box -1$;
(c) $2.09 \Box 2.1$.

<details markdown="1">
<summary>Hint</summary>

Write each pair with the same number of decimal places, or picture them on a
number line.
</details>

<details markdown="1">
<summary>Full working</summary>

(a) $0.60 > 0.58$, so $>$. (b) $-4$ is further left, so $-4 < -1$. (c)
$2.09 < 2.10$, so $<$.
</details>

**4.** Write these in order, smallest first: $3.7,\ 0.73,\ 3.07,\ 0.703$.

<details markdown="1">
<summary>Hint</summary>

Pad to three decimal places: $3.700,\ 0.730,\ 3.070,\ 0.703$.
</details>

<details markdown="1">
<summary>Full working</summary>

$0.703 < 0.730 < 3.070 < 3.700$, so $0.703,\ 0.73,\ 3.07,\ 3.7$.
</details>

**5.** The temperature at 6 am was $-3\,^\circ\text{C}$ and by noon it was
$4\,^\circ\text{C}$. Which temperature is lower? By how many degrees did it rise?

<details markdown="1">
<summary>Hint</summary>

Sketch a number line from $-5$ to $5$. The rise is the gap between the two marks.
</details>

<details markdown="1">
<summary>Full working</summary>

$-3\,^\circ\text{C}$ is lower. The rise is $4 - (-3) = 7\,^\circ\text{C}$.
</details>

**6.** A shop lists four prices: $£0.85$, $£0.79$, $£0.9$ and $£0.809$. Put them
in order and say which is the cheapest.

<details markdown="1">
<summary>Hint</summary>

Pad to three decimal places and compare.
</details>

<details markdown="1">
<summary>Full working</summary>

$£0.790 < £0.809 < £0.850 < £0.900$, so the cheapest is $£0.79$.
</details>
