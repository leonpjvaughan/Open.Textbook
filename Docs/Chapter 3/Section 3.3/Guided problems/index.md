# 3.3 Laws of indices — Practise with help

## Warm-up: remember

1. Work out $3^2$.
2. Work out $36\div6$, then check by multiplying.

<details markdown="1">
<summary>Answers and feedback</summary>

1. $9$, because $3\times3=9$.
2. $6$, because $6\times6=36$. The check is $6\times6=36$.

</details>

## Practise with help

**1.** Start with $2^4$. Find its value.

<details markdown="1">
<summary>Hint</summary>

Write four factors of 2.

<details markdown="1">
<summary>One step</summary>

$2^4=2\times2\times2\times2$.

<details markdown="1">
<summary>Full working</summary>

$2^4=2\times2\times2\times2=16$.

</details>
</details>
</details>

**2.** Find $\sqrt{81}$.

<details markdown="1">
<summary>Hint</summary>

Which positive whole number squares to 81?

<details markdown="1">
<summary>One step</summary>

$9^2=81$.

<details markdown="1">
<summary>Full working</summary>

$\sqrt{81}=9$, since $9^2=81$.

</details>
</details>
</details>

**3.** Simplify $x^2x^5$.

<details markdown="1">
<summary>Hint</summary>

Write out the factors, then count them.

<details markdown="1">
<summary>One step</summary>

$x^2x^5=x^{2+5}$.

<details markdown="1">
<summary>Full working</summary>

$x^2x^5=x^7$ because the product joins seven factors of $x$.

</details>
</details>
</details>
