# 9.1 Solving linear equations — Practise with help

## Warm-up: remember

1. Solve $2x=18$.
2. Work out $3(4+2)$.

<details markdown="1">
<summary>Check your answers</summary>

1. $x=9$. 2. $18$.
</details>

## Practise with help

**1.** Solve $x+6=14$.

<details markdown="1">
<summary>Hint</summary>

Undo the addition.
</details>

<details markdown="1">
<summary>Next step</summary>

Try the first operation or write the equation before opening the full solution.
</details>

<details markdown="1">
<summary>Full working</summary>

Subtract $6$: $x=8$. Check: $8+6=14$.
</details>

**2.** Solve $4x=28$.

<details markdown="1">
<summary>Hint</summary>

Undo multiplication by $4$.
</details>

<details markdown="1">
<summary>Next step</summary>

Try the first operation or write the equation before opening the full solution.
</details>

<details markdown="1">
<summary>Full working</summary>

Divide by $4$: $x=7$. Check: $4(7)=28$.
</details>

**3.** Solve $2x+3=15$.

<details markdown="1">
<summary>Hint</summary>

Undo addition before multiplication.
</details>

<details markdown="1">
<summary>Next step</summary>

Try the first operation or write the equation before opening the full solution.
</details>

<details markdown="1">
<summary>Full working</summary>

Subtract $3$: $2x=12$. Divide by $2$: $x=6$.
</details>

**4.** Solve $3(x+2)=21$.

<details markdown="1">
<summary>Hint</summary>

Remove the outside factor first.
</details>

<details markdown="1">
<summary>Next step</summary>

Try the first operation or write the equation before opening the full solution.
</details>

<details markdown="1">
<summary>Full working</summary>

Divide by $3$: $x+2=7$. Subtract $2$: $x=5$.
</details>

**5.** Solve $x/4-1=3$.

<details markdown="1">
<summary>Hint</summary>

Add $1$, then undo division by $4$.
</details>

<details markdown="1">
<summary>Next step</summary>

Try the first operation or write the equation before opening the full solution.
</details>

<details markdown="1">
<summary>Full working</summary>

Add $1$: $x/4=4$. Multiply by $4$: $x=16$.
</details>
