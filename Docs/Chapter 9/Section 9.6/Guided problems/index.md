# 9.6 Quadratic inequalities — Practise with help

## Warm-up: remember

1. Solve $2x=18$.
2. Work out $3(4+2)$.

<details markdown="1">
<summary>Check your answers</summary>

1. $x=9$. 2. $18$.
</details>

## Practise with help

**1.** Solve $x+4=0$.

<details markdown="1">
<summary>Hint</summary>

Use the inverse operation.
</details>

<details markdown="1">
<summary>Next step</summary>

Try the first operation or write the equation before opening the full solution.
</details>

<details markdown="1">
<summary>Full working</summary>

$x=-4$.
</details>

**2.** Solve $(x-1)(x-4)=0$.

<details markdown="1">
<summary>Hint</summary>

A product is zero when either factor is zero.
</details>

<details markdown="1">
<summary>Next step</summary>

Try the first operation or write the equation before opening the full solution.
</details>

<details markdown="1">
<summary>Full working</summary>

$x=1$ or $x=4$.
</details>

**3.** For $(x-2)(x+2)>0$, test $x=0$.

<details markdown="1">
<summary>Hint</summary>

Substitute 0 into both factors.
</details>

<details markdown="1">
<summary>Next step</summary>

Try the first operation or write the equation before opening the full solution.
</details>

<details markdown="1">
<summary>Full working</summary>

$(-2)(2)<0$, so the middle interval is not a solution.
</details>

**4.** Solve $(x-2)(x+2)>0$.

<details markdown="1">
<summary>Hint</summary>

Use roots $-2,2$ and test the middle and outer intervals.
</details>

<details markdown="1">
<summary>Next step</summary>

Try the first operation or write the equation before opening the full solution.
</details>

<details markdown="1">
<summary>Full working</summary>

The expression is positive outside: $x<-2$ or $x>2$.
</details>

**5.** Solve $x^2-4x+3\leq0$.

<details markdown="1">
<summary>Hint</summary>

Factorise and include roots because equality is allowed.
</details>

<details markdown="1">
<summary>Next step</summary>

Try the first operation or write the equation before opening the full solution.
</details>

<details markdown="1">
<summary>Full working</summary>

$(x-1)(x-3)\leq0$, so $1\leq x\leq3$.
</details>
