# 5.3 Direct proportion — Learn

## Before you start

You should be able to multiply and divide whole numbers and fractions. Check units before comparing quantities.

## Key terms

**Direct proportion** means one quantity is a fixed multiple of another. The **constant of proportionality** is written $k$.

## What you will learn

- Find equations and values in direct proportion, including square and cube relationships.
- Check that the result matches the units and direction of change.

## Learn the method

In direct proportion, one quantity is a fixed multiple of another: $y=kx$. For $y\propto x^2$, write $y=kx^2$. Substitute known values to find $k$, then find the new value.

**Worked example. $y$ is proportional to $x^2$. When $x=3$, $y=45$. Find $y$ when $x=5$.**

- Write the model: $y=kx^2$.
- Substitute the known pair: $45=9k$.
- Divide by 9: $k=5$.
- Substitute $x=5$: $y=5\times25=125$.
- Check: $45\times(25/9)=125$.

**Progress check:** apply this multiplier idea to the garden path scale.

> **Watch out.** For $y\propto x^2$, doubling $x$ multiplies $y$ by 4, not 2. Square the scale factor, then check with the original and new values.

## You should now be able to

- I can find $k$ in $y=kx$, $y=kx^2$ or $y=kx^3$.
- I can use the model to find a missing value.
- I can check the scaling factor and the answer.
