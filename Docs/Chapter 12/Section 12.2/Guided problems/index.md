# 12.2 Factorising harder quadratics — Practise with help

Start closed-book. Check each answer after you have tried it.

## Warm-up: remember

1. Expand $(x+2)(x+3)$.
2. Factorise $x^2+5x+6$.

<details markdown="1">
<summary>Answers</summary>

1. $x^2+5x+6$.
2. $(x+2)(x+3)$.
</details>

## Practise with help

**1.** Factorise $2x^2+7x+3$.

<details markdown="1">
<summary>Hint</summary>

Find a pair with product $6$ and sum $7$.
</details>

<details markdown="1">
<summary>Next step</summary>

Set out the expression or equation using the hint, then continue without opening the next part.
</details>

<details markdown="1">
<summary>Full working</summary>

Use $6$ and $1$: $2x^2+6x+x+3=2x(x+3)+1(x+3)=(2x+1)(x+3)$.
</details>

**Choose a method:** factorise $x^2+7x+10$. Which method applies, and why?

<details markdown="1">
<summary>Full working</summary>

Factorisation applies because the expression is a monic quadratic with integer factors: $x^2+7x+10=(x+5)(x+2)$.
</details>
