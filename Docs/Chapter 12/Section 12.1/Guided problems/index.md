# 12.1 Expanding and factorising quadratics — Practise with help

Start closed-book. Check each answer after you have tried it.

## Warm-up: remember

1. Expand $(x+2)(x+3)$.
2. Factorise $x^2+5x+6$.

<details markdown="1">
<summary>Answers</summary>

1. $x^2+5x+6$.
2. $(x+2)(x+3)$.
</details>

## Practise with help

**1.** Expand $(x+2)(x+6)$.

<details markdown="1">
<summary>Hint</summary>

Multiply each term in the first bracket by both terms in the second.
</details>

<details markdown="1">
<summary>Next step</summary>

Set out the expression or equation using the hint, then continue without opening the next part.
</details>

<details markdown="1">
<summary>Full working</summary>

$(x+2)(x+6)=x^2+6x+2x+12=x^2+8x+12$.
</details>

**2.** Factorise $x^2+9x+20$.

<details markdown="1">
<summary>Hint</summary>

Find a pair with sum $9$ and product $20$.
</details>

<details markdown="1">
<summary>Next step</summary>

Set out the expression or equation using the hint, then continue without opening the next part.
</details>

<details markdown="1">
<summary>Full working</summary>

The pair is $4,5$, so $x^2+9x+20=(x+4)(x+5)$.
</details>

**Choose a method:** factorise $x^2+7x+10$. Which method applies, and why?

<details markdown="1">
<summary>Full working</summary>

Factorisation applies because the expression is a monic quadratic with integer factors: $x^2+7x+10=(x+5)(x+2)$.
</details>
