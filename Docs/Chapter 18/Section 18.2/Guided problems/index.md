# 18.2 Enlargement — Practise with help

Attempt these from memory before opening the answers. Then try each question before opening a hint.

## Warm-up: remember

1. Work out $-3+8$.
2. Translate $(1,2)$ by $\begin{pmatrix}2\\-1\end{pmatrix}$.

<details markdown="1">
<summary>Answers and feedback</summary>

1. $5$. Starting at $-3$ and moving $8$ places right gives $5$.
2. $(3,1)$. Add $2$ to the horizontal coordinate and subtract $1$ from the vertical coordinate.
</details>

## Practise with help

**1.** Enlarge $(3,2)$ by scale factor $2$ about the origin.

<details markdown="1"><summary>Hint</summary>Multiply both coordinates by the scale factor.</details>
<details markdown="1"><summary>Next step</summary>$x'=3\times2=6$ and $y'=2\times2=4$.</details>
<details markdown="1"><summary>Full working</summary>The image is $(6,4)$.</details>

**2.** A length of $5$ cm becomes $15$ cm. Find the scale factor.

<details markdown="1"><summary>Hint</summary>Divide image length by original length.</details>
<details markdown="1"><summary>Next step</summary>$15\div5=3$.</details>
<details markdown="1"><summary>Full working</summary>The scale factor is $3$.</details>

**3.** Earlier topic: solve $3x=18$.

<details markdown="1"><summary>Hint</summary>Use the inverse operation.</details>
<details markdown="1"><summary>Next step</summary>Divide both sides by $3$.</details>
<details markdown="1"><summary>Full working</summary>$x=6$.</details>
