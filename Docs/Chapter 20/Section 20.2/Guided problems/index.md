# 20.2 Trigonometric ratios (SOHCAHTOA) — Practise with help

Try each problem first. Open a hint if you need it, then use the working to check your method.

## Warm-up: remember

1. Work out $3^2+4^2$.
2. State the sum of the angles in a triangle.

<details markdown="1"><summary>Answers</summary>

1. $25$. 2. $180^\circ$.
</details>

## Practise with help

**1.** Find the opposite side for hypotenuse 12 and angle 30°.

<details markdown="1"><summary>Hint</summary>

Use sine: opposite over hypotenuse.
</details>

<details markdown="1"><summary>Full working</summary>

sin 30° = x/12, so x = 6.
</details>

**2.** Find the adjacent side for hypotenuse 10 and angle 60°.

<details markdown="1"><summary>Hint</summary>

Use cosine.
</details>

<details markdown="1"><summary>Full working</summary>

cos 60° = x/10, so x = 5.
</details>

**3.** Opposite is 8 and adjacent is 15. Find the angle.

<details markdown="1"><summary>Hint</summary>

Use tangent, then inverse tangent.
</details>

<details markdown="1"><summary>Full working</summary>

tan θ = 8/15, so θ ≈ 28.1°.
</details>
