# 20.4 Exact trigonometric values — Practise with help

Try each problem first. Open a hint if you need it, then use the working to check your method.

## Warm-up: remember

1. Work out $3^2+4^2$.
2. State the sum of the angles in a triangle.

<details markdown="1"><summary>Answers</summary>

1. $25$. 2. $180^\circ$.
</details>

## Practise with help

**1.** Give sin 30° exactly.

<details markdown="1"><summary>Hint</summary>

Use the special-value table.
</details>

<details markdown="1"><summary>Full working</summary>

sin 30° = 1/2.
</details>

**2.** Work out cos 45° exactly.

<details markdown="1"><summary>Hint</summary>

The 45° triangle has equal legs.
</details>

<details markdown="1"><summary>Full working</summary>

cos 45° = √2/2.
</details>

**3.** Work out sin 60° × cos 30° exactly.

<details markdown="1"><summary>Hint</summary>

Both values are √3/2.
</details>

<details markdown="1"><summary>Full working</summary>

(√3/2)(√3/2) = 3/4.
</details>

Before opening each full working, name the method and explain which measurements led you to choose it.
