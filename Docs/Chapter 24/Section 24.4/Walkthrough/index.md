# 24.4 Averages from frequency tables — Learn

**Prerequisites:** multiplication, division and the mean of a list.

**Objectives:** calculate the mean, median, mode and range from a frequency table where the data values are given. This section covers S4.

A frequency table records each value and how many times it occurs. To find the mean, multiply each value by its frequency, add those products, then divide by the total frequency.

**Example.** The values 1, 2 and 3 have frequencies 2, 3 and 1. Find the mean and median.

Multiply values by frequencies: $1	imes2=2$, $2	imes3=6$, $3	imes1=3$.

Add products: $2+6+3=11$.

Add frequencies: $2+3+1=6$.

Mean $=11/6$.

The six ordered values are $1,1,2,2,2,3$.

The middle pair is 2 and 2, so median $=2$.

Mode $=2$ because its frequency is greatest. Range $=3-1=2$.

> **Watch out.** Do not divide the weighted total by the number of rows. Divide by the total frequency.
