# 4.5 Recurring decimals — Practise with help

## Warm-up: remember

Answer from memory before checking.

1. From Section 4.4, write $0.125$ as a fraction in simplest form.
2. From Section 4.4, write $\frac{3}{8}$ as a decimal.

<details markdown="1">
<summary>Answers</summary>

1. $\frac{1}{8}$.
2. $0.375$.
</details>

## Practise with help

Try each question first. Reveal the hint, next step and full working in that order.

**1.** Convert $0.\dot{3}$ to a fraction.

<details markdown="1">
<summary>Hint</summary>

Let $x=0.333\ldots$ and multiply by $10$.

<details markdown="1">
<summary>Next step</summary>

Set up the calculation using that idea.

<details markdown="1">
<summary>Full working</summary>

Then $10x=3.333\ldots$. Subtract to get $9x=3$, so $x=\frac{1}{3}$.
</details>
</details>
</details>

**2.** Convert $0.\dot{2}\dot{7}$ to a fraction.

<details markdown="1">
<summary>Hint</summary>

Multiply by $100$ because the block has two digits.

<details markdown="1">
<summary>Next step</summary>

Write the calculation before simplifying.

<details markdown="1">
<summary>Full working</summary>

If $x=0.272727\ldots$, then $100x-x=27$, so $99x=27$ and $x=\frac{3}{11}$.
</details>
</details>
</details>

**3. Progress check.** Convert $0.\dot{6}$ to a fraction, then use it to find $0.\dot{6}$ of £48.

<details markdown="1">
<summary>Hint</summary>

First convert the recurring decimal to a fraction.

<details markdown="1">
<summary>Next step</summary>

Then multiply £48 by that fraction.

<details markdown="1">
<summary>Full working</summary>

$0.\dot{6}=\frac23$, so $\frac23\times£48=£32$.
</details>
</details>
</details>
