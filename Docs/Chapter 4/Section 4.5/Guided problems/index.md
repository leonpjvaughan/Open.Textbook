# 4.5 Recurring decimals — Practise with help

## Warm-up: remember

Work without looking back. Then open the answers to check.

1. Write $0.4$ as a fraction with denominator $10$.
2. Work out $3\times8$.

<details markdown="1">
<summary>Answers</summary>

1. $\frac{4}{10}$.
2. $24$.
</details>

## Practise with help

Try each question first. Reveal the hint, next step and full working in that order.

**1.** Convert $0.\dot{3}$ to a fraction.

<details markdown="1">
<summary>Hint</summary>

Let $x=0.333\ldots$ and multiply by $10$.

<details markdown="1">
<summary>Next step</summary>

Set up the calculation using that idea.

<details markdown="1">
<summary>Full working</summary>

Then $10x=3.333\ldots$. Subtract to get $9x=3$, so $x=\frac{1}{3}$.
</details>
</details>
</details>

**2.** Convert $0.\dot{2}\dot{7}$ to a fraction.

<details markdown="1">
<summary>Hint</summary>

Multiply by $100$ because the block has two digits.

<details markdown="1">
<summary>Next step</summary>

Write the calculation before simplifying.

<details markdown="1">
<summary>Full working</summary>

If $x=0.272727\ldots$, then $100x-x=27$, so $99x=27$ and $x=\frac{3}{11}$.
</details>
</details>
</details>

**3. Progress check.** Return to the keyboard prices. What fraction of £48 is the discount?

<details markdown="1">
<summary>Hint</summary>

Multiply the price by the discount fraction.

<details markdown="1">
<summary>Next step</summary>

Find one quarter of £48, then compare with £37.50.

<details markdown="1">
<summary>Full working</summary>

£48 divided by $4$ is £12. The discounted price is £48-£12=£36, which is £1.50 below £37.50.
</details>
</details>
</details>
