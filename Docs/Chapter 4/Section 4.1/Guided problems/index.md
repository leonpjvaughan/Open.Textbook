# 4.1 Equivalent fractions and ordering — Practise with help

## Warm-up: remember

Work without looking back. Then open the answers to check.

1. Write $0.4$ as a fraction with denominator $10$.
2. Work out $3\times8$.

<details markdown="1">
<summary>Answers</summary>

1. $\frac{4}{10}$.
2. $24$.
</details>

## Practise with help

Try each question first. Reveal the hint, next step and full working in that order.

**1.** Which fraction is equal to $\frac{2}{5}$ with denominator $20$?

<details markdown="1">
<summary>Hint</summary>

Multiply denominator $5$ by $4$.

<details markdown="1">
<summary>Next step</summary>

Set up the calculation using that idea.

<details markdown="1">
<summary>Full working</summary>

Multiply numerator and denominator by $4$: $\frac{2}{5}=\frac{8}{20}$.
</details>
</details>
</details>

**2.** Compare $\frac{3}{4}$ and $0.7$.

<details markdown="1">
<summary>Hint</summary>

Write $\frac{3}{4}=0.75$.

<details markdown="1">
<summary>Next step</summary>

Write the calculation before simplifying.

<details markdown="1">
<summary>Full working</summary>

Since $0.75>0.7$, the fraction is larger.
</details>
</details>
</details>

**3. Progress check.** Return to the keyboard prices. What fraction of £48 is the discount?

<details markdown="1">
<summary>Hint</summary>

Multiply the price by the discount fraction.

<details markdown="1">
<summary>Next step</summary>

Find one quarter of £48, then compare with £37.50.

<details markdown="1">
<summary>Full working</summary>

£48 divided by $4$ is £12. The discounted price is £48-£12=£36, which is £1.50 below £37.50.
</details>
</details>
</details>
