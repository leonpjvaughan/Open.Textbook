# 14.5 Iteration and numerical methods — Practise with help

Work each question first. Open a hint if you need one, then reveal the working to check your method.

## Warm-up: remember

1. Solve $2x+3=11$.
2. If $y=3x-2$, find $y$ when $x=4$.

<details markdown="1">
<summary>Answers</summary>

1. $x=4$. 2. $y=10$.
</details>

## Practise with help

**1.** Solve $x+y=9$ and $x-y=3$.

<details markdown="1"><summary>Hint</summary>
Add the equations to remove $y$.
</details>
<details markdown="1"><summary>Full working</summary>
$2x=12$, so $x=6$. Then $y=3$. Check both equations.
</details>

**2.** Solve $y=2x+1$ and $x+y=10$.

<details markdown="1"><summary>Hint</summary>
Replace $y$ in the second equation.
</details>
<details markdown="1"><summary>Full working</summary>
$x+2x+1=10$, so $x=3$ and $y=7$.
</details>

**3.** Use $x_{n+1}=
rac12(x_n+6/x_n)$ from $x_0=2$ to find $x_2$.

<details markdown="1"><summary>Hint</summary>
Find $x_1$ first. Use that value in the rule again.
</details>
<details markdown="1"><summary>Full working</summary>
$x_1=2.5$, then $x_2=2.45$.
</details>
