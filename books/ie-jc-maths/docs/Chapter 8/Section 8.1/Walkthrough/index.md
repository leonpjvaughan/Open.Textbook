# 8.1 Sets and set notation — Learn

**Prerequisites:** counting whole numbers, and listing the multiples of a number.

**Objectives:** say what makes a collection a set; write a set in roster form;
decide whether an object is an element of a set; count the elements of a set.

By the end of this section, you can write a set down, name its elements,
and say how many elements it has.

## What a set is

A **set** is a well-defined collection of things. "Well-defined" means there is a
clear rule that decides whether any particular thing belongs. The things in a set
are its **elements**, and they can be numbers, letters, people or clubs.

Here is a set of numbers.

$$A = \{2, 4, 6, 8\}$$

The curly brackets $\{\ \}$ hold the elements. A capital letter names the set, so
the set above is called $A$. The elements of $A$ are 2, 4, 6 and 8.

You write $x \in A$ to say that $x$ is an element of $A$. You write $x \notin A$
to say that $x$ is not an element of $A$.

$$4 \in A \qquad 5 \notin A$$

The symbol $\in$ means "is in". The symbol $\notin$ means "is not in".

**Example 1.** Write the set of odd numbers from 1 to 9 in roster form.

List the elements inside the brackets, separated by commas.

$$B = \{1, 3, 5, 7, 9\}$$

**Roster form** means writing every element in a list like this.

**Example 2.** Is 7 an element of $B = \{1, 3, 5, 7, 9\}$? Is 8?

Look at the list. The number 7 is in it, so $7 \in B$. The number 8 is not in it,
so $8 \notin B$.

## Order and repetition

The order of the elements does not matter, and a repeated element does not make the
set bigger.

$$\{2, 4, 6, 8\} = \{8, 6, 4, 2\} = \{2, 2, 4, 6, 8\}$$

All three describe the same set, because each contains exactly the same four
numbers. A set is decided by which elements it has, not by how you write them.

**Example 3.** Are $\{1, 2, 3\}$ and $\{3, 1, 2\}$ equal?

Yes. Both contain 1, 2 and 3, and nothing else. The order is different, so the two
lists look different, but the sets are equal.

## The cardinality of a set

The **cardinality** of a set is the number of elements it has. You write $n(A)$ or
$|A|$, and both mean the same thing.

$$n(\{2, 4, 6, 8\}) = 4$$

$$n(\{1, 3, 5, 7, 9\}) = 5$$

Count each element once, even if it is written twice in the list.

**Example 4.** Find $n(\{a, b, c, d, e, f\})$.

Count the letters: $a$, $b$, $c$, $d$, $e$, $f$. There are six.

$$n(\{a, b, c, d, e, f\}) = 6$$

## Sets in words

A set is often described in words, and you write the elements yourself. The
description must be clear enough that two people would write the same list.

**Example 5.** Write the set of even numbers between 1 and 10.

The even numbers are the multiples of 2.

$$C = \{2, 4, 6, 8, 10\}$$

The words "between 1 and 10" exclude 1 and 10 as endpoints, but 10 is even and 1 is
not. The set of even numbers from 1 up to 10 is the same list.

> **Watch out.** An element and a set are different kinds of thing. The number 4
> is an element of $A = \{2, 4, 6, 8\}$, but the set $\{4\}$ is not. Writing
> $4 \in A$ is correct; writing $\{4\} \in A$ is not, because $A$ does not contain
> the set $\{4\}$.
>
> **Re-check:** ask what is inside the brackets. $A$ contains the number 4. It does
> not contain a bracket holding the number 4.

## Progress check

Return to the chapter problem. The year group signs up for Chess, Drama and
Science.

1. Write the set $C$ of students who joined Chess, using the cardinality from the
   sign-up sheet.
2. State $n(C)$, $n(D)$ and $n(S)$.
3. A student in the year group is picked at random. Write one sentence to say what
   the number 15 describes in this problem, and why 15 is not an element of $C$.

In Section 8.2 you will compare these sets with the whole year group.

## You should now be able to

- say what makes a collection a set, and write one in roster form;
- use the symbols $\in$ and $\notin$ correctly;
- tell an element from a set, so you do not confuse 4 with $\{4\}$;
- find the cardinality of a set, counting a repeated element once;
- write the elements of a set from a clear description in words.
