# 8.1 Sets and set notation — Practise with help

## Warm-up: remember

1. Write down the first four multiples of 3.
2. Work out $4^2$ and $2^4$.

<details markdown="1">
<summary>Answers and feedback</summary>

1. $3, 6, 9, 12$. A multiple of 3 is 3 times a whole number.
2. $4^2 = 16$ and $2^4 = 16$. The index tells you how many factors to multiply:
   $4 \times 4$ for the first, and $2 \times 2 \times 2 \times 2$ for the second.

Both skills appear in this section. Multiples give you the elements of a set, and
powers help you describe a set of square numbers.

</details>

:::figure warm-up-gate


## Practise with help

**1.** Write the set of even numbers from 2 to 10 in roster form.

<details markdown="1">
<summary>Hint</summary>

An even number is a multiple of 2. Start at 2 and count up in twos.

<details markdown="1">
<summary>Next step</summary>

$2, 4, 6, 8, 10$.

<details markdown="1">
<summary>Full working</summary>

$$\{2, 4, 6, 8, 10\}$$

The curly brackets hold the list. Every number in the list is a multiple of 2, and
no number between 2 and 10 is left out.

</details>
</details>
</details>

**2.** Is 6 an element of $A = \{2, 4, 6, 8\}$? Is 5?

<details markdown="1">
<summary>Hint</summary>

Look at the list inside the brackets. Is the number written there?

<details markdown="1">
<summary>Next step</summary>

The number 6 is in the list, and the number 5 is not.

<details markdown="1">
<summary>Full working</summary>

$6 \in A$ and $5 \notin A$.

The symbol $\in$ means "is in" and $\notin$ means "is not in". The set $A$ holds
four elements: 2, 4, 6 and 8.

</details>
</details>
</details>

**3.** Write the set of multiples of 5 that are less than 30.

<details markdown="1">
<summary>Hint</summary>

Start at 5 and add 5 each time. Stop before you reach 30.

<details markdown="1">
<summary>Next step</summary>

$5, 10, 15, 20, 25$.

<details markdown="1">
<summary>Full working</summary>

$$\{5, 10, 15, 20, 25\}$$

The next multiple is 30, and 30 is not less than 30, so the list stops at 25.

</details>
</details>
</details>

**4.** Find $n(\{3, 6, 9, 12, 15\})$.

<details markdown="1">
<summary>Hint</summary>

$n(A)$ asks how many elements the set has. Count them.

<details markdown="1">
<summary>Next step</summary>

There are five numbers in the brackets.

<details markdown="1">
<summary>Full working</summary>

$$n(\{3, 6, 9, 12, 15\}) = 5$$

The set has five elements. The numbers happen to be multiples of 3, but that does
not change the count.

</details>
</details>
</details>

**5.** Are $\{1, 2, 3\}$ and $\{3, 2, 1\}$ equal? Give a reason.

<details markdown="1">
<summary>Hint</summary>

A set is decided by which elements it has, not by the order you write them.

<details markdown="1">
<summary>Next step</summary>

Both sets contain 1, 2 and 3, and nothing else.

<details markdown="1">
<summary>Full working</summary>

Yes, the sets are equal.

Both contain exactly the elements 1, 2 and 3. The order is different, so the two
lists look different, but the same three numbers are in each.

</details>
</details>
</details>

**6.** Write the set of letters in the word "sets" in roster form.

<details markdown="1">
<summary>Hint</summary>

The word has two letter s. A set counts each element once.

<details markdown="1">
<summary>Next step</summary>

The letters are s, e, t and s.

<details markdown="1">
<summary>Full working</summary>

$$\{s, e, t\}$$

The letter s appears twice in the word, but a set holds each element once. The
cardinality is 3, not 4.

</details>
</details>
</details>

**7.** The set $P = \{2, 3, 5, 7, 11\}$ holds the prime numbers less than 12. Write
$n(P)$, and say whether $9 \in P$.

<details markdown="1">
<summary>Hint</summary>

Count the elements for the first part. For the second part, look for 9 in the list.

<details markdown="1">
<summary>Next step</summary>

There are five elements, and 9 is not among them.

<details markdown="1">
<summary>Full working</summary>

$n(P) = 5$ and $9 \notin P$.

The number 9 is not prime, because $9 = 3 \times 3$. So 9 does not belong to a set
of prime numbers.

</details>
</details>
</details>

**8.** Write the set of square numbers from 1 to 25.

<details markdown="1">
<summary>Hint</summary>

A square number is a whole number times itself. Start at $1 \times 1$.

<details markdown="1">
<summary>Next step</summary>

$1, 4, 9, 16, 25$.

<details markdown="1">
<summary>Full working</summary>

$$\{1, 4, 9, 16, 25\}$$

These are $1^2$, $2^2$, $3^2$, $4^2$ and $5^2$. The next square is $6^2 = 36$,
which is past 25.

</details>
</details>
</details>

## A question from an earlier section

**9.** Find the highest common factor of 12 and 18.

<details markdown="1">
<summary>Hint</summary>

List the factors of each number, and look for the largest number in both lists.
Section 3.3 has the method.

<details markdown="1">
<summary>Next step</summary>

Factors of 12: $1, 2, 3, 4, 6, 12$. Factors of 18: $1, 2, 3, 6, 9, 18$.

<details markdown="1">
<summary>Full working</summary>

The common factors are $1, 2, 3$ and $6$, so the highest common factor is 6.

The set of common factors is $\{1, 2, 3, 6\}$, and its largest element is 6. Sets
give a neat way to say "the factors that both numbers share".

</details>
</details>
</details>
