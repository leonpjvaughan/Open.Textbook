# Glossary — Number

**Absolute change** — the actual increase or decrease in a quantity, found by
subtracting one value from another.

**Associative property** — the rule that the way you group numbers in addition
or multiplication does not change the answer.

**Base** — the number that is raised to a power, such as the $2$ in $2^3$.

**BIDMAS** — the order of operations: brackets, indices, division and
multiplication, addition and subtraction.

**Cardinality** — the number of elements in a set.

**Commission** — a payment worked out as a percentage of a sale.

**Commutative property** — the rule that the order of two numbers in addition or
multiplication does not change the answer.

**Complement** — the set of elements in the universal set that are not in a
given set.

**Composite number** — a whole number greater than 1 that has more than two
factors.

**Compound interest** — interest worked out each time on the original amount and
on the interest already added.

**Cost price** — the amount paid for an item before any mark-up.

**Cube number** — a number formed by multiplying a whole number by itself twice,
such as $27=3^3$.

**Decimal place** — a position after the decimal point; the first is tenths, the
second hundredths.

**Denominator** — the bottom number of a fraction, which says how many equal
parts the whole is split into.

**Difference** — the result of subtracting one number from another.

**Direct proportion** — a relationship where one quantity is a fixed multiple of
the other.

**Distributive property** — the rule that lets you multiply a sum by multiplying
each part and adding the results.

**Element** — one member of a set.

**Equivalent fraction** — a fraction with the same value as another, made by
multiplying or dividing the top and bottom by the same number.

**Equivalent ratio** — a ratio with the same comparison as another, made by
multiplying or dividing both parts by the same number.

**Estimate** — a quick, approximate answer found by rounding.

**Exchange rate** — the number that converts an amount in one currency to
another.

**Factor** — a whole number that divides another exactly.

**Fraction** — a way to write a part of a whole, as one number over another.

**Gross pay** — the total pay before any deductions.

**Highest common factor** — the largest number that divides two or more numbers
exactly.

**Income tax** — tax taken from pay by the government.

**Index (plural indices)** — a power, such as the $3$ in $2^3=8$.

**Integer** — a whole number, positive, negative or zero.

**Intersection** — the set of elements that belong to both of two sets.

**Inverse proportion** — a relationship where one quantity increases as the
other decreases, so their product stays constant.

**Irrational number** — a number that cannot be written as a fraction of two
integers.

**Loss** — a negative profit: the money taken is less than the money spent.

**Lowest common multiple** — the smallest number that is a multiple of two or
more numbers.

**Margin** — profit written as a percentage of the selling price.

**Mark-up** — the amount added to the cost price to set the selling price.

**Multiple** — the result of multiplying a number by a whole number.

**Natural numbers** — the counting numbers, starting at 1.

**Net pay** — the pay left after tax and other deductions.

**Null set** — a set with no elements.

**Numerator** — the top number of a fraction, which says how many parts are
taken.

**Per cent** — a fraction out of 100.

**Percentage** — a number written as a part of 100.

**Power** — a way of writing repeated multiplication, such as $2^3$.

**Prime number** — a whole number greater than 1 whose only factors are 1 and
itself.

**Principal** — the original amount of money borrowed or invested.

**Profit** — money left after costs are subtracted from the money taken.

**Proper subset** — a subset that does not contain every element of the larger
set.

**PRSI** — Pay-Related Social Insurance, a social insurance contribution taken
from pay in Ireland.

**Rate** — a comparison of two quantities measured in different units.

**Ratio** — a way to compare amounts by showing how many parts of each there
are.

**Rational number** — a number that can be written as a fraction of two
integers, with the bottom number not zero.

**Reciprocal** — the result of dividing 1 by a number; the reciprocal of 4 is
$\frac{1}{4}$.

**Relative change** — the change written as a fraction or a percentage of the
original value.

**Roster form** — a way to write a set by listing its elements inside braces.

**Rounding** — replacing a number by a nearby number with fewer significant
figures or decimal places.

**Selling price** — the amount a customer pays for an item.

**Set** — a well-defined collection of objects.

**Significant figures** — the digits that carry meaning in a number, counted
from the first non-zero digit.

**Simple interest** — interest calculated each time on the original amount only.

**Simplest form** — a fraction written with the smallest possible whole numbers
on the top and bottom.

**Speed** — the rate at which distance is covered.

**Square number** — a number formed by multiplying a whole number by itself,
such as $16=4^2$.

**Standard form** — a way to write a number as $a\times10^n$, where $1\leq a<10$
and $n$ is an integer.

**Subset** — a set whose elements all belong to another set.

**Subtotal** — the amount before tax is added.

**Surd** — a square root that cannot be simplified to a whole number, such as
$\sqrt{2}$.

**Tax credit** — an amount that reduces the income tax you pay.

**Union** — the set of elements that belong to at least one of two sets.

**Universal set** — the set of all elements being considered in a problem.

**Value added tax** — a tax added to the price of goods and services.

**Venn diagram** — a diagram that uses circles to show the relationships between
sets.
