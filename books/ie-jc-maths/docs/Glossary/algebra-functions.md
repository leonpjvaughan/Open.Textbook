# Glossary — Algebra and Functions

**Closed circle** — a filled circle on a number line that shows a value is
included.

**Co-domain** — the set of possible outputs a function is allowed to give.

**Coefficient** — the number multiplying a variable, such as the $5$ in $5x$.

**Common difference** — the amount added to each term to get the next term in a
linear pattern.

**Constant** — a value that does not change.

**Difference of two squares** — an expression of the form $a^2-b^2$, which
factorises as $(a-b)(a+b)$.

**Distance–time graph** — a graph of distance against time.

**Domain** — the set of inputs a function accepts.

**Elimination** — a method for solving simultaneous equations by adding or
subtracting them to remove one variable.

**Equation** — a statement that two expressions have the same value, shown by an
equals sign.

**Expanding** — multiplying out brackets to remove them.

**Expression** — numbers, variables and operations written together without an
equals sign.

**Factorising** — writing an expression as a product of its factors.

**First differences** — the differences between consecutive terms of a sequence.

**Formula** — a rule written in symbols that links quantities.

**Function** — a rule that gives exactly one output for each permitted input.

**General term** — a formula that gives any term of a sequence from its
position.

**Inequality** — a comparison that uses a symbol such as $<$, $>$, $\leq$ or
$\geq$.

**Input** — a value you put into a function.

**Inverse operation** — the operation that undoes another.

**Like terms** — terms with the same variable part, such as $3x$ and $-2x$.

**Linear equation** — an equation in which the variable appears to the first
power only.

**Linear pattern** — a pattern whose terms increase or decrease by the same
amount each time.

**Linear relationship** — a relationship that can be represented by a straight-
line graph.

**Multiplier** — the number by which each term of a pattern is multiplied to get
the next term.

**Number line** — a line on which numbers are marked in order.

**Open circle** — a circle on a number line that shows a value is not included.

**Origin** — the point $(0,0)$ where the axes meet.

**Output** — the value a function gives for a given input.

**Parabola** — the curve-shaped graph of a quadratic function.

**Position** — the place a term holds in a sequence, counted from the first.

**Quadratic expression** — an expression in which the highest power of the
variable is 2.

**Quadratic function** — a function whose rule contains the square of the input.

**Quadratic pattern** — a pattern whose second differences are constant.

**Range** — the set of outputs a function produces.

**Root** — a value that makes an expression equal to zero.

**Second differences** — the differences between consecutive first differences.

**Sequence** — an ordered list of numbers.

**Simultaneous equations** — two or more equations that must be true at the same
time.

**Solution** — the value that makes an equation true.

**Subject** — the variable a formula is written for.

**Substitution** — replacing a variable with a number.

**Table of values** — a table listing inputs and the outputs a rule gives.

**Term** — one number or expression in a sequence or in an expression.

**Variable** — a letter that stands for a number that can change.
