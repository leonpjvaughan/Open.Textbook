# 6.6 Speed, distance and time — Practise

Work independently. The questions and answers are shown together at the end.

Write down the units you are working in before you calculate. If a time is given
in minutes and the answer is wanted in km/h, change the time to hours first. A
correct number with the wrong unit is not a correct answer.
