# 2.4 Fractional indices and roots — Learn

**Prerequisites:** squares, cubes and roots, and the laws of indices from
Section 2.2.

**Objectives:** read $a^{\frac1n}$ as the $n$th root of $a$; work out values such
as $9^{\frac12}$ and $8^{\frac13}$; work out a power such as $8^{\frac23}$; work
out a negative fractional index.

By the end of this section, you can read a fractional index as a root, and work
out the value of a fractional power.

## The half index

Which number, squared, gives 2? It is not a whole number, because $1^2 = 1$ and
$2^2 = 4$. The number is the square root of 2, written $\sqrt2$.

Use the power law to see how the half index fits. If $2^{\frac12}$ is to make
sense, then squaring it must give 2.

$$\left(2^{\frac12}\right)^2 = 2^{\frac12\times2} = 2^1 = 2$$

So $2^{\frac12}$ is the number whose square is 2. That is exactly what $\sqrt2$
means.

$$a^{\frac12} = \sqrt a$$

The value is about 1.414. The decimal never ends and never repeats, so 1.414 is a
rounded value.

## The one-nth index

The same reasoning works for any root. Cube $8^{\frac13}$ and you must get 8.

$$\left(8^{\frac13}\right)^3 = 8^{\frac13\times3} = 8^1 = 8$$

So $8^{\frac13}$ is the number whose cube is 8, which is 2.

$$a^{\frac1n} = \sqrt[n]{a}$$

The symbol $\sqrt[n]{a}$ is the **$n$th root** of $a$. For $n = 2$ you write
$\sqrt a$ and leave the 2 out.

**Example 1.** Work out $9^{\frac12}$, $100^{\frac12}$ and $27^{\frac13}$.

$$9^{\frac12} = \sqrt9 = 3$$

$$100^{\frac12} = \sqrt{100} = 10$$

$$27^{\frac13} = \sqrt[3]{27} = 3$$

**Example 2.** Work out $16^{\frac14}$.

$$16^{\frac14} = \sqrt[4]{16} = 2$$

Check it: $2^4 = 16$.

## A fractional index with a numerator

$8^{\frac23}$ has numerator 2 and denominator 3. The denominator names the root,
and the numerator is the power.

$$8^{\frac23} = \left(8^{\frac13}\right)^2 = 2^2 = 4$$

Take the root first, then raise the result to the power. Taking the root first
keeps the numbers small.

$$a^{\frac mn} = \left(\sqrt[n]{a}\right)^m$$

**Example 3.** Work out $16^{\frac34}$.

$$16^{\frac34} = \left(16^{\frac14}\right)^3 = 2^3 = 8$$

**Example 4.** Work out $25^{\frac32}$.

$$25^{\frac32} = \left(25^{\frac12}\right)^3 = 5^3 = 125$$

## Negative fractional indices

A negative index still means a reciprocal, even when the index is a fraction.

**Example 5.** Work out $4^{-\frac12}$.

$$4^{-\frac12} = \frac{1}{4^{\frac12}} = \frac{1}{2}$$

**Example 6.** Work out $27^{-\frac23}$.

$$27^{-\frac23} = \frac{1}{27^{\frac23}} = \frac{1}{\left(27^{\frac13}\right)^2} = \frac{1}{3^2} = \frac{1}{9}$$

## Using a calculator

The root key is usually written $\sqrt[n]{x}$ or `x^(1/n)`. To work out
$2^{\frac12}$, type `2 ^ ( 1 / 2 ) =` and read 1.414213562. That is $\sqrt2$
rounded.

> **Watch out.** A fractional index is not a division of the base. $2^{\frac12}$
> is not $2\div2 = 1$, and $8^{\frac13}$ is not $8\div3$. The denominator tells
> you which root to take. Check by raising your answer back to the power: $1^2 = 1$,
> and 1 is not 2, so 1 cannot be $2^{\frac12}$.

## Progress check

Back to the photocopier, and now the chapter problem is within reach. An A4 sheet
is 210 mm wide and 297 mm tall.

1. The 141% button multiplies the width by $2^{\frac12}$. Work out $2^{\frac12}$
   to 3 decimal places.
2. Work out $210\times2^{\frac12}$, to the nearest millimetre. That is the width
   of an A3 sheet.
3. The 71% button multiplies the width by $2^{-\frac12}$. Work out
   $2^{-\frac12}$ to 3 decimal places, and explain why it undoes the 141% button.
4. The 141% button doubles the area. Write that multiplier as $2^1$, and check
   that $2^{\frac12}\times2^{\frac12} = 2^1$.

## You should now be able to

- read $a^{\frac1n}$ as the $n$th root of $a$;
- work out values such as $9^{\frac12}$, $8^{\frac13}$ and $16^{\frac14}$;
- work out a fractional power such as $8^{\frac23}$ by taking the root first;
- work out a negative fractional index as a reciprocal;
- say why $2^{\frac12}$ is $\sqrt2$ and not 1.
