# 2.2 The laws of indices — Practise with help

## Warm-up: remember

1. Write $4\times4\times4$ in index form.
2. Work out $2^5$.

<details markdown="1">
<summary>Answers and feedback</summary>

1. $4^3$. The base is 4 and it repeats three times.
2. $32$. Keep doubling: 2, 4, 8, 16, 32.

Both answers come from Section 2.1. This section does not change what a power
means. It gives you shorter ways to combine powers, so return here if either
answer felt unsure.

</details>

:::figure warm-up-gate


## Practise with help

**1.** Simplify $2^4\times2^3$.

<details markdown="1">
<summary>Hint</summary>

The base is the same in both powers, so the indices combine.

<details markdown="1">
<summary>Next step</summary>

Multiplying powers with the same base adds the indices: $2^{4+3}$.

<details markdown="1">
<summary>Full working</summary>

$$2^4\times2^3 = 2^{4+3} = 2^7$$

The value is $128$. Check with the products: $16\times8 = 128$.

</details>
</details>
</details>

**2.** Simplify $7^6\div7^2$.

<details markdown="1">
<summary>Hint</summary>

Dividing powers with the same base subtracts the indices.

<details markdown="1">
<summary>Next step</summary>

$7^{6-2}$.

<details markdown="1">
<summary>Full working</summary>

$$7^6\div7^2 = 7^{6-2} = 7^4$$

The value is $2401$. Dividing cancels the two matching factors underneath.

</details>
</details>
</details>

**3.** Simplify $(3^2)^4$.

<details markdown="1">
<summary>Hint</summary>

One power is raised to another. The brackets show that the whole power repeats.

<details markdown="1">
<summary>Next step</summary>

Multiply the two indices: $3^{2\times4}$.

<details markdown="1">
<summary>Full working</summary>

$$(3^2)^4 = 3^{2\times4} = 3^8$$

The value is $6561$. It is not $3^6$, because the indices multiply and do not add.

</details>
</details>
</details>

**4.** Simplify $x^5\times x^2$.

<details markdown="1">
<summary>Hint</summary>

The base is $x$ in both powers. The same law works with a letter as the base.

<details markdown="1">
<summary>Next step</summary>

Add the indices: $x^{5+2}$.

<details markdown="1">
<summary>Full working</summary>

$$x^5\times x^2 = x^7$$

The base stays as $x$, and the index is 7. Write the answer as one power rather
than as a product.

</details>
</details>
</details>

**5.** Simplify $\dfrac{a^7}{a^3}$.

<details markdown="1">
<summary>Hint</summary>

This is a division of powers with the same base.

<details markdown="1">
<summary>Next step</summary>

Subtract the indices: $a^{7-3}$.

<details markdown="1">
<summary>Full working</summary>

$$\frac{a^7}{a^3} = a^4$$

You can picture the cancellation: seven copies of $a$ on top, three underneath,
leaving four on top.

</details>
</details>
</details>

**6.** Simplify $(2y)^3$.

<details markdown="1">
<summary>Hint</summary>

The power outside the bracket applies to every factor inside it.

<details markdown="1">
<summary>Next step</summary>

$2^3\times y^3$.

<details markdown="1">
<summary>Full working</summary>

$$(2y)^3 = 2^3 y^3 = 8y^3$$

The 2 is raised to the power as well as the $y$, because the whole product
repeats three times.

</details>
</details>
</details>

**7.** Simplify $\dfrac{5^6\times5^2}{5^5}$.

<details markdown="1">
<summary>Hint</summary>

Deal with the top of the fraction first, then the division.

<details markdown="1">
<summary>Next step</summary>

$5^6\times5^2 = 5^8$, so the fraction is $5^8\div5^5$.

<details markdown="1">
<summary>Full working</summary>

$$\frac{5^6\times5^2}{5^5} = \frac{5^8}{5^5} = 5^3 = 125$$

Adding the indices on top gives 8, then subtracting the index underneath gives 3.

</details>
</details>
</details>

**8.** Which law applies to $(4^3)^2$, and which to $4^3\times4^2$? Work out both.

<details markdown="1">
<summary>Hint</summary>

Look at the brackets. One expression has a power of a power, and the other
multiplies two powers.

<details markdown="1">
<summary>Next step</summary>

For $(4^3)^2$ multiply the indices. For $4^3\times4^2$ add them.

<details markdown="1">
<summary>Full working</summary>

$$(4^3)^2 = 4^6 = 4096$$

$$4^3\times4^2 = 4^5 = 1024$$

The first has brackets, so the indices multiply. The second has no brackets, so
the indices add.

</details>
</details>
</details>

## A question from an earlier section

**9.** Work out $2^8$.

<details markdown="1">
<summary>Hint</summary>

You can build $2^8$ from $2^5\times2^3$, using this section's law.

<details markdown="1">
<summary>Next step</summary>

$2^5 = 32$ and $2^3 = 8$.

<details markdown="1">
<summary>Full working</summary>

$$2^8 = 2^5\times2^3 = 32\times8 = 256$$

You could also keep doubling from $2^6 = 64$: 128, then 256. Both methods agree.

</details>
</details>
</details>
