# Chapter 2: Powers and index laws

Some numbers grow by adding the same amount each time. Others grow by
multiplying by the same amount. The second kind grows much faster, and writing it
down needs a new piece of notation.

## The chapter problem

**The A3 button.** A sheet of A4 paper is 210 mm wide and 297 mm tall. The
photocopier in the school office has buttons marked 50%, 71%, 100%, 141% and
200%.

The 141% button turns an A4 sheet into an A3 sheet. The shape stays the same and
the area doubles.

Before you calculate anything, write down a prediction. If the area doubles, does
the width double too? Do you expect the new width to be nearer 250 mm, 300 mm or
420 mm?

By the end of the chapter you can say what each button multiplies the width and
the area by. You can also explain why the number 141 appears on the button at
all. You will return to this photocopier in every section.

## By the end of this chapter you can

- write a repeated product in index form, and name the base and the index;
- work out the value of a power, including squares and cubes;
- use the laws of indices to multiply powers, divide powers and raise a power to
  a power;
- explain why any non-zero number to the power zero is 1, and write a negative
  index as a reciprocal;
- read a fractional index as a root, and work out values such as $8^{\frac23}$;
- use all of this to describe what each photocopier button does.

## Where it is used

Science, money and computing all use powers. A population that doubles, a debt
that grows by a fixed percentage and a file size that keeps multiplying are all
powers. Very large and very small numbers are written with powers of 10. A root
turns an area back into a side length, or a volume back into an edge.
