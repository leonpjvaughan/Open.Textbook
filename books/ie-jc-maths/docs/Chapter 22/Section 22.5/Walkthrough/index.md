# 22.5 Measures of centre: mean, median and mode — Learn

**Prerequisites:** frequency tables from Section 22.3.

**Objectives:** work out the mean, the median and the mode of a set of data;
choose the measure that best describes the data; read a mean from a frequency
table.

By the end of this section you can give one number that describes a whole set of
data, and say why you chose that number.

## A single typical value

A table or a graph shows all the data. Sometimes you want one number that stands
for the whole set. That number is a **measure of centre**. It describes a typical
or middle value.

There are three measures of centre, and each is useful in a different way.

## The mean

The **mean** is the total of the values divided by how many there are.

$$\text{mean} = \frac{\text{sum of the values}}{\text{number of values}}$$

**Example 1.** Find the mean of $4, 7, 6, 9, 4$.

$$4+7+6+9+4=30$$

There are 5 values, so the mean is

$$\frac{30}{5}=6$$

The mean is 6.

## The median

The **median** is the middle value when the data is written in order. Half the
values are below it, and half are above it.

If there is an even number of values, there is no single middle value. Take the
mean of the two middle values.

**Example 2.** Find the median of $4, 7, 6, 9, 4$.

Write the values in order.

$$4, 4, 6, 7, 9$$

There are 5 values, so the third one is the middle. The median is 6.

Now find the median of $3, 5, 8, 10$. There are 4 values, so the middle two are 5
and 8.

$$\frac{5+8}{2}=6.5$$

The median is 6.5.

## The mode

The **mode** is the value that appears most often.

**Example 3.** Find the mode of $4, 7, 6, 9, 4$.

The value 4 appears twice, and every other value appears once. The mode is 4.

A set of data can have more than one mode, if two values tie for the most
appearances. It can also have no mode, if every value appears the same number of
times.

## The chapter problem

The 20 sleep answers are

$$9, 10, 9, 10, 8, 8, 8, 9, 7, 8, 8, 7, 6, 7, 6, 7, 5, 6, 5, 5$$

**The mean.** Add the 20 values.

$$9+10+9+10+8+8+8+9+7+8+8+7+6+7+6+7+5+6+5+5=148$$

Divide by 20.

$$\frac{148}{20}=7.4$$

The mean sleep is 7.4 hours.

**The median.** Write the values in order.

$$5, 5, 5, 6, 6, 6, 7, 7, 7, 7, 8, 8, 8, 8, 8, 9, 9, 9, 10, 10$$

There are 20 values, so the middle two are the 10th and the 11th. They are 7 and 8.

$$\frac{7+8}{2}=7.5$$

The median sleep is 7.5 hours.

**The mode.** The value 8 appears 5 times, more than any other. The mode is 8
hours.

## Which measure should you use?

Each measure tells you something different.

| Measure | Best used when |
|---|---|
| Mean | the data is fairly even, and you want to use every value |
| Median | there are extreme values, or the data is skewed |
| Mode | the data is a category, or you want the most common value |

An extreme value is one that is much larger or smaller than the rest. It pulls the
mean towards it, but the median hardly moves. That is why house prices are usually
described by the median.

## Watch out

> **Watch out.** You must put the data in order before you find the median. The
> common error is to take the middle value of the list as it was given.
>
> For $9, 4, 7, 4, 6$, the middle value in the original list is 7, but that is not
> the median. In order the list is $4, 4, 6, 7, 9$, so the median is 6.
>
> **Re-check:** sort the list first, then count. For an even number of values, take
> the mean of the two middle ones.
