# 1.1 The number systems ℕ, ℤ and ℚ — Learn

**Prerequisites:** counting, place value, and multiplication tables.

**Objectives:** name the natural numbers, the integers and the rational numbers; say
which of those sets a number belongs to; write a decimal as a fraction.

By the end of this section, you can sort a number into the right family and explain
your choice.

## The natural numbers

The numbers you count with are the **natural numbers**:

$$\mathbb{N} = \{1, 2, 3, 4, \ldots\}$$

The three dots mean that the list never ends. Natural numbers answer the question
"how many?". They are the numbers on a number line when you count steps to the right
from 1.

In this book, the natural numbers start at 1. The number 0 is not natural, because
you do not count to zero. That is a choice, and other books make it differently, so
say which one you are using if it matters.

**Example 1.** Write down the natural numbers between 3 and 8.

$$4, 5, 6, 7$$

The word *between* leaves out 3 and 8. It also leaves out $4.5$, because $4.5$ is not
a counting number.

## The integers

If you owe money, the counting numbers are not enough. You need a way to write that
an amount is below zero.

$$\mathbb{Z} = \{\ldots, -3, -2, -1, 0, 1, 2, 3, \ldots\}$$

These are the **integers**. The integers contain every natural number, and they add
zero and the negatives. The letter Z comes from the German word *Zahl*, which means
number.

Every natural number is an integer. So $\mathbb{N}$ sits inside $\mathbb{Z}$.

**Example 2.** Which of $-6$, $0$, $4$ and $9$ are integers?

All four are integers. The integers include the negatives, zero and the positives.
$-6$ is an integer but not a natural number, because it is below 1.

## The rational numbers

A **rational number** is a number that you can write as a fraction of two integers,
with the bottom number not zero.

$$\mathbb{Q} = \left\{\frac{a}{b} : a \text{ and } b \text{ are integers, and } b \neq 0\right\}$$

Every integer is rational, because you can write it over 1:

$$7 = \frac{7}{1} \qquad -4 = \frac{-4}{1}$$

So $\mathbb{N}$ sits inside $\mathbb{Z}$, and $\mathbb{Z}$ sits inside $\mathbb{Q}$.

A rational number written as a decimal does one of two things. It either stops, like
$0.75$, or it repeats for ever, like $0.333\ldots$. Both kinds can be turned back
into a fraction.

**Example 3.** Write $0.75$ as a fraction in its simplest form.

$$0.75 = \frac{75}{100} = \frac{3}{4}$$

Divide the top and the bottom by 25. The fraction $3/4$ is in its simplest form,
because 3 and 4 share no factor.

**Example 4.** Write $2.5$ as a fraction, and say which sets it belongs to.

$$2.5 = \frac{25}{10} = \frac{5}{2}$$

So $2.5$ is rational. It is not an integer and not natural, because it sits between
2 and 3.

## The three sets together

| Set | Symbol | What is in it | Examples |
|---|---|---|---|
| Natural numbers | $\mathbb{N}$ | the counting numbers | $1, 2, 3, 4$ |
| Integers | $\mathbb{Z}$ | the whole numbers and their negatives | $-3, -2, -1, 0, 1, 2, 3$ |
| Rational numbers | $\mathbb{Q}$ | numbers that are a fraction of two integers | $\frac{3}{4}, -5, 0.75, \frac{13}{2}$ |

Every natural number is an integer. Every integer is rational. So the three sets sit
inside each other like boxes:

$$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q}$$

> **Watch out.** A decimal is not automatically outside $\mathbb{Q}$. The number
> $0.5$ is $\frac{1}{2}$, so it is rational. What decides the family is whether you
> can write the number as a fraction of two integers, not how it looks.
>
> **Re-check:** if you are told a number is rational, try to write it as a fraction.
> If you are told it is an integer, check that it has no fractional part. A negative
> number is never natural.

## Progress check

Return to the chapter problem. The trip budget uses three of these kinds of number:

- 35 people;
- a fund balance that falls to $-20$ euros;
- a lunch price of $6.50$ euros.

1. Which of the three is a natural number?
2. Which one is an integer that is not a natural number?
3. Write $6.50$ as a fraction in its simplest form.

Keep your answers. In Section 1.2 you will work out how the balance of $-20$ euros
arose.

## You should now be able to

- write down natural numbers to a given point, and say why 0 is not one of them;
- say whether a number is an integer;
- write a decimal such as $0.75$ or $6.5$ as a fraction in its simplest form;
- explain why every natural number is an integer, and every integer is rational.
