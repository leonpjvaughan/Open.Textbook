# 17.3 Slope of a line — Practise with help

## Warm-up: remember

Work these from memory. They are the skills this section uses.

1. Work out $-8\div4$.
2. Write $6\div8$ as a fraction in its simplest form.
3. Work out $9-4$.

<details markdown="1">
<summary>Answers and feedback</summary>

1. $-2$. A negative divided by a positive is negative.
2. $\tfrac{3}{4}$. Divide the top and the bottom by 2.
3. $5$. The rise and the run are found by subtracting coordinates.

A slope is a division, so the sign and the fraction both matter.

</details>

:::figure warm-up-gate


## Practise with help

**1.** Find the slope of the line through $(1,3)$ and $(5,11)$.

<details markdown="1">
<summary>Hint</summary>

Divide the rise by the run. The rise is the change in $y$ and the run is the
change in $x$.

<details markdown="1">
<summary>Next step</summary>

$$\frac{11-3}{5-1} = \frac{8}{4}$$

<details markdown="1">
<summary>Full working</summary>

The slope is $2$.

$$\frac{8}{4}=2$$

The line rises 2 for every 1 across.

</details>
</details>
</details>

**2.** Find the slope of the line through $(2,5)$ and $(6,2)$.

<details markdown="1">
<summary>Hint</summary>

The rise is $2-5$, which is negative because the line falls.

<details markdown="1">
<summary>Next step</summary>

$$\frac{2-5}{6-2} = \frac{-3}{4}$$

<details markdown="1">
<summary>Full working</summary>

The slope is $-\tfrac{3}{4}$.

$$\frac{-3}{4}=-\frac{3}{4}$$

The slope is negative, so the line goes down as you move right.

</details>
</details>
</details>

**3.** Find the slope of the line through $(0,1)$ and $(4,3)$.

<details markdown="1">
<summary>Hint</summary>

Use the two points in the same order in the top and the bottom.

<details markdown="1">
<summary>Next step</summary>

$$\frac{3-1}{4-0} = \frac{2}{4}$$

<details markdown="1">
<summary>Full working</summary>

The slope is $\tfrac{1}{2}$.

$$\frac{2}{4}=\frac{1}{2}$$

The line rises 1 for every 2 across, so it is gentler than 45°.

</details>
</details>
</details>

**4.** Find the slope of the line through $(1,4)$ and $(5,4)$.

<details markdown="1">
<summary>Hint</summary>

Both points have the same $y$-coordinate. Work out the rise.

<details markdown="1">
<summary>Next step</summary>

$$\frac{4-4}{5-1} = \frac{0}{4}$$

<details markdown="1">
<summary>Full working</summary>

The slope is $0$.

$$\frac{0}{4}=0$$

The line is horizontal. A horizontal line has slope 0, because its rise is 0.

</details>
</details>
</details>

**5.** Find the slope of the line through $(2,1)$ and $(2,7)$.

<details markdown="1">
<summary>Hint</summary>

Both points have the same $x$-coordinate. Work out the run.

<details markdown="1">
<summary>Next step</summary>

$$\frac{7-1}{2-2} = \frac{6}{0}$$

<details markdown="1">
<summary>Full working</summary>

The slope is undefined. The run is $2-2=0$, and division by 0 has no answer. The
line is vertical, and a vertical line has no slope.

</details>
</details>
</details>

**6.** A path rises 4 m over a horizontal run of 6 m. Find its slope.

<details markdown="1">
<summary>Hint</summary>

Divide the rise by the run and simplify the fraction.

<details markdown="1">
<summary>Next step</summary>

$$\frac{4}{6}$$

<details markdown="1">
<summary>Full working</summary>

The slope is $\tfrac{2}{3}$.

$$\frac{4}{6}=\frac{2}{3}$$

The path rises 2 m for every 3 m across. A slope is a pure number, with no unit.

</details>
</details>
</details>

**7.** The park gate is $G(1,2)$, the kiosk is $K(9,8)$ and the pond is $P(3,16)$.
Find the slope of the main path $GK$ and the slope of the second path $KP$.

<details markdown="1">
<summary>Hint</summary>

Use the same formula twice. Watch the sign when the run is negative.

<details markdown="1">
<summary>Next step</summary>

$$\frac{8-2}{9-1} = \frac{6}{8}$$

$$\frac{16-8}{3-9} = \frac{8}{-6}$$

<details markdown="1">
<summary>Full working</summary>

The main path has slope $\tfrac{3}{4}$ and the second path has slope
$-\tfrac{4}{3}$.

$$\frac{6}{8}=\frac{3}{4} \qquad \frac{8}{-6}=-\frac{4}{3}$$

The second path runs to the left, so its run is negative. It still rises, so its
slope is negative.

</details>
</details>
</details>

## A question from an earlier section

**8.** Work out $\frac{1}{2}+\frac{1}{4}$.

<details markdown="1">
<summary>Hint</summary>

Write both fractions with the same denominator.

<details markdown="1">
<summary>Next step</summary>

$$\frac{2}{4}+\frac{1}{4}$$

<details markdown="1">
<summary>Full working</summary>

$$\frac{1}{2}+\frac{1}{4}=\frac{3}{4}$$

Adding fractions returns in this chapter, because a slope is often left as a
fraction.

</details>
