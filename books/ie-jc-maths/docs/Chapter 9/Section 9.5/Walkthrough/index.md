# 9.5 Converting between representations — Learn

**Prerequisites:** the general terms of linear, quadratic and exponential patterns
from Sections 9.2, 9.3 and 9.4.

**Objectives:** move between words, a table, a graph and a rule; plot a pattern from a
table; read a rule from a graph.

By the end of this section, you can describe the same pattern in four different ways.

## The same pattern, four ways

Every pattern can be shown in four ways. They all describe the same thing, and you can
move from any one to any other.

- **Words:** "Start at 4, and add 3 each time."
- **Table:** a row of positions and a row of terms.
- **Graph:** the points plotted on a grid.
- **Rule:** the general term, $3n+1$.

## From a rule to a table

To turn a rule into a table, put the positions into the rule one at a time.

**Example 1.** Make a table for the rule $3n+1$ at positions 1 to 4.

| Position $n$ | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| Term $3n+1$ | 4 | 7 | 10 | 13 |

The terms are $4, 7, 10, 13$. The rule and the table hold the same information.

## From a table to a graph

To draw the graph, plot each pair as a point. The **position** goes on the horizontal
axis, and the **term** goes on the vertical axis.

For the table above, the points are

$$(1, 4), (2, 7), (3, 10), (4, 13)$$

Because the first difference is constant, the points lie on a straight line. A linear
pattern always gives a straight-line graph.

## From a graph to a rule

To read a rule from a graph, find the change between neighbouring points. That change
is the common difference, and it is the number that multiplies $n$.

**Example 2.** A graph passes through $(1, 4)$, $(2, 7)$ and $(3, 10)$. Find the rule.

The points rise by 3 each step across, so the common difference is $3$. The rule starts
with $3n$.

At position 1, the term is 4, and $3(1)=3$. You need 1 more, so the rule is $3n+1$.

Check position 3: $3(3)+1=10$. It matches.

**Example 3.** A graph passes through $(1, 3)$, $(2, 6)$ and $(3, 12)$. Find the rule.

The points do not rise by the same amount, so the pattern is not linear. Divide each
term by the one before it: $6\div3=2$ and $12\div6=2$. The multiplier is 2, so the
pattern is exponential.

The first term is 3, so the rule is $3\times2^{n-1}$.

Check position 3: $3\times2^2=12$. It matches.

## The shape of each graph

The kind of pattern decides the shape of the graph.

| Kind | Shape of the graph |
|---|---|
| Linear | a straight line |
| Quadratic | a curve that bends upwards |
| Exponential | a curve that gets steep very quickly |

**Example 4.** A graph curves through $(1, 1)$, $(2, 4)$ and $(3, 9)$. Which kind of
pattern is it?

The points are the square numbers, so the rule is $n^2$. The first differences are
$3, 5, 7$, which grow, so the graph curves. The pattern is quadratic.

> **Watch out.** The graph plots the term against the **position**, not against the
> previous term. For the pattern $4, 7, 10, 13$, the points are $(1,4), (2,7), (3,10),
> (4,13)$. Plotting $(4,7)$ would be wrong, because 4 is a term, not a position.
>
> **Re-check:** read the horizontal axis label before you plot. If it says "position",
> the first coordinate is a position.

## You should now be able to

- move between words, a table, a graph and a rule;
- plot a pattern from a table, using the position and the term;
- read the common difference or the multiplier from a graph;
- recognise a linear, quadratic or exponential graph from its shape.
