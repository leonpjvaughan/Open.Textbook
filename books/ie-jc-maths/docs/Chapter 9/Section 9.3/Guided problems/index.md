# 9.3 Quadratic patterns and their general term — Practise with help

## Warm-up: remember

1. Work out $6^2$.
2. Work out $9-4$.

<details markdown="1">
<summary>Answers and feedback</summary>

1. $36$, because $6\times6=36$.
2. $5$.

Squaring returns in every $n^2$ term, and subtraction is how you find a difference.

</details>

## Practise with help

**1.** Write down the first differences of the pattern $4, 9, 16, 25, \ldots$.

<details markdown="1">
<summary>Hint</summary>

Subtract each term from the next one.

<details markdown="1">
<summary>Next step</summary>

$9-4=5$ and $16-9=7$.

<details markdown="1">
<summary>Full working</summary>

$$5, 7, 9$$

The first differences grow by 2 each time, so this is a quadratic pattern.

</details>
</details>
</details>

**2.** Write down the second difference of the pattern $4, 9, 16, 25, \ldots$.

<details markdown="1">
<summary>Hint</summary>

Find the first differences first, then subtract them.

<details markdown="1">
<summary>Next step</summary>

The first differences are $5, 7, 9$.

<details markdown="1">
<summary>Full working</summary>

$$7-5=2 \qquad 9-7=2$$

The second difference is $2$. It is the same each time, which confirms the pattern is
quadratic.

</details>
</details>
</details>

**3.** Find the general term of the quadratic pattern $1, 4, 9, 16, \ldots$.

<details markdown="1">
<summary>Hint</summary>

These are the square numbers.

<details markdown="1">
<summary>Next step</summary>

The second difference is 2, and half of 2 is 1, so the rule starts with $1n^2$.

<details markdown="1">
<summary>Full working</summary>

The general term is $n^2$.

Check position 3: $3^2=9$. Check position 4: $4^2=16$. Both match.

</details>
</details>
</details>

**4.** Find the general term of $3, 8, 15, 24, \ldots$.

<details markdown="1">
<summary>Hint</summary>

Find the second difference, then halve it.

<details markdown="1">
<summary>Next step</summary>

The first differences are $5, 7, 9$, and the second difference is 2. So start with
$n^2$, which is $1, 4, 9, 16$.

<details markdown="1">
<summary>Full working</summary>

Subtract $n^2$ from each term: $3-1=2$, $8-4=4$, $15-9=6$, $24-16=8$. That row follows
$2n$, so the general term is $n^2+2n$.

Check position 4: $16+8=24$. It matches.

</details>
</details>
</details>

**5.** Find the general term of $2, 6, 12, 20, \ldots$.

<details markdown="1">
<summary>Hint</summary>

The first differences are $4, 6, 8$.

<details markdown="1">
<summary>Next step</summary>

The second difference is 2, so start with $n^2$.

<details markdown="1">
<summary>Full working</summary>

Subtract $n^2$ from each term: $1, 2, 3, 4$. That row follows $n$, so the general term
is $n^2+n$.

Check position 3: $9+3=12$. It matches.

</details>
</details>
</details>

**6.** Find the general term of $5, 12, 23, 38, \ldots$.

<details markdown="1">
<summary>Hint</summary>

The first differences are $7, 11, 15$, so the second difference is 4. Halve it.

<details markdown="1">
<summary>Next step</summary>

Start with $2n^2$, which is $2, 8, 18, 32$. Subtract it from each term.

<details markdown="1">
<summary>Full working</summary>

The remainders are $3, 4, 5, 6$, which follow $n+2$. So the general term is
$2n^2+n+2$.

Check position 4: $2(16)+4+2=38$. It matches.

</details>
</details>
</details>

**7.** Ben's plan has general term $n^2$ euro. How much does he save in week 12?

<details markdown="1">
<summary>Hint</summary>

Put $n=12$ into the rule.

<details markdown="1">
<summary>Next step</summary>

$$12^2$$

<details markdown="1">
<summary>Full working</summary>

$$144$$

He saves €144 in week 12. The square numbers grow quickly, so this is already far more
than Aoife's plan at the same week.

</details>
</details>
</details>

**8.** A quadratic pattern has a constant second difference of 8. What number multiplies
$n^2$ in its general term?

<details markdown="1">
<summary>Hint</summary>

The number that multiplies $n^2$ is half the second difference.

<details markdown="1">
<summary>Next step</summary>

$$8\div2$$

<details markdown="1">
<summary>Full working</summary>

$$4$$

The rule starts with $4n^2$. The second difference of $n^2$ itself is 2, so a second
difference of 8 means four copies of $n^2$.

</details>
</details>
</details>

## A question from an earlier section

**9.** Work out $7^2$.

<details markdown="1">
<summary>Hint</summary>

A square number is a number times itself.

<details markdown="1">
<summary>Next step</summary>

$$7\times7$$

<details markdown="1">
<summary>Full working</summary>

$$49$$

Square numbers are the backbone of every quadratic pattern, so you will use them
often.

</details>
</details>
</details>
