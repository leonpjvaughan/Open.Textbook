# 14.3 Graphing linear functions — Learn

**Prerequisites:** finding the output of a function from Section 14.2, and the order of
operations from Section 1.4.

**Objectives:** plot points on the coordinate plane; make a table of values for a
linear function; draw the graph and join the points with a straight line; read a value
from a graph.

By the end of this section, you can draw the graph of a linear function and read values
from it.

## The coordinate plane

A graph is drawn on a grid with two number lines.

- The **horizontal axis** runs left to right. It is the $x$-axis.
- The **vertical axis** runs bottom to top. It is the $y$-axis.
- The two axes cross at the **origin**, which is the point $(0,0)$.

A point is named by an ordered pair $(x,y)$. The first number is how far across to go,
and the second number is how far up to go.

The point $(3,5)$ is 3 across and 5 up. The point $(0,3)$ is on the vertical axis,
because it is 0 across.

## A table of values

A function gives you the height of the graph at each input. A **table of values** lists
those heights.

**Example 1.** Make a table of values for $y=2x+1$ for $x=0$, $1$, $2$ and $3$.

| $x$ | $2x+1$ | $y$ |
|---|---|---|
| 0 | $2\times0+1$ | 1 |
| 1 | $2\times1+1$ | 3 |
| 2 | $2\times2+1$ | 5 |
| 3 | $2\times3+1$ | 7 |

Each row is one point: $(0,1)$, $(1,3)$, $(2,5)$ and $(3,7)$.

## Drawing the graph

Plot the four points on a grid, and then join them with a straight line. Use a ruler,
and carry the line on a little past the last point.

Every function of the form $y=mx+c$ has a straight-line graph. The values of $m$ and
$c$ decide where the line sits and how steep it is.

- The line crosses the vertical axis at the value $c$, which is the output for $x=0$.
- The number $m$ in front of $x$ decides the steepness. Each step of 1 to the right
  changes $y$ by $m$.

For $y=2x+1$, the line crosses the vertical axis at 1, and each step of 1 to the right
raises the line by 2.

## Going up and going down

The sign of $m$ decides the direction.

- When $m$ is positive, the line goes up as you move to the right.
- When $m$ is negative, the line goes down as you move to the right.

**Example 2.** Make a table for $y=-x+3$ for $x=0$, $1$, $2$ and $3$.

| $x$ | $-x+3$ | $y$ |
|---|---|---|
| 0 | $-0+3$ | 3 |
| 1 | $-1+3$ | 2 |
| 2 | $-2+3$ | 1 |
| 3 | $-3+3$ | 0 |

The values go down by 1 each time, so the line falls to the right. It crosses the
vertical axis at 3.

## Reading a value from the graph

A graph answers two kinds of question.

- Given $x$, find $y$: start on the horizontal axis, go up to the line, then across to
  the vertical axis.
- Given $y$, find $x$: start on the vertical axis, go across to the line, then down to
  the horizontal axis.

**Example 3.** The graph of $y=2x+1$ is a straight line. Find the input that gives the
output 7.

Solve $2x+1=7$. Subtract 1 to get $2x=6$, and divide by 2.

$$x = 3$$

The point $(3,7)$ is on the line.

## The garden bed: the fenced length

The fenced length of the garden bed is a function of the width.

$$L(x) = 12-2x$$

**Example 4.** Make a table for $L(x)=12-2x$ for $x=0$, $1$, $2$, $3$, $4$, $5$ and
$6$.

| $x$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| $L(x)$ | 12 | 10 | 8 | 6 | 4 | 2 | 0 |

Plot the points and join them with a straight line. The line starts at $(0,12)$ and
goes down to $(6,0)$. It falls by 2 for each step of 1 to the right, because the two
widths take 2 m of fence for each extra metre of width.

**Example 5.** Use the table or the graph to find the fenced length when the width is
4 m.

$$L(4) = 12-2\times4 = 12-8 = 4$$

The fenced length is 4 m. On the graph this is the point $(4,4)$.

> **Watch out.** The points on the graph are joined with one straight line, not with
> separate dots or a curve. A linear function has a straight-line graph.
>
> The common error is to plot $(y,x)$ instead of $(x,y)$. For the table above, the
> point for $x=1$ is $(1,10)$, not $(10,1)$.
>
> **Re-check:** the first number of each pair is the input, which goes across. Check one
> point against the table: $x=3$ gives $L=6$, so the point $(3,6)$ must sit on the line.

## Progress check

Return to the chapter problem. The fenced length of the garden bed is $L(x)=12-2x$
metres.

1. Copy and complete the table for $x=0$, $2$, $4$ and $6$.
2. Plot the points and draw the line.
3. Use the graph to find the fenced length when the width is 3 m.
4. Use the graph to find the width that leaves a fenced length of 0 m.

In Section 14.4 you will graph the area of the bed, which is a curve rather than a
line.

## You should now be able to

- plot a point $(x,y)$ on the coordinate plane;
- make a table of values for a linear function;
- draw the graph of a linear function as a straight line;
- read a value of $x$ or of $y$ from the graph;
- explain what the number in front of $x$ does to the line.
