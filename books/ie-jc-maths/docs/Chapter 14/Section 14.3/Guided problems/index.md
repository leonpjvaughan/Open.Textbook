# 14.3 Graphing linear functions — Practise with help

## Warm-up: remember

1. Work out $5\times2-3$.
2. Write down the coordinates of the point that is 4 across and 2 up.

<details markdown="1">
<summary>Answers and feedback</summary>

1. $7$. Multiply first: $5\times2=10$, and then $10-3=7$.
2. $(4,2)$. The first number is across and the second number is up.

Both skills appear in this section. The first one works out a value for the table, and
the second one names a point on the graph.

</details>

## Practise with help

**1.** Make a table of values for $y=x+2$ for $x=0$, $1$ and $2$.

<details markdown="1">
<summary>Hint</summary>

Add 2 to each input.

<details markdown="1">
<summary>Next step</summary>

$$0+2 \qquad 1+2 \qquad 2+2$$

<details markdown="1">
<summary>Full working</summary>

The values are 2, 3 and 4.

The three points are $(0,2)$, $(1,3)$ and $(2,4)$. Plot them and join them with a
straight line.

</details>
</details>
</details>

**2.** Make a table of values for $y=2x$ for $x=0$, $1$, $2$ and $3$.

<details markdown="1">
<summary>Hint</summary>

Double each input.

<details markdown="1">
<summary>Next step</summary>

$$2\times0 \qquad 2\times1 \qquad 2\times2 \qquad 2\times3$$

<details markdown="1">
<summary>Full working</summary>

The values are 0, 2, 4 and 6.

The line passes through the origin, because the output is 0 when the input is 0.

</details>
</details>
</details>

**3.** Find the value of $y$ when $x=2$, using $y=3x-1$.

<details markdown="1">
<summary>Hint</summary>

Multiply before you subtract.

<details markdown="1">
<summary>Next step</summary>

$$3\times2-1$$

<details markdown="1">
<summary>Full working</summary>

$$y = 6-1 = 5$$

The point $(2,5)$ lies on the line.

</details>
</details>
</details>

**4.** Find the value of $y$ when $x=-1$, using $y=x+4$.

<details markdown="1">
<summary>Hint</summary>

Replace $x$ with $-1$. Adding a negative number makes the answer smaller.

<details markdown="1">
<summary>Next step</summary>

$$-1+4$$

<details markdown="1">
<summary>Full working</summary>

$$y = 3$$

The point $(-1,3)$ is to the left of the vertical axis.

</details>
</details>
</details>

**5.** Does the point $(2,5)$ lie on the line $y=x+3$? Substitute to decide.

<details markdown="1">
<summary>Hint</summary>

Put the $x$-coordinate into the rule and see whether you get the $y$-coordinate.

<details markdown="1">
<summary>Next step</summary>

$$2+3 = 5$$

<details markdown="1">
<summary>Full working</summary>

Yes. The rule gives 5 when the input is 2, which is the second coordinate. So the point
$(2,5)$ lies on the line.

</details>
</details>
</details>

**6.** The garden bed has fenced length $L(x)=12-2x$ metres. Find $L(2)$.

<details markdown="1">
<summary>Hint</summary>

Substitute 2 for $x$ and multiply before you subtract.

<details markdown="1">
<summary>Next step</summary>

$$12-2\times2$$

<details markdown="1">
<summary>Full working</summary>

$$L(2) = 12-4 = 8$$

The fenced length is 8 m when the width is 2 m.

</details>
</details>
</details>

**7.** The garden bed has fenced length $L(x)=12-2x$ metres. Find the width that gives
a fenced length of 6 m.

<details markdown="1">
<summary>Hint</summary>

Write $12-2x=6$ and solve the equation.

<details markdown="1">
<summary>Next step</summary>

Subtract 12 from both sides: $-2x=-6$.

<details markdown="1">
<summary>Full working</summary>

$$x = 3$$

The width is 3 m. On the graph this is the point $(3,6)$.

</details>
</details>
</details>

**8.** The graph of $y=2x+1$ is a straight line. Find the input $x$ for which the graph
has height $y=9$.

<details markdown="1">
<summary>Hint</summary>

Solve $2x+1=9$. Subtract 1 first, and then divide by 2.

<details markdown="1">
<summary>Next step</summary>

$$2x = 8$$

<details markdown="1">
<summary>Full working</summary>

$$x = 4$$

The point $(4,9)$ is on the line. On the graph, find 9 on the vertical axis and move
across to the line.

</details>
</details>
</details>

## A question from an earlier section

**9.** Solve $3x-2=10$.

<details markdown="1">
<summary>Hint</summary>

Look back at Section 12.1. Add 2 to both sides, and then divide by 3.

<details markdown="1">
<summary>Next step</summary>

$$3x = 12$$

<details markdown="1">
<summary>Full working</summary>

$$x = 4$$

This is the same equation you solve when you are given the height of the line
$y=3x-2$ and want the input.

</details>
</details>
</details>
