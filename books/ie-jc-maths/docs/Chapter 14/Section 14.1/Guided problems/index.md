# 14.1 The idea of a function — Practise with help

## Warm-up: remember

1. Work out $2\times3+1$.
2. Work out $(-2)^2$.

<details markdown="1">
<summary>Answers and feedback</summary>

1. $7$. Multiply first: $2\times3=6$, and then $6+1=7$.
2. $4$, because $(-2)\times(-2)=4$. The square of a negative number is positive.

Both skills appear in every function in this section. The order of operations decides
what to work out first, and the sign rule decides the sign of the output.

</details>

:::figure warm-up-gate


## Practise with help

**1.** A machine adds 4 to the input. Find the output when the input is 6.

<details markdown="1">
<summary>Hint</summary>

The rule is "add 4". Replace the input with 6 and apply the rule.

<details markdown="1">
<summary>Next step</summary>

$$6+4$$

<details markdown="1">
<summary>Full working</summary>

The output is $10$.

The input 6 gives one output, so the machine is a function.

</details>
</details>
</details>

**2.** A machine multiplies the input by 5. Find the output when the input is 3.

<details markdown="1">
<summary>Hint</summary>

The rule is "multiply by 5". Put the input 3 into the machine.

<details markdown="1">
<summary>Next step</summary>

$$5\times3$$

<details markdown="1">
<summary>Full working</summary>

The output is $15$.

Every input has one output, because multiplying always gives one answer.

</details>
</details>
</details>

**3.** A machine doubles the input and then subtracts 3. Find the output when the input
is 7.

<details markdown="1">
<summary>Hint</summary>

Two operations are applied to the input. Double it first, and then subtract.

<details markdown="1">
<summary>Next step</summary>

$$2\times7 = 14$$

<details markdown="1">
<summary>Full working</summary>

$$14-3 = 11$$

The output is $11$. The doubling happens before the subtraction, because it is the
first operation in the rule.

</details>
</details>
</details>

**4.** The same machine doubles the input and then subtracts 3. Find the output when
the input is 2.

<details markdown="1">
<summary>Hint</summary>

Double 2, and then subtract 3.

<details markdown="1">
<summary>Next step</summary>

$$2\times2 = 4$$

<details markdown="1">
<summary>Full working</summary>

$$4-3 = 1$$

The output is $1$. Compare this with question 3: the same rule gives a different
output for a different input, and one output for each.

</details>
</details>
</details>

**5.** A table shows the input 3 with the outputs 6 and 9. Is the table a function?

<details markdown="1">
<summary>Hint</summary>

Look down the input column. Does any input repeat, and does it have two outputs?

<details markdown="1">
<summary>Next step</summary>

The input 3 has the outputs 6 and 9.

<details markdown="1">
<summary>Full working</summary>

The table is **not** a function.

One input, 3, gives two different outputs. A function gives exactly one output for
each input.

</details>
</details>
</details>

**6.** A rule gives the square of the input. Find the output when the input is $-5$.

<details markdown="1">
<summary>Hint</summary>

Put the input in brackets before you square it, so the sign stays attached.

<details markdown="1">
<summary>Next step</summary>

$$(-5)^2$$

<details markdown="1">
<summary>Full working</summary>

$$(-5)^2 = 25$$

The output is $25$. Squaring is a function, because each input has one square.

</details>
</details>
</details>

**7.** A function has domain $\{2, 4, 6\}$ and the rule "multiply by 3". Write down the
range.

<details markdown="1">
<summary>Hint</summary>

Apply the rule to each input in the domain. The outputs make up the range.

<details markdown="1">
<summary>Next step</summary>

$$3\times2 = 6 \qquad 3\times4 = 12 \qquad 3\times6 = 18$$

<details markdown="1">
<summary>Full working</summary>

The range is $\{6, 12, 18\}$.

The domain lists the inputs and the range lists the outputs. Three inputs give three
outputs here.

</details>
</details>
</details>

**8.** The garden bed has width $x$ metres and area $A=x(12-2x)$ square metres. Find
the area when the width is 3 m, and when the width is 6 m.

<details markdown="1">
<summary>Hint</summary>

Work out the bracket first. For $x=6$ the bracket is $12-12$.

<details markdown="1">
<summary>Next step</summary>

$$x=3: \quad 3(12-6) = 3\times6 \qquad x=6: \quad 6(12-12) = 6\times0$$

<details markdown="1">
<summary>Full working</summary>

$$3\times6 = 18 \qquad 6\times0 = 0$$

The area is $18\ \text{m}^2$ for a width of 3 m, and $0\ \text{m}^2$ for a width of
6 m. A width of 6 m uses all 12 m of fencing on the two widths, so no length is left.

</details>
</details>
</details>

## A question from an earlier section

**9.** Substitute $a=3$ into the expression $4a-1$.

<details markdown="1">
<summary>Hint</summary>

Look back at Section 10.2. The $4a$ means $4\times a$.

<details markdown="1">
<summary>Next step</summary>

$$4\times3-1$$

<details markdown="1">
<summary>Full working</summary>

$$12-1 = 11$$

Substituting a number for a letter is the same skill you use to find the output of a
function.

</details>
</details>
</details>
