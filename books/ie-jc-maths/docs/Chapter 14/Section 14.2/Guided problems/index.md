# 14.2 Function notation and evaluating functions — Practise with help

## Warm-up: remember

1. Work out $3\times4-2$.
2. Solve $x+3=10$.

<details markdown="1">
<summary>Answers and feedback</summary>

1. $10$. Multiply first: $3\times4=12$, and then $12-2=10$.
2. $x=7$. Subtract 3 from both sides.

Both skills appear in this section. Finding an output uses the first one, and finding
an input uses the second one.

</details>

## Practise with help

**1.** The function $f$ is given by $f(x)=x+6$. Find $f(2)$.

<details markdown="1">
<summary>Hint</summary>

Replace the $x$ in the rule with the input 2.

<details markdown="1">
<summary>Next step</summary>

$$f(2) = 2+6$$

<details markdown="1">
<summary>Full working</summary>

$$f(2) = 8$$

The output is 8. The number in the bracket is the input.

</details>
</details>
</details>

**2.** The function $f$ is given by $f(x)=4x$. Find $f(5)$.

<details markdown="1">
<summary>Hint</summary>

The $4x$ means $4\times x$. Replace the $x$ with 5.

<details markdown="1">
<summary>Next step</summary>

$$f(5) = 4\times5$$

<details markdown="1">
<summary>Full working</summary>

$$f(5) = 20$$

The output is 20. The letter $x$ has gone, because it was replaced by the input.

</details>
</details>
</details>

**3.** The function $f$ is given by $f(x)=2x-1$. Find $f(-3)$.

<details markdown="1">
<summary>Hint</summary>

Put the negative input in brackets before you multiply.

<details markdown="1">
<summary>Next step</summary>

$$f(-3) = 2\times(-3)-1$$

<details markdown="1">
<summary>Full working</summary>

$$f(-3) = -6-1 = -7$$

The output is $-7$. The multiplication gives a negative number, and subtracting 1
makes it smaller still.

</details>
</details>
</details>

**4.** The function $g$ is given by $g(x)=x^2+2$. Find $g(4)$.

<details markdown="1">
<summary>Hint</summary>

Work out the square before the addition.

<details markdown="1">
<summary>Next step</summary>

$$g(4) = 4^2+2 = 16+2$$

<details markdown="1">
<summary>Full working</summary>

$$g(4) = 18$$

The output is 18. The index applies to the input alone, so $4^2$ is $4\times4$.

</details>
</details>
</details>

**5.** The function $f$ is given by $f(x)=3x+1$. Find the input $x$ for which
$f(x)=13$.

<details markdown="1">
<summary>Hint</summary>

Write the rule equal to the output, and solve the equation.

<details markdown="1">
<summary>Next step</summary>

$$3x+1 = 13$$

Subtract 1 from both sides: $3x=12$.

<details markdown="1">
<summary>Full working</summary>

$$x = 4$$

The input is 4, because $3\times4+1=13$.

</details>
</details>
</details>

**6.** The function $h$ is given by $h(x)=2x$. Find the input $x$ for which $h(x)=18$.

<details markdown="1">
<summary>Hint</summary>

Write $2x=18$ and divide both sides by 2.

<details markdown="1">
<summary>Next step</summary>

$$2x = 18$$

<details markdown="1">
<summary>Full working</summary>

$$x = 9$$

The input is 9, because $2\times9=18$.

</details>
</details>
</details>

**7.** The garden bed has area $A(x)=12x-2x^2$ square metres, where $x$ is the width
in metres. Find $A(5)$.

<details markdown="1">
<summary>Hint</summary>

Substitute 5 for $x$. Work out the index before the subtraction.

<details markdown="1">
<summary>Next step</summary>

$$A(5) = 12\times5-2\times5^2 = 60-2\times25$$

<details markdown="1">
<summary>Full working</summary>

$$A(5) = 60-50 = 10$$

The area is $10\ \text{m}^2$ for a width of 5 m.

</details>
</details>
</details>

**8.** The garden bed has area $A(x)=12x-2x^2$ square metres. Find the two widths for
which the area is $10\ \text{m}^2$.

<details markdown="1">
<summary>Hint</summary>

Write $12x-2x^2=10$. Move every term to one side and divide by 2 first.

<details markdown="1">
<summary>Next step</summary>

$$12x-2x^2 = 10 \qquad x^2-6x+5 = 0$$

<details markdown="1">
<summary>Full working</summary>

$$(x-1)(x-5) = 0$$

So $x=1$ or $x=5$.

The two widths 1 m and 5 m both give an area of $10\ \text{m}^2$. The answer to
question 7 is one of them.

</details>
</details>
</details>

## A question from an earlier section

**9.** Solve $2x+5=17$.

<details markdown="1">
<summary>Hint</summary>

Look back at Section 12.1. Undo the addition first, and then the multiplication.

<details markdown="1">
<summary>Next step</summary>

Subtract 5 from both sides: $2x=12$.

<details markdown="1">
<summary>Full working</summary>

$$x = 6$$

Finding the input of a function is the same two-step process, with the rule written in
place of the left-hand side.

</details>
</details>
</details>
