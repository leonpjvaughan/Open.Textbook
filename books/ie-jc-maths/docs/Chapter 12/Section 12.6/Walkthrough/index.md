# 12.6 Graphing the solution set of an inequality — Learn

**Prerequisites:** solving linear inequalities from Section 12.5, and the number line
from Section 17.1.

**Objectives:** draw the solution set of an inequality on a number line; choose an open
or a closed circle; point the arrow the right way; show a solution set between two
values; graph for whole numbers, integers and real numbers.

By the end of this section, you can draw the solution set of an inequality on a number
line.

## The number line

The solution set of an inequality has many values, so a single dot is not enough. You
show the whole set on a **number line**.

Two things carry the meaning:

- the **circle** at the endpoint, which is open or closed;
- the **arrow**, which points to the side that belongs to the solution set.

A **closed circle** means the endpoint is included, which happens with $\leq$ and
$\geq$. An **open circle** means the endpoint is not included, which happens with $<$
and $>$.

## Drawing one inequality

**Example 1.** Draw the solution set of $x>4$.

The endpoint is 4, and the sign is $>$, so the circle is open. The solution set is
greater than 4, so the arrow points to the right.

Draw an open circle at 4, and draw an arrow from it to the right.

**Example 2.** Draw the solution set of $x\leq4$.

The sign is $\leq$, so the circle at 4 is closed. The solution set is less than 4, so
the arrow points to the left.

**Example 3.** Draw the solution set of $x<-2$.

Draw an open circle at $-2$, and an arrow to the left.

**Example 4.** Draw the solution set of $x\geq0$.

Draw a closed circle at 0, and an arrow to the right.

## A solution set between two values

Some inequalities have two endpoints, one at each end of the shaded part. The circle at
each end follows its own sign.

**Example 5.** Draw the solution set of $-1<x\leq3$.

The left endpoint is $-1$ with an open circle, because the sign is $<$. The right
endpoint is 3 with a closed circle, because the sign is $\leq$. Shade the part between
them.

**Example 6.** Draw the solution set of $1\leq x<4$.

The circle at 1 is closed, and the circle at 4 is open. Shade between them.

To solve an inequality like this, do the same operation to all three parts.

**Example 7.** Solve and draw $3\leq2x+1<9$.

Subtract 1 from all three parts, and then divide all three by 2.

$$2\leq2x<8 \qquad 1\leq x<4$$

The circle at 1 is closed, and the circle at 4 is open.

## Whole numbers, integers and real numbers

The set the letter belongs to changes the picture.

- For **real numbers**, every value is allowed, so the shading is a solid line.
- For **whole numbers** and **integers**, only the marked values are allowed, so the
  graph is a row of dots.

**Example 8.** Draw the solution set of $n\geq207$ for $n$ a whole number.

A whole number cannot be 206.25, so the first whole number that works is 207. The graph
is a dot at 207, a dot at 208, a dot at 209, and so on to the right. The dot at 207 is
filled, because 207 is included.

If $n$ were a real number instead, the boundary would be 206.25 and the graph would be a
solid line from 206.25 to the right.

> **Watch out.** An open circle and a closed circle mean different things, and the
> arrow shows the direction. In $x\leq4$, the common error is to draw an open circle at
> 4 and point the arrow right. The sign is $\leq$, so the circle is closed, and the
> solution set is smaller than 4, so the arrow points left.
>
> **Re-check:** test the endpoint in the inequality. If the endpoint makes the
> statement true, the circle is closed. Test a value on the arrow side as well, and make
> sure it works.

## Progress check

Return to the chapter problem. The inequality $8n-150\geq1500$ has the solution
$n\geq206.25$.

1. For whole numbers, what is the smallest value of $n$?
2. Is the dot at that value filled or open?
3. Draw the solution set for whole numbers, and then for real numbers.

## You should now be able to

- draw the solution set of an inequality on a number line;
- choose a closed circle for $\leq$ and $\geq$, and an open circle for $<$ and $>$;
- point the arrow towards the values in the solution set;
- show a solution set that lies between two endpoints;
- use dots for whole numbers and integers, and a solid line for real numbers.
