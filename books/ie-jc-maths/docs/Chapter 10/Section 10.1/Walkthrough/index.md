# 10.1 Generating and interpreting expressions — Learn

**Prerequisites:** the order of operations and brackets from Section 1.4, and the
general term of a linear pattern from Section 9.2.

**Objectives:** say what a letter stands for; write an expression from a rule in
words; name the parts of an expression; interpret what each part means in the
situation it came from.

By the end of this section, you can turn a rule in words into an expression, and
say what each number and letter in it means.

## Letters that stand for numbers

Algebra uses letters in place of numbers. The letter is called a **variable**,
because the number it stands for can change.

Think about the sponsored walk. The number of kilometres is not fixed. One walker
completes 5 km, another completes 8 km, and another completes 12 km. So give that
number a letter.

$$k = \text{the number of kilometres a walker completes}$$

Now the rule can be written once, and it works for every walker.

## What an expression is

An **expression** is a mathematical phrase built from numbers, letters and
operations. It has no equals sign.

$$5 + 2k$$

This expression is the payment from one sponsor. It has two **terms**, which are
the parts that are added together: the term $5$ and the term $2k$.

| Part | In $5+2k$ | What it means |
|---|---|---|
| variable | $k$ | the number of kilometres |
| coefficient | $2$ | the payment for each kilometre, in euro |
| constant | $5$ | the payment for taking part, in euro |

The **coefficient** is the number that multiplies the letter. The **constant** is
the term with no letter in it.

**Example 1.** A taxi charges €4 to start the journey and €2 for each kilometre.
Write an expression for the fare for $k$ kilometres.

The €4 is charged once, so it is the constant. The €2 is charged for each
kilometre, so it multiplies $k$.

$$4 + 2k$$

The fare is $4+2k$ euro.

## Writing an expression from words

Some words have a clear mathematical meaning. Read the sentence and decide which
operation it describes.

| Words | Expression |
|---|---|
| a number $n$ plus 7 | $n+7$ |
| 7 more than a number $n$ | $n+7$ |
| a number $n$ minus 5 | $n-5$ |
| 5 less than a number $n$ | $n-5$ |
| a number $n$ multiplied by 3 | $3n$ |
| three times a number $n$ | $3n$ |
| a number $n$ divided by 2 | $\frac{n}{2}$ |
| half of a number $n$ | $\frac{n}{2}$ |
| a number $n$ squared | $n^2$ |

**Example 2.** Write an expression for the cost of $n$ notebooks at €3 each.

Each notebook costs €3, so the cost is 3 times the number of notebooks.

$$3n$$

**Example 3.** A plumber charges €40 to call out and €25 for each hour of work.
Write an expression for the cost of $h$ hours.

$$40 + 25h$$

## Generating an expression from a pattern

A pattern in a table can also give an expression. The expression is the rule that
turns the figure number into the value.

**Example 4.** A row of squares is made from matchsticks. One square uses 4
matches, two squares use 7, and three squares use 10.

| Number of squares, $n$ | 1 | 2 | 3 | 4 |
|---|---|---|---|---|
| Number of matches | 4 | 7 | 10 | 13 |

Each new square adds 3 matches. That is the coefficient of $n$. To get from $3n$
to the first value, add 1.

$$3n + 1$$

Check it with $n=4$: $3\times4+1=13$, which matches the table.

> **Watch out.** The letter next to a number means multiply. So $3n$ means
> $3\times n$, and $5+2k$ means $5$ plus $2\times k$.
>
> The common error is to add the numbers first and write $5+2k=7k$. That is a
> different expression. With $k=10$, the correct expression gives $5+20=25$,
> while $7k$ gives $70$.
>
> **Re-check:** choose one value of the letter and work out both forms. If they
> disagree, the two expressions are not equal.

## Progress check

Return to the chapter problem. Each sponsor pays €5 to take part and €2 for every
kilometre.

1. Write an expression for what one sponsor pays when a walker completes $k$
   kilometres.
2. Say what the $5$ and the $2$ mean in the walk.

Keep your expression. In Section 10.2 you will put a number into it.

## You should now be able to

- say what the letter stands for in an expression;
- name the terms, the coefficient and the constant;
- write an expression from a rule in words;
- build an expression from a table or a pattern;
- check an expression by substituting one value.
