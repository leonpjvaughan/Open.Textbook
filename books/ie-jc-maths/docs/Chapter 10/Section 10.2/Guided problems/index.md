# 10.2 Substituting values into expressions — Practise with help

## Warm-up: remember

1. Work out $(-3)^2$.
2. Work out $2 + 5 \times 3$.

<details markdown="1">
<summary>Answers and feedback</summary>

1. $9$, because $(-3)\times(-3)=9$. The square of a negative number is positive.
2. $17$. Multiplication goes first: $5\times3=15$, and then $2+15=17$.

Both rules return in every substitution in this section. The order of operations
decides what to work out first, and the sign rule decides the sign of the answer.

</details>

## Practise with help

**1.** Find the value of $5+2k$ when $k=8$.

<details markdown="1">
<summary>Hint</summary>

Replace $k$ with 8. Multiply before you add.

<details markdown="1">
<summary>Next step</summary>

$$5 + 2\times8$$

<details markdown="1">
<summary>Full working</summary>

$$5 + 16 = 21$$

The value is 21. This is the payment from one sponsor when the walker completes
8 km.

</details>
</details>
</details>

**2.** Find the value of $3x-7$ when $x=4$.

<details markdown="1">
<summary>Hint</summary>

Replace $x$ with 4, and keep the subtraction outside the multiplication.

<details markdown="1">
<summary>Next step</summary>

$$3\times4 - 7$$

<details markdown="1">
<summary>Full working</summary>

$$12 - 7 = 5$$

The value is 5. The multiplication happens before the subtraction, because the
$3x$ is one term.

</details>
</details>
</details>

**3.** Find the value of $x^2+2x$ when $x=5$.

<details markdown="1">
<summary>Hint</summary>

Work out the index first.

<details markdown="1">
<summary>Next step</summary>

$$5^2 + 2\times5$$

<details markdown="1">
<summary>Full working</summary>

$$25 + 10 = 35$$

The value is 35. The index applies to the $x$ alone, so $x^2$ is $25$ and $2x$
is $10$.

</details>
</details>
</details>

**4.** Find the value of $x^2+2x$ when $x=-3$.

<details markdown="1">
<summary>Hint</summary>

Put the $-3$ in brackets when you substitute it.

<details markdown="1">
<summary>Next step</summary>

$$(-3)^2 + 2\times(-3)$$

<details markdown="1">
<summary>Full working</summary>

$$9 - 6 = 3$$

The value is 3. The square of a negative number is positive, because
$(-3)\times(-3)=9$. The second term is negative, so it is subtracted.

</details>
</details>
</details>

**5.** Find the value of $2a+3b$ when $a=4$ and $b=-2$.

<details markdown="1">
<summary>Hint</summary>

Each letter gets its own number. Keep the sign with the number.

<details markdown="1">
<summary>Next step</summary>

$$2\times4 + 3\times(-2)$$

<details markdown="1">
<summary>Full working</summary>

$$8 - 6 = 2$$

The value is 2. The first term is $8$ and the second is $-6$, so the two terms
partly cancel.

</details>
</details>
</details>

**6.** Find the value of $10+0.05m$ when $m=240$.

<details markdown="1">
<summary>Hint</summary>

A decimal substitutes in the same way as a whole number.

<details markdown="1">
<summary>Next step</summary>

$$10 + 0.05\times240$$

<details markdown="1">
<summary>Full working</summary>

$$10 + 12 = 22$$

The value is 22. This is the cost in euro of 240 minutes on the phone plan.

</details>
</details>
</details>

**7.** Find the value of $3a^2$ when $a=4$.

<details markdown="1">
<summary>Hint</summary>

The index sits next to the $a$, so only the $a$ is squared.

<details markdown="1">
<summary>Next step</summary>

$$3\times4^2$$

<details markdown="1">
<summary>Full working</summary>

$$3\times16 = 48$$

The value is 48. Compare $(3\times4)^2=144$, which is what you get if you square
the whole of $3a$. The index applies to $a$ alone.

</details>
</details>
</details>

**8.** Find the value of $4y-2$ when $y=2.5$.

<details markdown="1">
<summary>Hint</summary>

Multiply first, and then subtract.

<details markdown="1">
<summary>Next step</summary>

$$4\times2.5 - 2$$

<details markdown="1">
<summary>Full working</summary>

$$10 - 2 = 8$$

The value is 8. Multiplying by 4 doubles 2.5 twice: $4\times2.5=10$.

</details>
</details>
</details>

## A question from an earlier section

**9.** A school fair charges €6 for each ticket plus €4 for booking. Write an
expression for the cost of $n$ tickets, and find the cost of 5 tickets.

<details markdown="1">
<summary>Hint</summary>

From Section 10.1: the booking fee happens once, and the €6 happens for each
ticket.

<details markdown="1">
<summary>Next step</summary>

The expression is $6n+4$. Now substitute $n=5$.

<details markdown="1">
<summary>Full working</summary>

$$6n+4 = 6\times5+4 = 30+4 = 34$$

The cost of 5 tickets is €34. The €4 is charged once, and the €6 is charged five
times.

</details>
</details>
</details>
