# 10.2 Substituting values into expressions — Learn

**Prerequisites:** writing an expression from words from Section 10.1, and the
order of operations with negative numbers from Sections 1.2 and 1.4.

**Objectives:** replace a letter with a number; work out the value with the order
of operations; substitute a negative number or a decimal; work out an expression
that contains an index.

By the end of this section, you can find the value of an expression for any value
of the letter.

## Substituting a value

To **substitute** means to replace a letter with a number. Then you work out the
value of the expression by following the order of operations.

**Example 1.** Find the value of $5+2k$ when $k=8$.

$$5 + 2\times8 = 5 + 16 = 21$$

The value is 21. This is the payment from one sponsor when the walker completes
8 km.

**Example 2.** Find the value of $3x-7$ when $x=4$.

$$3\times4 - 7 = 12 - 7 = 5$$

**Example 3.** A phone plan costs €10 a month plus €0.05 for each minute. The
cost is $10+0.05m$ euro for $m$ minutes. Find the cost when $m=240$.

$$10 + 0.05\times240 = 10 + 12 = 22$$

The cost is €22.

## Working out an index first

An index tells you how many copies of a number to multiply. Work out the index
before the operations around it.

**Example 4.** Find the value of $x^2+2x$ when $x=5$.

$$5^2 + 2\times5 = 25 + 10 = 35$$

**Example 5.** Find the value of $3a^2$ when $a=4$.

$$3\times4^2 = 3\times16 = 48$$

The index applies to the $a$ alone. So $3a^2$ means $3\times(a^2)$, not
$(3a)^2$. Compare $(3\times4)^2=144$, which is a different value.

## Substituting a negative number

Put a negative number in brackets when you substitute it. The brackets keep the
sign attached to the number.

**Example 6.** Find the value of $x^2+2x$ when $x=-3$.

$$(-3)^2 + 2\times(-3) = 9 - 6 = 3$$

The square of a negative number is positive, because $(-3)\times(-3)=9$.

**Example 7.** Find the value of $4y-2$ when $y=-1$.

$$4\times(-1) - 2 = -4 - 2 = -6$$

## An expression with two letters

Substitute each letter with its own number.

**Example 8.** Find the value of $2a+3b$ when $a=4$ and $b=-2$.

$$2\times4 + 3\times(-2) = 8 - 6 = 2$$

> **Watch out.** A negative number without brackets changes the meaning. The
> expression $x^2$ with $x=-3$ is $(-3)^2=9$. If you write $-3^2$, the index
> applies only to the 3, and the value is $-9$.
>
> **Re-check:** write the number in brackets as soon as you substitute it. The
> brackets keep the minus sign inside the power.

## Progress check

Return to the chapter problem. A sponsor pays $5+2k$ euro when the walker
completes $k$ kilometres.

1. Substitute $k=8$ and work out the value.
2. Look back at the prediction you wrote at the start of the chapter. Is the
   payment for 8 km above or below €25?

In Section 10.3 you will write an equation for the €25 and find the distance that
gives it.

## You should now be able to

- replace a letter with a number and work out the value;
- work out an index before the operations around it;
- substitute a negative number or a decimal correctly;
- substitute into an expression with two letters.
