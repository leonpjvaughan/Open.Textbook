# 10.3 Equality and the meaning of an equation — Practise with help

## Warm-up: remember

1. Work out $5 + 2 \times 6$.
2. Work out $4 \times 7$ and $30 - 2$. Are the two values equal?

<details markdown="1">
<summary>Answers and feedback</summary>

1. $17$. Multiplication goes first: $2\times6=12$, and then $5+12=17$.
2. $4\times7=28$ and $30-2=28$. The two values are equal, so you can write
   $4\times7=30-2$.

The second one is the whole idea of this section. Two expressions can have the
same value, and the equals sign is how you say so.

</details>

:::figure warm-up-gate


## Practise with help

**1.** Find the value of $x$ that makes $x+6=15$ true.

<details markdown="1">
<summary>Hint</summary>

Which number, with 6 added, gives 15? Test a few values.

<details markdown="1">
<summary>Next step</summary>

Try $x=8$: $8+6=14$, which is too small. Try $x=10$: $10+6=16$, which is too
big.

<details markdown="1">
<summary>Full working</summary>

$$x = 9$$

Test it: $9+6=15$, which equals the right side. So $x=9$ is a solution.

</details>
</details>
</details>

**2.** Is $x=3$ a solution of $4x-5=23$?

<details markdown="1">
<summary>Hint</summary>

Substitute $x=3$ into the left side, and compare with 23.

<details markdown="1">
<summary>Next step</summary>

$$4\times3 - 5$$

<details markdown="1">
<summary>Full working</summary>

The left side is $12-5=7$, and the right side is 23. Since $7$ is not $23$,
$x=3$ is not a solution.

</details>
</details>
</details>

**3.** Is $x=7$ a solution of $4x-5=23$?

<details markdown="1">
<summary>Hint</summary>

Substitute $x=7$ into the left side, and compare with 23.

<details markdown="1">
<summary>Next step</summary>

$$4\times7 - 5$$

<details markdown="1">
<summary>Full working</summary>

The left side is $28-5=23$, which equals the right side. So $x=7$ is a solution.

Compare this with question 2. The same equation gives a false statement for
$x=3$ and a true one for $x=7$.

</details>
</details>
</details>

**4.** Find the value of $n$ that makes $3n=21$ true.

<details markdown="1">
<summary>Hint</summary>

Which number, multiplied by 3, gives 21? Test values around 7.

<details markdown="1">
<summary>Next step</summary>

Try $n=5$: $3\times5=15$, which is too small. Try $n=8$: $3\times8=24$, which is
too big.

<details markdown="1">
<summary>Full working</summary>

$$n = 7$$

Test it: $3\times7=21$, which equals the right side.

</details>
</details>
</details>

**5.** A club sells tickets for €12 each and charges €5 for booking. The cost is
$12n+5$ euro for $n$ tickets. The club spends €101. Write an equation, and find
the number of tickets.

<details markdown="1">
<summary>Hint</summary>

The cost is 101, so the expression equals 101.

<details markdown="1">
<summary>Next step</summary>

The equation is $12n+5=101$. Try $n=7$: $12\times7+5=89$. Try $n=9$:
$12\times9+5=113$.

<details markdown="1">
<summary>Full working</summary>

$$12n+5 = 101$$

Try $n=8$: $12\times8+5=96+5=101$, which is true. So $n=8$, and the club bought
8 tickets.

</details>
</details>
</details>

**6.** Is $n=5$ a solution of $3n+4=19$?

<details markdown="1">
<summary>Hint</summary>

Substitute $n=5$, and work out the left side.

<details markdown="1">
<summary>Next step</summary>

$$3\times5 + 4$$

<details markdown="1">
<summary>Full working</summary>

The left side is $15+4=19$, which equals the right side. So $n=5$ is a solution.

</details>
</details>
</details>

**7.** Is $x=2$ a solution of $x^2+1=5$?

<details markdown="1">
<summary>Hint</summary>

Work out the index first, and then add 1.

<details markdown="1">
<summary>Next step</summary>

$$2^2 + 1$$

<details markdown="1">
<summary>Full working</summary>

The left side is $4+1=5$, which equals the right side. So $x=2$ is a solution.

</details>
</details>
</details>

**8.** A plumber charges $40+25h$ euro for $h$ hours. The bill is €165. Write an
equation, and find $h$.

<details markdown="1">
<summary>Hint</summary>

The cost is 165, so the expression equals 165.

<details markdown="1">
<summary>Next step</summary>

The equation is $40+25h=165$. Start by taking 40 from 165.

<details markdown="1">
<summary>Full working</summary>

$$40 + 25h = 165$$

Test $h=4$: $40+25\times4=140$, which is too small. Test $h=6$:
$40+25\times6=190$, which is too big. Test $h=5$: $40+25\times5=40+125=165$,
which is true.

So $h=5$, and the plumber worked 5 hours.

</details>
</details>
</details>
