# 10.3 Equality and the meaning of an equation — Learn

**Prerequisites:** writing an expression from words from Section 10.1, and
substituting a value into an expression from Section 10.2.

**Objectives:** say what the equals sign means; tell an expression from an
equation; write an equation from a rule in words; test whether a value makes an
equation true; find the value that does.

By the end of this section, you can build an equation for a situation and find
the value that makes it true.

## What the equals sign says

The sign $=$ says that the two sides have the same value. It is a statement of
balance, like a scale with equal weights on each side.

$$3 + 4 = 7$$

The left side and the right side are both 7, so the statement is true.

$$3 + 4 = 8$$

This statement is false, because the two sides do not have the same value.

## Expression or equation

An **expression** has no equals sign. An **equation** has one, and it states that
two expressions are equal.

| | Example | What it is |
|---|---|---|
| expression | $5+2k$ | a rule that gives a value when you choose $k$ |
| equation | $5+2k=25$ | a statement that the rule gives 25 for some value of $k$ |

An expression has a value for every value of the letter. An equation is true only
for particular values of the letter.

## Building an equation from words

An equation comes from a sentence that says two amounts are equal.

**Example 1.** A number $x$ plus 6 equals 15.

$$x + 6 = 15$$

**Example 2.** Three times a number $n$ is 24.

$$3n = 24$$

**Example 3.** The chapter problem. A sponsor pays $5+2k$ euro, and the class
wants one sponsor to pay €25.

$$5 + 2k = 25$$

## Testing a value

A **solution** of an equation is a value that makes the equation true. To test a
value, substitute it into the left side and work out the value. Then compare that
value with the right side.

**Example 4.** Is $k=8$ a solution of $5+2k=25$?

Left side: $5+2\times8 = 21$. Right side: $25$. Since $21$ is not $25$, the value
$k=8$ is not a solution.

**Example 5.** Is $k=10$ a solution of $5+2k=25$?

Left side: $5+2\times10 = 25$. Right side: $25$. Since the two sides are equal,
the value $k=10$ is a solution.

## Finding the value by testing

If you do not know the value, try a few numbers and test each one. Start from a
sensible estimate, and move towards the right answer.

**Example 6.** Find the value of $n$ that makes $3n=21$ true.

Try $n=5$: $3\times5=15$, which is too small.

Try $n=8$: $3\times8=24$, which is too big.

Try $n=7$: $3\times7=21$, which is true.

$$n = 7$$

> **Watch out.** The equals sign does not mean "the answer comes next". It says
> that the two sides have the same value, so every line must stay balanced.
>
> The common error is to chain the working through one equals sign, like
> $5+2k=25=10$. The first statement says the payment is 25, and the second says
> 25 is 10, which is false.
>
> **Re-check:** write one equation per line, and test your value in the original
> equation.

## Progress check

Return to the chapter problem. The class wants one sponsor to pay €25, and a
sponsor pays $5+2k$ euro.

1. Write the equation for this situation.
2. Test $k=8$. Is it a solution?
3. Test $k=10$. Is it a solution?

The Review brings the distance, the expression and the equation together.

## You should now be able to

- say what the equals sign means;
- tell an expression from an equation;
- write an equation from a sentence;
- test whether a value is a solution;
- find a solution by testing values.
