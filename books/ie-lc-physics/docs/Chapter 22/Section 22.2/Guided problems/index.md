# 22.2 Researching from secondary sources — Practise with help

## Warm-up: remember

1. State the difference between a scientific model and the thing it describes.
2. A voltage is written as 4.2 V. State the unit and name an instrument that
   would read it.

<details markdown="1">
<summary>Answers and feedback</summary>

1. A model is a simplified representation. It keeps the features that matter for
   the question and leaves out the rest, so it is never the real thing. The
   falling-ball model keeps gravity and leaves out the air.
2. The unit is the volt, V. A voltmeter reads it. A reading is a number, a unit
   and an uncertainty, so the unit is part of the measurement.

Both ideas return here. A source is a model of somebody else's measurement, and a
number without its unit cannot be used.

</details>

## Practise with help

**1.** A student finds two sources about the efficiency of a solar cell. Source A
is a data sheet from the company that makes the cell. Source B is a report from a
university laboratory. Which is more reliable, and why?

<details markdown="1">
<summary>Hint</summary>

Ask who wrote each source and what they gain from the result.

<details markdown="1">
<summary>Next step</summary>

The company sells the cell. The laboratory does not.

<details markdown="1">
<summary>Full working</summary>

Source B is more reliable. The university laboratory has no product to sell, so it
has no reason to favour a high value. The company's data sheet is exact about its
own cell, and it is the maker's own test.

The two together are more useful than either alone. Use the independent value as
the evidence, and report the maker's value beside it.

</details>
</details>
</details>

**2.** A website claims that a device "saves up to 45% of the energy used". State
two signs that this claim is weak.

<details markdown="1">
<summary>Hint</summary>

Look at the words "up to", and at what the website is selling.

<details markdown="1">
<summary>Next step</summary>

A best-case figure is not a typical one, and a seller has a reason to favour its
own product.

<details markdown="1">
<summary>Full working</summary>

The claim is weak for two reasons. First, "up to 45%" gives the best of several
results, not the typical saving, so it overstates what most users would see.
Second, the site sells the device, so it has a reason to select the flattering
test.

A stronger version of the claim would name the number of homes tested, the period
of the test and the typical saving. Without those, the number cannot be checked.

</details>
</details>
</details>

**3.** State the difference between primary data and secondary data, and give one
example of each.

<details markdown="1">
<summary>Hint</summary>

The difference is who takes the reading.

<details markdown="1">
<summary>Next step</summary>

Your own reading is primary. A table in a book is secondary.

<details markdown="1">
<summary>Full working</summary>

Primary data are readings you take yourself, such as a voltage you measure with a
voltmeter. Secondary data are readings that somebody else took, such as a table in
a textbook.

The research phase of the investigation works on secondary data. The experiment
phase produces primary data.

</details>
</details>
</details>

**4.** A manufacturer quotes an efficiency of 25%, and an independent test finds
20%. Taking the manufacturer's value as the reference, calculate the percentage
difference.

<details markdown="1">
<summary>Hint</summary>

Find the difference first, then divide by the reference value and multiply by 100.

<details markdown="1">
<summary>Next step</summary>

The difference is $25\% - 20\% = 5\%$, and the reference value is 25%.

<details markdown="1">
<summary>Full working</summary>

$$\text{percentage difference} = \frac{25 - 20}{25} \times 100\% = \frac{5}{25} \times 100\% = 20\%$$

The two values differ by 20% of the reference value. A difference that large is
worth reporting, and it is a reason to look at how each value was obtained.

</details>
</details>
</details>

**5.** A data sheet quotes the power of a lamp as 0.80 kW. Convert it to watts.

<details markdown="1">
<summary>Hint</summary>

The prefix kilo means a thousand.

<details markdown="1">
<summary>Next step</summary>

Multiply by 1000.

<details markdown="1">
<summary>Full working</summary>

$$0.80\,\text{kW} = 0.80 \times 1000 = 800\,\text{W}$$

A unit conversion is part of using a source honestly. If you quote a value in
watts, the reader knows what you measured without doing the conversion.

</details>
</details>
</details>

**6.** A student wants to use a source but cannot find its date. Explain why this
matters, and say what the student should do.

<details markdown="1">
<summary>Hint</summary>

Think about whether the value in the source still describes the world.

<details markdown="1">
<summary>Next step</summary>

A device or a fuel mix can change, so an old value may no longer be right.

<details markdown="1">
<summary>Full working</summary>

The date matters because a measurement describes the world at the time it was
taken. A value for the efficiency of a device may be out of date if the device has
changed, and a value for the cost of electricity changes every year.

The student should look for a dated source, or find the same value in a source
that gives its date. If no dated source exists, the value can still be mentioned,
but the report must say that its date is unknown.

</details>
</details>
</details>

## A question from Chapter 1

**7.** A source states that the acceleration of free fall is 9.8 m/s$^2$. State
the quantity, its unit and the prefix meaning of the unit, and say whether this is
primary or secondary data for a student who has not measured it.

<details markdown="1">
<summary>Hint</summary>

Name the quantity, then break the unit into its parts.

<details markdown="1">
<summary>Next step</summary>

The unit is metres per second squared. The student has not taken the reading.

<details markdown="1">
<summary>Full working</summary>

The quantity is acceleration, and its unit is metres per second squared,
m/s$^2$. The unit is built from the metre and the second, and it has no prefix.

For a student who has not measured it, the value is secondary data, because
somebody else took the reading. It is still useful, as a value to compare their own
measurement against. If the student measures the fall themselves, that reading is
primary data.

</details>
</details>
</details>
