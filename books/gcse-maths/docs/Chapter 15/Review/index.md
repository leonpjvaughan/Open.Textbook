# Chapter 15: Review

## The chapter problem, solved

The first machine is $f(x)=2x+3$. The second is $g(x)=\frac{x-3}{2}$.
For input $4$, the first then second gives

$$
g(f(4))=g(11)=4.
$$

The second then first also gives

$$
f(g(4))=f(0.5)=4.
$$

These two rules are inverses, so each undoes the other. In general,
$g(f(x))=x$ and $f(g(x))=x$.
