# 14.4 Linear and quadratic simultaneous equations — Practise with help

Work each question first. Open a hint if you need one, then reveal the working to check your method.

## Warm-up: remember

Answer these from memory. Do not look back at the section.

1. Expand $(x+2)(x-3)$.
2. Solve $x^2-4=0$.

<details markdown="1">
<summary>Answers</summary>

1. $x^2-x-6$.
2. $x=2$ or $x=-2$.

If an answer differs, revisit Section 8.3 for expanding brackets and Section 12.4 for solving quadratics.

</details>
## Practise with help

**1.** Solve $x+y=9$ and $x-y=3$.

<details markdown="1"><summary>Hint</summary>
Add the equations to remove $y$.
</details>
<details markdown="1"><summary>Full working</summary>
$2x=12$, so $x=6$. Then $y=3$. Check both equations.
</details>

**2.** Solve $y=2x+1$ and $x+y=10$.

<details markdown="1"><summary>Hint</summary>
Replace $y$ in the second equation.
</details>
<details markdown="1"><summary>Full working</summary>
$x+2x+1=10$, so $x=3$ and $y=7$.
</details>

**3.** Solve $y=x+2$ and $y=x^2-2x-3$.

<details markdown="1"><summary>Hint</summary>
Set the two expressions for $y$ equal, then factorise.
</details>
<details markdown="1"><summary>Full working</summary>
$x+2=x^2-2x-3$ gives $x^2-3x-5=0$. Solve this quadratic, then use $y=x+2$ for each root.
</details>
