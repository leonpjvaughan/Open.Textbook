# 11.4 Parallel and perpendicular lines — Practise with help

Try each question before opening its hint.

## Warm-up: remember

1. State the gradient of $y=2x+3$. 2. Work out $-1+4$.

<details markdown="1"><summary>Check your answers</summary>

Answers: 2; 3.
</details>

## Practise with help

**1.** Give the gradient parallel to $y=3x+2$.

<details markdown="1"><summary>Hint</summary>Parallel lines have equal gradients.</details>
<details markdown="1"><summary>Next step</summary>Read the coefficient of $x$.</details>
<details markdown="1"><summary>Full working</summary>3.</details>

**2.** Give the gradient perpendicular to $y=2x-1$.

<details markdown="1"><summary>Hint</summary>Use $-1/m$.</details>
<details markdown="1"><summary>Next step</summary>Calculate $-1/2$.</details>
<details markdown="1"><summary>Full working</summary>The gradient is $-1/2$.</details>

**3.** Earlier learning: solve $2x+3=11$. Then state a gradient parallel to $y=2x-9$.

<details markdown="1"><summary>Hint</summary>Use inverse operations, then compare gradients.</details>
<details markdown="1"><summary>Next step</summary>Subtract 3 and divide by 2; parallel gradients are equal.</details>
<details markdown="1"><summary>Full working</summary>$x=4$; the parallel gradient is 2.</details>
