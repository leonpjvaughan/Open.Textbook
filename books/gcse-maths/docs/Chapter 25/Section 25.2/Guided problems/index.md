# 25.2 Cumulative frequency — Practise with help

## Warm-up: remember

1. Find the median of $2,4,6,8,10$.
2. Add frequencies $3,7,4$.

<details markdown="1"><summary>Feedback</summary>

1. $6$. 2. $14$.
</details>

:::figure warm-up-gate


## Practise with help

Use this table: classes $0<t\leq5$, $5<t\leq10$, $10<t\leq15$ have frequencies $3,6,5$.

**1.** Find the cumulative frequency at each upper boundary.

<details markdown="1"><summary>Hint</summary>

Keep a running total, starting from the first frequency.
</details>

<details markdown="1"><summary>Next step</summary>

The totals are $3$, then $3+6$, then $3+6+5$.
</details>

<details markdown="1"><summary>Full working</summary>

The cumulative frequencies are $3,9,14$.
</details>

**2.** State the coordinates to plot, including the starting point.

<details markdown="1"><summary>Hint</summary>

Pair each upper boundary with its cumulative frequency.
</details>

<details markdown="1"><summary>Next step</summary>

Start at $(0,0)$, then use boundaries $5,10,15$.
</details>

<details markdown="1"><summary>Full working</summary>

Plot $(0,0),(5,3),(10,9),(15,14)$, then draw a smooth increasing curve.
</details>

**3.** Earlier work: the frequencies are $3,6,5$. Which class has the greatest frequency?

<details markdown="1"><summary>Hint</summary>

Compare the three frequencies, not their running totals.
</details>

<details markdown="1"><summary>Next step</summary>

The largest frequency is $6$.
</details>

<details markdown="1"><summary>Full working</summary>

The class $5<t\leq10$ has the greatest frequency, $6$.
</details>
