# 13.1 Cubic, reciprocal and exponential graphs — Practise with help

Try each question first. Open one level at a time when you need support.

## Warm-up: remember

1. Factorise $x^2-9$.
2. Work out $2^3$.
3. Give the coordinates of the $y$-intercept of $y=3x+2$.
4. Solve $x^2-9=0$.

<details markdown="1">
<summary>Answers</summary>

$ (x-3)(x+3)$; $8$; $(0,2)$; $x=-3$ or $x=3$.
</details>

## Practise with help

**1.** Find the intercepts of $y=x^3-4x$.

<details markdown="1"><summary>Hint</summary>

Set $y=0$ and factor out $x$.
</details>
<details markdown="1"><summary>Next step</summary>

$x(x^2-4)=0$, then factor the difference of squares.
</details>
<details markdown="1"><summary>Full working</summary>

$x(x-2)(x+2)=0$, so $x=-2,0,2$. The intercepts are $(-2,0),(0,0),(2,0)$.
</details>

**2.** For $y=1/x$, find the outputs at $x=-2$ and $x=2$. State the asymptotes.

<details markdown="1"><summary>Hint</summary>

Substitute each input. Consider what happens when the input or output is zero.
</details>
<details markdown="1"><summary>Next step</summary>

$1/(-2)=-1/2$ and $1/2=1/2$.
</details>
<details markdown="1"><summary>Full working</summary>

The outputs are $-1/2$ and $1/2$. The asymptotes are $x=0$ and $y=0$.
</details>

**3.** For $y=2^x$, find the output at $x=-1,0,1,2$. Describe the pattern.

<details markdown="1"><summary>Hint</summary>

Substitute the four inputs. Recall that a negative index gives a reciprocal.
</details>
<details markdown="1"><summary>Next step</summary>

Evaluate $2^{-1},2^0,2^1,2^2$.
</details>
<details markdown="1"><summary>Full working</summary>

The outputs are $1/2,1,2,4$. Each unit step right doubles the output.
</details>

**4.** A line graph has value $5$ at $x=0$. Which point is its $y$-intercept? How does this help you recognise the exponential graph $y=2^x$?

<details markdown="1"><summary>Hint</summary>

The $y$-intercept occurs when $x=0$.
</details>
<details markdown="1"><summary>Next step</summary>

Write the point as $(0,5)$, then substitute zero into $2^x$.
</details>
<details markdown="1"><summary>Full working</summary>

The intercept is $(0,5)$. The graph $y=2^x$ instead passes through $(0,1)$ because $2^0=1$.
</details>
