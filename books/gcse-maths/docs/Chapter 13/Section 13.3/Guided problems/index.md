# 13.3 Transformations of graphs — Practise with help

Try each question before opening a hint. Move through the steps in order.

## Warm-up: remember

1. Find $f(2)$ if $f(x)=x^2$.
2. State the $y$-intercept of $y=x+3$.
3. Give the image of $(1,4)$ after moving it two units up.
4. Expand $(x+2)^2$.

<details markdown="1"><summary>Answers</summary>

$4$; $(0,3)$; $(1,6)$; $x^2+4x+4$.
</details>

## Practise with help

**1.** Translate $y=x^2$ two units right.

<details markdown="1"><summary>Hint</summary>

For a right shift, replace $x$ with $x-2$.
</details>
<details markdown="1"><summary>Next step</summary>

Substitute $x-2$ wherever the original rule has $x$.
</details>
<details markdown="1"><summary>Full working</summary>

The new rule is $y=(x-2)^2$.
</details>

**2.** Starting with $y=x^2$, move the graph two units right and three units down.

<details markdown="1"><summary>Hint</summary>

Make the horizontal change inside the brackets and the vertical change outside.
</details>
<details markdown="1"><summary>Next step</summary>

First write $(x-2)^2$, then subtract three.
</details>
<details markdown="1"><summary>Full working</summary>

$y=(x-2)^2-3$. The turning point is $(2,-3)$.
</details>

**3.** Reflect $y=f(x)$ in the $x$-axis.

<details markdown="1"><summary>Hint</summary>

Change the sign of every output.
</details>
<details markdown="1"><summary>Next step</summary>

Write the new output as $-f(x)$.
</details>
<details markdown="1"><summary>Full working</summary>

The reflected rule is $y=-f(x)$.
</details>

**4.** A point $(2,5)$ lies on $y=f(x)$. Find its image under reflection in the $x$-axis.

<details markdown="1"><summary>Hint</summary>

Keep the input fixed and change the sign of the output.
</details>
<details markdown="1"><summary>Next step</summary>

The new output is $-5$.
</details>
<details markdown="1"><summary>Full working</summary>

The image is $(2,-5)$, because the input stays fixed and the output changes sign.
</details>
