# 9.5 Solving linear inequalities — Practise with help

## Warm-up: remember

1. Solve $2x=18$.
2. Work out $3(4+2)$.

**3.** Solve $-3x\geq12$.

<details markdown="1">
<summary>Hint</summary>

Divide by negative 3 and reverse the sign.
</details>

<details markdown="1">
<summary>Next step</summary>

Try the first operation or write the equation before opening the full solution.
</details>

<details markdown="1">
<summary>Full working</summary>

</details>

**4.** Solve $4x-5<7$.

<details markdown="1">
<summary>Hint</summary>

Add 5, then divide by 4.
</details>

<details markdown="1">
<summary>Next step</summary>

Try the first operation or write the equation before opening the full solution.
</details>

<details markdown="1">
<summary>Full working</summary>

</details>
