# 12.3 Quadratic graphs and their features — Practise with help

## Warm-up: remember

Answer these from earlier chapters before you continue. Then open the answers and check your work.

1. Solve $3x+8=20$.
2. Simplify $2^3\times2^4$.

<details markdown="1">
<summary>Answers</summary>

1. $x=4$. Substitution gives $3(4)+8=20$.
2. $2^7=128$. Add the powers when multiplying powers with the same base.
</details>

## Practise with help

**1.** For $y=x^2-1$, find the roots.

<details markdown="1">
<summary>Hint</summary>

Set $y=0$ and solve $x^2-1=0$.
</details>

<details markdown="1">
<summary>Next step</summary>

Use the hint to write the next algebra line. Then finish the calculation before opening the full working.
</details>

<details markdown="1">
<summary>Full working</summary>

$(x-1)(x+1)=0$, so the roots are $x=1$ and $x=-1$.
</details>

**Choose a method:** factorise $x^2+7x+10$. Which method applies, and why?

<details markdown="1">
<summary>Full working</summary>

Factorisation applies because the expression is a monic quadratic with integer factors: $x^2+7x+10=(x+5)(x+2)$.
</details>
