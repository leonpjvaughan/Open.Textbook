# 4.2 Adding and subtracting fractions — Practise with help

## Warm-up: remember

Answer from memory before checking.

1. From Section 4.1, write $\frac{2}{5}$ with denominator $10$.
2. From Chapter 1, work out $7-12$.

<details markdown="1">
<summary>Answers</summary>

1. $\frac{4}{10}$.
2. $-5$.
</details>

## Practise with help

Try each question first. Reveal the hint, next step and full working in that order.

**1.** Work out $\frac{1}{3}+\frac{1}{6}$.

<details markdown="1">
<summary>Hint</summary>

Use denominator $6$.

<details markdown="1">
<summary>Next step</summary>

Set up the calculation using that idea.

<details markdown="1">
<summary>Full working</summary>

Rewrite $\frac{1}{3}=\frac{2}{6}$, then add: $\frac{3}{6}=\frac{1}{2}$.
</details>
</details>
</details>

**2.** Work out $\frac{5}{8}-\frac{1}{3}$.

<details markdown="1">
<summary>Hint</summary>

Use denominator $24$.

<details markdown="1">
<summary>Next step</summary>

Write the calculation before simplifying.

<details markdown="1">
<summary>Full working</summary>

Rewrite as $\frac{15}{24}-\frac{8}{24}=\frac{7}{24}$.
</details>
</details>
</details>

**3. Progress check.** Return to the keyboard prices. What fraction of £48 is the discount?

<details markdown="1">
<summary>Hint</summary>

Multiply the price by the discount fraction.

<details markdown="1">
<summary>Next step</summary>

Find one quarter of £48, then compare with £37.50.

<details markdown="1">
<summary>Full working</summary>

£48 divided by $4$ is £12. The discounted price is £48-£12=£36, which is £1.50 below £37.50.
</details>
</details>
</details>
