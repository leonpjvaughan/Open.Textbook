# 4.6 Fractions and percentages as operators — Practise with help

## Warm-up: remember

Answer from memory before checking.

1. From Section 4.3, work out $\frac{2}{3}$ of $30$.
2. From Section 4.4, write $0.25$ as a fraction.

<details markdown="1">
<summary>Answers</summary>

1. $20$.
2. $\frac{1}{4}$.
</details>

## Practise with help

Try each question first. Reveal the hint, next step and full working in that order.

**1.** Work out $\frac{2}{5}$ of £30.

<details markdown="1">
<summary>Hint</summary>

Find one fifth, then multiply by two.

<details markdown="1">
<summary>Next step</summary>

Set up the calculation using that idea.

<details markdown="1">
<summary>Full working</summary>

£30 divided by $5$ is £6; $2\times£6=£12$.
</details>
</details>
</details>

**2.** Work out $12\%$ of £50.

<details markdown="1">
<summary>Hint</summary>

Write $12\%$ as $\frac{12}{100}$.

<details markdown="1">
<summary>Next step</summary>

Write the calculation before simplifying.

<details markdown="1">
<summary>Full working</summary>

 $\frac{12}{100}\times50=£6$.
</details>
</details>
</details>

**3. Progress check.** The £48 keyboard has a $25\%$ discount. Work out the new price and compare it with £37.50.

<details markdown="1">
<summary>Hint</summary>

Find the multiplier for a $25\%$ decrease.

<details markdown="1">
<summary>Next step</summary>

Multiply £48 by the multiplier, then find the difference from £37.50.

<details markdown="1">
<summary>Full working</summary>

$48\times0.75=£36$. The first price is $£37.50-£36=£1.50$ lower.
</details>
</details>
</details>
