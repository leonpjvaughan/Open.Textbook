# 4.4 Fractions and terminating decimals — Practise with help

## Warm-up: remember

Answer from memory before checking.

1. From Section 4.1, write $\frac{3}{5}$ with denominator $10$.
2. From Chapter 1, write $0.4$ in tenths.

<details markdown="1">
<summary>Answers</summary>

1. $\frac{6}{10}$.
2. $4$ tenths.
</details>

## Practise with help

Try each question first. Reveal the hint, next step and full working in that order.

**1.** Write $\frac{3}{8}$ as a decimal.

<details markdown="1">
<summary>Hint</summary>

Make the denominator a power of ten.

<details markdown="1">
<summary>Next step</summary>

Set up the calculation using that idea.

<details markdown="1">
<summary>Full working</summary>

Multiply top and bottom by $125$: $\frac{3}{8}=\frac{375}{1000}=0.375$.
</details>
</details>
</details>

**2.** Write $0.24$ as a fraction in simplest form.

<details markdown="1">
<summary>Hint</summary>

Use denominator $100$.

<details markdown="1">
<summary>Next step</summary>

Write the calculation before simplifying.

<details markdown="1">
<summary>Full working</summary>

 $0.24=\frac{24}{100}=\frac{6}{25}$.
</details>
</details>
</details>

**3. Progress check.** The discount is $\frac14=0.25$. What decimal multiplier gives the reduced price?

<details markdown="1">
<summary>Hint</summary>

Subtract $0.25$ from $1$.

<details markdown="1">
<summary>Next step</summary>

Multiply £48 by the remaining fraction.

<details markdown="1">
<summary>Full working</summary>

$1-0.25=0.75$, so the reduced price is $48\times0.75=£36$.
</details>
</details>
</details>
