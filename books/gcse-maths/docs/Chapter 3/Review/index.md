# Chapter 3: Review

## The chapter problem, solved

After 20 rounds, the file size is $2^{20}$. Split the power into two equal
groups of ten factors:

$$2^{20}=(2^{10})^2=1024^2=1\,048\,576$$

The size is $1,048,576$ units. It is about $1,000,000$ units and far from
$1,000$ units, so it is nearer one million. The estimate from 3.2 was
reasonable.

and give a reason for your choice.

2. Estimate $\sqrt{130}$ to the nearest whole number. Give a reason using two squares.

4. Simplify $(q^3)^2$. Explain why the indices multiply.

7. A rectangle has area $144\text{ cm}^2$. Work out its side length if it is a square.
