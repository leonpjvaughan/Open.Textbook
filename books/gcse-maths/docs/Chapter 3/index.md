# Chapter 3: Powers, roots and indices

## The chapter problem: the doubling file

### Repeated doubling

A computer file starts at 1 unit. In each round, its size doubles. After 20
rounds, predict whether its size is nearer one thousand or one million units.
You do not need an exact answer yet.

By the end of this chapter, you will use powers and index laws to find and
estimate the size.

## By the end of this chapter you will be able to

You will be able to:

- calculate powers and roots, including square roots and cube roots;
- estimate powers and roots by comparing with nearby known values;
- use index laws to simplify products, quotients and powers;
- work with zero, negative and fractional indices.

## Where it is used

Powers describe anything that grows or shrinks by a fixed multiplier. A
computer file doubles in size each round, and a population or a debt can grow by
a fixed percentage each year. Roots and index laws let engineers work back from
a measurement to the size that produced it, and they keep very large and very
small numbers manageable.
