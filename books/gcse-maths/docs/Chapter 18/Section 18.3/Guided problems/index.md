# 18.3 Enlargement with fractional and negative scale factors — Practise with help

Attempt these from memory before opening the answers. Then try each question before opening a hint.

## Warm-up: remember

Answer these from memory. Do not look back at the section.

1. Work out $\frac{1}{2}\times8$.
2. Work out $-2\times3$.

<details markdown="1">
<summary>Check the warm-up</summary>

2. $-6$.

If an answer differs, revisit Section 4.3 for multiplying fractions and Section 1.3 for negative numbers.

## Practise with help

**1.** Enlarge $(8,-6)$ by factor $\frac12$ about the origin.

<details markdown="1"><summary>Hint</summary>Multiply each coordinate by one half.</details>
<details markdown="1"><summary>Next step</summary>$(8\times\frac12,-6\times\frac12)=(4,-3)$.</details>
<details markdown="1"><summary>Full working</summary>The image is $(4,-3)$.</details>

**2.** Enlarge $(3,-2)$ by factor $-2$ about the origin.

<details markdown="1"><summary>Hint</summary>Multiply each coordinate by $-2$.</details>
<details markdown="1"><summary>Next step</summary>$(3\times-2,-2\times-2)=(-6,4)$.</details>
<details markdown="1"><summary>Full working</summary>The image is $(-6,4)$, on the opposite side of the origin.</details>

**3.** Earlier topic: solve $3x=18$.

<details markdown="1"><summary>Hint</summary>Use the inverse operation.</details>
<details markdown="1"><summary>Next step</summary>Divide both sides by $3$.</details>
<details markdown="1"><summary>Full working</summary>$x=6$.</details>
