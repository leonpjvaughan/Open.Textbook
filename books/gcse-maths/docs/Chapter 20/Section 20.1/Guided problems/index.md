# 20.1 Pythagoras' theorem — Practise with help

Try each problem first. Open a hint if you need it, then use the working to check your method.

## Warm-up: remember

Answer these from memory. Do not look back at the section.

1. Work out $9^2$.
2. Work out $\sqrt{144}$.

<details markdown="1"><summary>Answers</summary>

1. $81$. 2. $12$.

If an answer differs, revisit Section 3.1 for squares and Section 3.2 for
square roots.
</details>

## Practise with help

**1.** Find the hypotenuse for shorter sides 3 and 4.

<details markdown="1"><summary>Hint</summary>

Square both shorter sides and add.
</details>

<details markdown="1"><summary>Full working</summary>

c² = 3² + 4² = 25, so c = 5.
</details>

**2.** Find the missing leg when hypotenuse is 10 and other leg is 6.

<details markdown="1"><summary>Hint</summary>

The hypotenuse square is the total.
</details>

<details markdown="1"><summary>Full working</summary>

x² = 10² − 6² = 64, so x = 8.
</details>

**3.** A right triangle has legs 8 and 15. Find its hypotenuse.

<details markdown="1"><summary>Hint</summary>

Name the hypotenuse before substituting.
</details>

<details markdown="1"><summary>Full working</summary>

c² = 8² + 15² = 289, so c = 17.
</details>

Before opening each full working, name the method and explain which measurements led you to choose it.
