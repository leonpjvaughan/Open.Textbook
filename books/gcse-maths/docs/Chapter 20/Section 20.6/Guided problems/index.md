# 20.6 The sine rule — Practise with help

Try each problem first. Open a hint if you need it, then use the working to check your method.

## Warm-up: remember

1. Work out $3^2+4^2$.
2. State the sum of the angles in a triangle.

<details markdown="1"><summary>Answers</summary>

1. $25$. 2. $180^\circ$.
</details>

## Practise with help

**1.** In a triangle a=6, A=30°, B=90°. Find b.

<details markdown="1"><summary>Hint</summary>

Pair a with A.
</details>

<details markdown="1"><summary>Full working</summary>

b/sin90° = 6/sin30°, so b = 12.
</details>

**2.** Given a=8, A=30°, B=45°, find b.

<details markdown="1"><summary>Hint</summary>

Use the paired sides and angles.
</details>

<details markdown="1"><summary>Full working</summary>

b = 8 sin45°/sin30° = 8√2.
</details>

**3.** Given a=10, A=90°, b=5, find B.

<details markdown="1"><summary>Hint</summary>

Use inverse sine after forming the ratio.
</details>

<details markdown="1"><summary>Full working</summary>

sin B = 5/10, so B = 30°.
</details>

Before opening each full working, name the method and explain which measurements led you to choose it.
