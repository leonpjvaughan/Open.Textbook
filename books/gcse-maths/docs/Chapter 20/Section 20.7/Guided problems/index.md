# 20.7 The cosine rule — Practise with help

Try each problem first. Open a hint if you need it, then use the working to check your method.

## Practise with help

**1.** Two sides 3 and 4 include 90°. Find the third side.

<details markdown="1"><summary>Hint</summary>

Use the cosine rule with the included angle.
</details>

<details markdown="1"><summary>Full working</summary>

c² = 3² + 4² − 24 cos90° = 25, so c = 5.
</details>

**2.** Sides 5 and 6 include 60°. Find opposite side.

<details markdown="1"><summary>Hint</summary>

Substitute the included angle.
</details>

<details markdown="1"><summary>Full working</summary>

c² = 25 + 36 − 60 cos60° = 31; c = √31.
</details>

**3.** Sides 4, 5, 6. Find the angle opposite 6.

<details markdown="1"><summary>Hint</summary>

Rearrange cosine rule for cos C.
</details>

<details markdown="1"><summary>Full working</summary>

cos C = (16+25−36)/40 = 1/8; C ≈ 82.8°.
</details>

Before opening each full working, name the method and explain which measurements led you to choose it.
