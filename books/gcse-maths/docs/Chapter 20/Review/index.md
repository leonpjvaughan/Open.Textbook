# Chapter 20: Review

## The chapter problem, solved

The garden is $9$ m by $12$ m. The path is the hypotenuse of a right-angled triangle, with length $d$.

$$d^2=9^2+12^2$$

$$d^2=81+144=225$$

$$d=15\text{ m}$$

The estimate should have been near $15$ m. The result is longer than either side and shorter than going around two edges, so it is plausible.
