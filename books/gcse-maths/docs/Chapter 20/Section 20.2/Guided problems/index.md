# 20.2 Trigonometric ratios (SOHCAHTOA) — Practise with help

Try each problem first. Open a hint if you need it, then use the working to check your method.

## Warm-up: remember

Answer these from memory. Do not look back at the section.

1. Simplify $\frac{8}{12}$.
2. In a right-angled triangle, which side is opposite the right angle?

<details markdown="1"><summary>Answers</summary>

1. $\frac{2}{3}$. 2. The hypotenuse.

If an answer differs, revisit Section 4.1 for simplifying fractions and Section
20.1 for naming the sides of a right-angled triangle.
</details>

## Practise with help

**1.** Find the opposite side for hypotenuse 12 and angle 30°.

<details markdown="1"><summary>Hint</summary>

Use sine: opposite over hypotenuse.
</details>

<details markdown="1"><summary>Full working</summary>

sin 30° = x/12, so x = 6.
</details>

**2.** Find the adjacent side for hypotenuse 10 and angle 60°.

<details markdown="1"><summary>Hint</summary>

Use cosine.
</details>

<details markdown="1"><summary>Full working</summary>

cos 60° = x/10, so x = 5.
</details>

**3.** Opposite is 8 and adjacent is 15. Find the angle.

<details markdown="1"><summary>Hint</summary>

Use tangent, then inverse tangent.
</details>

<details markdown="1"><summary>Full working</summary>

tan θ = 8/15, so θ ≈ 28.1°.
</details>

Before opening each full working, name the method and explain which measurements led you to choose it.
