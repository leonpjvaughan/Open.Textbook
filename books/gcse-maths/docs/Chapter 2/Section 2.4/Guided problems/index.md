# 2.4 The product rule for counting — Practise with help

Try each question first. Open a hint if needed, then check the full working.

## Warm-up: remember

1. Work out $6\times8$.
2. How many outcomes are in this list: AB, AC, BA, BC?

<details markdown="1"><summary>Answers</summary>

1. $48$.
2. Four outcomes.
</details>

:::figure warm-up-gate


## Practise with help

**1.** A menu has 4 sandwiches and 3 drinks. How many sandwich-and-drink combinations are possible?

<details markdown="1"><summary>Hint</summary>

Each sandwich can pair with each drink.
</details>
<details markdown="1"><summary>Next step</summary>

There are 4 choices at the first stage and 3 at the second.
</details>
<details markdown="1"><summary>Full working</summary>

$4\times3=12$ combinations.
</details>

**2.** How many three-digit codes can be made from digits 0 to 5 if repetition is allowed?

<details markdown="1"><summary>Hint</summary>

Count choices for each position. Zero is allowed in the first position because this is a code.
</details>
<details markdown="1"><summary>Next step</summary>

Each position has 6 choices.
</details>
<details markdown="1"><summary>Full working</summary>

$6\times6\times6=216$ codes.
</details>

**3.** A two-digit number uses different digits chosen from 1 to 5. How many numbers are possible?

<details markdown="1"><summary>Hint</summary>

After choosing the tens digit, count the remaining choices.
</details>
<details markdown="1"><summary>Next step</summary>

There are 5 choices first and 4 choices second.
</details>
<details markdown="1"><summary>Full working</summary>

$5\times4=20$ numbers.
</details>
