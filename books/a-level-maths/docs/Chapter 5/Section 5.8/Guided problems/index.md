# 5.8 Addition and double-angle formulae — Practise with help

Write the angle as a sum or a difference of two special angles before you
substitute. For a double angle, choose the form of the formula that uses the
ratio you already have.

## Warm-up: remember

1. Write down the exact values of $\sin 45^\circ$, $\cos 45^\circ$ and
   $\sin 30^\circ$.
2. Write down the exact value of $\cos 30^\circ$.
3. Work out $1 - 2\left(\dfrac{1}{2}\right)^2$.

<details markdown="1">
<summary>Answers</summary>

1. $\sin 45^\circ = \dfrac{\sqrt{2}}{2}$, $\cos 45^\circ = \dfrac{\sqrt{2}}{2}$
   and $\sin 30^\circ = \dfrac{1}{2}$.
2. $\cos 30^\circ = \dfrac{\sqrt{3}}{2}$.
3. $1 - 2 \times \dfrac{1}{4} = 1 - \dfrac{1}{2} = \dfrac{1}{2}$.

If question 2 was hard, revisit the exact values before you continue.
</details>

## Practise with help

**1.** Use the addition formula to find the exact value of $\sin 75^\circ$.

<details markdown="1">
<summary>Hint</summary>

Write $75^\circ$ as $45^\circ + 30^\circ$ and use
$\sin(A + B) = \sin A\cos B + \cos A\sin B$.
</details>

<details markdown="1">
<summary>Next step</summary>

Substitute the exact values:
$\dfrac{\sqrt{2}}{2} \times \dfrac{\sqrt{3}}{2} + \dfrac{\sqrt{2}}{2} \times
\dfrac{1}{2}$.
</details>

<details markdown="1">
<summary>Full working</summary>

$$
\sin 75^\circ
= \frac{\sqrt{2}}{2} \times \frac{\sqrt{3}}{2} + \frac{\sqrt{2}}{2} \times \frac{1}{2}
= \frac{\sqrt{6}}{4} + \frac{\sqrt{2}}{4}
= \frac{\sqrt{6} + \sqrt{2}}{4}.
$$
</details>

**2.** Use the addition formula to find the exact value of $\cos 15^\circ$.

<details markdown="1">
<summary>Hint</summary>

Write $15^\circ$ as $45^\circ - 30^\circ$. The cosine formula has a plus sign
for a difference.
</details>

<details markdown="1">
<summary>Next step</summary>

$\cos 15^\circ = \cos 45^\circ\cos 30^\circ + \sin 45^\circ\sin 30^\circ$.
</details>

<details markdown="1">
<summary>Full working</summary>

$$
\cos 15^\circ
= \frac{\sqrt{2}}{2} \times \frac{\sqrt{3}}{2} + \frac{\sqrt{2}}{2} \times \frac{1}{2}
= \frac{\sqrt{6} + \sqrt{2}}{4}.
$$
</details>

**3.** Use the addition formula to find the exact value of $\tan 75^\circ$.

<details markdown="1">
<summary>Hint</summary>

Write $75^\circ$ as $45^\circ + 30^\circ$ and use the tangent formula with
$\tan 45^\circ = 1$ and $\tan 30^\circ = \dfrac{\sqrt{3}}{3}$.
</details>

<details markdown="1">
<summary>Next step</summary>

$\tan 75^\circ = \dfrac{1 + \frac{\sqrt{3}}{3}}{1 - 1 \times \frac{\sqrt{3}}{3}}$.
Simplify by multiplying top and bottom by $3$.
</details>

<details markdown="1">
<summary>Full working</summary>

$$
\tan 75^\circ
= \frac{1 + \frac{\sqrt{3}}{3}}{1 - \frac{\sqrt{3}}{3}}
= \frac{3 + \sqrt{3}}{3 - \sqrt{3}}.
$$

Rationalise the denominator:

$$
= \frac{(3 + \sqrt{3})^2}{9 - 3}
= \frac{9 + 6\sqrt{3} + 3}{6}
= \frac{12 + 6\sqrt{3}}{6}
= 2 + \sqrt{3}.
$$
</details>

**4.** Given that $\sin A = \dfrac{5}{13}$ and $A$ is acute, find $\sin 2A$.

<details markdown="1">
<summary>Hint</summary>

Find $\cos A$ first, then use $\sin 2A = 2\sin A\cos A$.
</details>

<details markdown="1">
<summary>Next step</summary>

$\cos^2 A = 1 - \dfrac{25}{169} = \dfrac{144}{169}$, so $\cos A = \dfrac{12}{13}$.
Then multiply.
</details>

<details markdown="1">
<summary>Full working</summary>

$$
\sin 2A = 2 \times \frac{5}{13} \times \frac{12}{13} = \frac{120}{169}.
$$
</details>

**5.** For the same $A$, find $\cos 2A$ using the sine form.

<details markdown="1">
<summary>Hint</summary>

Use $\cos 2A = 1 - 2\sin^2 A$, the form that needs only the sine.
</details>

<details markdown="1">
<summary>Next step</summary>

Substitute $\sin A = \dfrac{5}{13}$:
$1 - 2 \times \dfrac{25}{169}$.
</details>

<details markdown="1">
<summary>Full working</summary>

$$
\cos 2A = 1 - 2 \times \frac{25}{169} = 1 - \frac{50}{169} = \frac{119}{169}.
$$
</details>

**6.** Given that $\tan A = \dfrac{1}{2}$, find $\tan 2A$.

<details markdown="1">
<summary>Hint</summary>

Use $\tan 2A = \dfrac{2\tan A}{1 - \tan^2 A}$.
</details>

<details markdown="1">
<summary>Next step</summary>

$\tan 2A = \dfrac{1}{1 - \frac{1}{4}} = \dfrac{1}{\frac{3}{4}}$.
</details>

<details markdown="1">
<summary>Full working</summary>

$$
\tan 2A = \frac{2 \times \frac{1}{2}}{1 - \frac{1}{4}} = \frac{1}{\frac{3}{4}} = \frac{4}{3}.
$$
</details>
