# 11.3 Diagrams for single-variable data and the histogram — Practise with help

Work each question closed book first. Check your arithmetic by adding the
frequencies back to the total.

## Warm-up: remember

1. Work out $8 + 14 + 11 + 7$.
2. Find $25\%$ of $60$.
3. Write $\dfrac{18}{24}$ in its simplest form.

<details markdown="1">
<summary>Answers</summary>

1. $8 + 14 + 11 + 7 = 40$.
2. $0.25 \times 60 = 15$.
3. $\dfrac{18}{24} = \dfrac{3}{4}$.

If question 3 was hard, revise equivalent fractions before you start.
</details>

:::figure warm-up-gate


## Practise with help

**1.** A class of width 20 contains 15 values. Find the frequency density.

<details markdown="1">
<summary>Hint</summary>

Frequency density is the frequency divided by the class width.
</details>

<details markdown="1">
<summary>Next step</summary>

Work out $\dfrac{15}{20}$ and leave it as a decimal or a fraction.
</details>

<details markdown="1">
<summary>Full working</summary>

$$
\text{frequency density} = \frac{15}{20} = 0.75.
$$

The bar is three-quarters of a unit high.
</details>

**2.** A histogram bar has frequency density 2.5 for the class $10$–$30$. Find
the frequency in the class.

<details markdown="1">
<summary>Hint</summary>

The class width is $30 - 10$. Multiply the density by it.
</details>

<details markdown="1">
<summary>Next step</summary>

The width is $20$, so work out $2.5 \times 20$.
</details>

<details markdown="1">
<summary>Full working</summary>

$$
\text{frequency} = 2.5 \times 20 = 50.
$$

So 50 values lie in the class.
</details>

**3.** A histogram has frequency density 3 for the class $0$–$8$. Find the number
of values between $2$ and $8$.

<details markdown="1">
<summary>Hint</summary>

The part from $2$ to $8$ has width $8 - 2 = 6$.
</details>

<details markdown="1">
<summary>Next step</summary>

Multiply the density 3 by the width 6.
</details>

<details markdown="1">
<summary>Full working</summary>

$$
\text{frequency} = 3 \times 6 = 18.
$$

The area over the part of the bar from $2$ to $8$ gives 18 values.
</details>

**4.** Complete the frequency density column: class $0$–$5$ with frequency 15,
class $5$–$15$ with frequency 25.

<details markdown="1">
<summary>Hint</summary>

Find each class width first. They are not the same.
</details>

<details markdown="1">
<summary>Next step</summary>

For the first class, $\dfrac{15}{5}$; for the second, $\dfrac{25}{10}$.
</details>

<details markdown="1">
<summary>Full working</summary>

The first width is 5, so the density is $\dfrac{15}{5} = 3$. The second width is
10, so the density is $\dfrac{25}{10} = 2.5$. The second class has a larger
frequency but a shorter bar, because it is twice as wide.
</details>

**5.** A histogram of 80 values has frequency density 0.5 in the class $20$–$40$.
Estimate the probability that a value lies in the class.

<details markdown="1">
<summary>Hint</summary>

First turn the frequency density into a frequency.
</details>

<details markdown="1">
<summary>Next step</summary>

The width is $20$, so the frequency is $0.5 \times 20 = 10$. Now divide by the
total of 80.
</details>

<details markdown="1">
<summary>Full working</summary>

$$
\text{frequency} = 0.5 \times 20 = 10,
\qquad
P = \frac{10}{80} = \frac{1}{8} = 0.125.
$$

The estimate is $\dfrac{1}{8}$.
</details>

**6.** A student wants to show the number of hours spent watching television by
40 people, grouped into classes 0–1, 1–2, 2–3 and 3–5 hours. Explain why a
histogram is the right choice, and why a bar chart with gaps would mislead.

<details markdown="1">
<summary>Hint</summary>

Decide whether the variable is continuous or categorical.
</details>

<details markdown="1">
<summary>Next step</summary>

Compare the class widths: the last class is twice as wide as the others.
</details>

<details markdown="1">
<summary>Full working</summary>

Time is continuous, so the classes have no gaps and a histogram is the right
diagram. The last class is twice as wide as the others, so its bar must be drawn
with frequency density, not frequency. A bar chart with gaps would treat the
classes as separate categories and would let the wide class look twice as
common as it is.
</details>
