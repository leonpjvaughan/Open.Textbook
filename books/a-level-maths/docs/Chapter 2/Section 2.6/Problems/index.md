# 2.6 Linear and quadratic inequalities, and set notation — Practise

Work through these on your own. Give every solution as a set: use an interval, a
union, or $\mathbb{R}$. Sketch the parabola for any quadratic inequality before
you choose the region, and include or exclude each endpoint deliberately.

Both the questions and the answers below come from a set that is checked by
computer every time the book is built.
