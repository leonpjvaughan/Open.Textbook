# 10.3 Vector addition and scalar multiplication — Practise

Work through these on your own. For each question, decide whether the answer is
a vector, a magnitude or a direction, and finish the calculation in that form.
Add and scale the components before you take any square root.

Both the questions and the answers below come from a set that is checked by
computer every time the book is built.
