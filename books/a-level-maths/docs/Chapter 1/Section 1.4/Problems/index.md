# 1.4 Disproof by counter example — Practise

Work through these on your own. A disproof needs two things: a value for which
the assumption holds, and a clear reason why the conclusion fails. Write both.
The last item asks you to choose the method: say which one fits and why before
you start.

Both the questions and the answers below come from a set that is checked by
computer every time the book is built.
