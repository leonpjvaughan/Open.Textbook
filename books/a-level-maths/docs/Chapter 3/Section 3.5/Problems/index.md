# 3.5 Parametric equations in modelling — Practise

Work through these on your own. For each question, decide whether it wants a
position, a path, or a time, and write down the domain of the parameter before
you calculate. Where a model is described in words, translate it into parametric
equations first. The final items reach back to the projectile and the drone of
this chapter, and ask you to choose between a "where" method and a "when"
method.

Both the questions and the answers below come from a set that is checked by
computer every time the book is built.
