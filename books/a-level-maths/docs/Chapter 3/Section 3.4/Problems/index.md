# 3.4 Parametric equations and Cartesian conversion — Practise

Work through these on your own. Before you eliminate the parameter, choose your
route: substitute from the simpler equation, or square and add with
$\cos^2 t + \sin^2 t = 1$. When the parameter has a restricted range, carry that
range across to the Cartesian form. Later items reach back to simultaneous
equations and to circles from 3.3, so decide which tool each one needs first.

Both the questions and the answers below come from a set that is checked by
computer every time the book is built.
