# 3.3 The equation of a circle and its properties — Practise

Work through these on your own. For an expanded equation, complete the square
before you do anything else: the centre and the radius decide every later step.
For a tangent, remember that the radius meets it at a right angle. Later items
reach back to gradients and simultaneous equations from Chapter 2, so decide
which tool each one needs before you start.

Both the questions and the answers below come from a set that is checked by
computer every time the book is built.
