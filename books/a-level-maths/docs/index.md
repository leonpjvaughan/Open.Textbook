# A-level Mathematics

Welcome. This is a complete, interactive A-level Mathematics book for England.
It covers pure mathematics, statistics and mechanics, across both years of the
course. Everything here is free to read online, and there is nothing to install.

The content is the common content set by the Department for Education. It
therefore follows the AQA 7357, Pearson Edexcel 9MA0 and OCR H240
specifications at once. Where the boards differ, a page says so.

## How to use this book

Each section has three pages:

| Page | What it is for |
|---|---|
| **Learn** | The teaching: ideas, worked examples, and something to try |
| **Practise with help** | Questions with hints you reveal only if you need them |
| **Practise** | Independent questions, with answers at the end |

Each chapter opens with a problem you will be able to solve by the end. It closes
with a **Review** that mixes the chapter's methods together, and returns to
earlier chapters.

## How the book is organised

The book has three strands.

- **Pure mathematics** covers proof, algebra, coordinate geometry, sequences and
  series, trigonometry, exponentials and logarithms, differentiation,
  integration, numerical methods and vectors.
- **Statistics** covers sampling, data presentation, probability, distributions
  and hypothesis testing.
- **Mechanics** covers quantities and units, kinematics, forces, Newton's laws
  and moments.

The chapters are numbered as one sequence, so the strands appear in the order you
meet them. The early pure chapters are the ones the applied chapters build on.

## Checked answers

The questions and the answers in each **Practise** set come from one set that a
computer checks every time the book is built. So the two cannot disagree. The
computer checks the algebra, not the argument, so read the reasoning in
**Learn** as well.
