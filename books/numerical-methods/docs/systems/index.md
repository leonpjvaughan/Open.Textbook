# Every system, and the class it belongs to

The map counts sixty-four systems, and every one of them is a bullet on a class
page under **Systems that live here**. This page is the other direction: find
the system you are trying to model, and follow it to the kind of problem it is.

The list is built from those bullets when the book is built, so it cannot fall
behind them. Add a system to a class page and it appears here.

:::systems

## Why this direction

The book offered three ways in: you have a model, you know a method's name, or
you have a wrong answer. The fourth is the most concrete thing many readers hold
— the system they are trying to model. Until now it sent them reading nine pages
to find the one that lists it.

| what you are holding | start at |
|---|---|
| a model, and no idea what it is | [Nine kinds of problem](../index.md) |
| a method's name | [Methods, A to Z](../techniques/index.md) |
| a wrong answer | [When it goes wrong](../symptoms/index.md) |
| the system | this page |
