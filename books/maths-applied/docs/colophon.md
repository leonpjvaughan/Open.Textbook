# About this book

## What this book is

This is a book about modelling, worked out on one mechanism: the front
suspension of a car. It asks one question — how far does the camber change as
the wheel moves — and answers it with four models of increasing complexity.
Each one is introduced only when the one before it has stopped answering the
question, and every model is checked against the last by a number the book
shows.
Every section has one page.
**Learn** teaches the ideas and the method.
Some sections offer an optional page as well, for a reader who wants
more. You never need one to follow the chapter.
You can read the whole book in a browser, and there is nothing to
install.
Each chapter opens with a question you can answer by the end, and closes with a **Review**.

## Who made it

This book is part of **Open.Textbook**, an independent project by Leon

## Where the content comes from

This book follows no syllabus, and it is not tied to a country's
curriculum.

The mathematics is standard, the geometry is illustrative rather than
measured, and every number in a figure is computed by the model the page
describes.

The claims in this book rest on these documents:

- [SAE J670: Vehicle Dynamics Terminology](https://www.sae.org/standards/content/j670_202208/)
- [A.d.Tramontana front suspension (cutaway display, Wikimedia Commons)](https://commons.wikimedia.org/wiki/File:A.d.Tramontana_Front_Suspension.jpg)
- [suspension-kinematics — the model, its exports and a generated solver](https://github.com/leonpjvaughan/suspension-kinematics)
