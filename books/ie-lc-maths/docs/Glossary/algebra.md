# Glossary — Algebra

**Argand diagram** — a plane on which a complex number is plotted, with the real
part on the horizontal axis and the imaginary part on the vertical axis.

**Arithmetic sequence** — a sequence in which each term is found by adding the
same number to the one before.

**Base case** — the first step of a proof by induction, where the statement is
checked for the smallest value.

**Coefficient** — the number multiplying a variable, such as the $5$ in $5x$.

**Common difference** — the amount added to each term to get the next term in an
arithmetic sequence.

**Common ratio** — the number by which each term is multiplied to get the next
term in a geometric sequence.

**Complex conjugate** — the number formed by changing the sign of the imaginary
part of a complex number.

**Complex number** — a number of the form $a+bi$, where $a$ and $b$ are real and
$i^2=-1$.

**Conditional** — a statement that one thing is true only if another is.

**Conjugate root theorem** — the result that a polynomial with real coefficients
has complex roots in conjugate pairs.

**Constant** — a value that does not change.

**Dependent variable** — the quantity whose value depends on another.

**Direct proportion** — a relationship where one quantity is a fixed multiple of
the other.

**Discriminant** — the value $b^2-4ac$ in a quadratic equation; it tells you how
many real roots there are.

**Equation** — a statement that two expressions have the same value, shown by an
equals sign.

**Evaluate** — work out the value of an expression.

**Expand** — multiply out brackets to remove them.

**Expression** — numbers, variables and operations written together without an
equals sign.

**Fixed point** — a value that a recurrence leaves unchanged.

**Geometric sequence** — a sequence in which each term is found by multiplying
the one before by the same number.

**Gradient** — the change in the vertical coordinate divided by the change in
the horizontal coordinate.

**Imaginary axis** — the vertical axis of an Argand diagram, on which imaginary
parts are plotted.

**Imaginary unit** — the number $i$, defined by $i^2=-1$.

**Independent variable** — the quantity you choose or change.

**Inductive hypothesis** — the assumption, in a proof by induction, that the
statement is true for one value.

**Inductive step** — the part of a proof by induction that shows the statement
passes from one value to the next.

**Inequality** — a comparison that uses a symbol such as $<$, $>$, $\leq$ or
$\geq$.

**Like terms** — terms with the same variable part, such as $3x$ and $-2x$.

**Linear relationship** — a relationship that can be represented by a straight-
line graph.

**Modulus** — the distance of a number from zero; for a complex number $a+bi$ it
is $\sqrt{a^2+b^2}$.

**Proof by induction** — a proof that a statement is true for every whole
number, using a base case and an inductive step.

**Purely imaginary** — having a real part of zero, so the number is a multiple
of $i$.

**Quadratic equation** — an equation in which the highest power of the variable
is 2.

**Quadratic formula** — the formula $x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$ that
solves a quadratic equation.

**Quadratic inequality** — an inequality that contains a term in the square of
the variable.

**Rate of change** — how quickly one quantity changes as another changes.

**Real axis** — the horizontal axis of an Argand diagram, on which real parts
are plotted.

**Real part** — the $a$ in a complex number $a+bi$.

**Recurrence relation** — a rule that gives each term of a sequence from the one
before.

**Series** — the sum of the terms of a sequence.

**Simultaneous solution** — a set of values that makes every equation in a
system true at once.

**Solution** — the value that makes an equation true.

**Standard form** — for a complex number, the form $a+bi$.

**Sum to infinity** — the total of all the terms of an infinite geometric
series, when it exists.

**System** — a set of equations that must be true at the same time.

**Term** — one number or expression in a sequence or in an expression.

**Theorem** — a statement that can be proved from earlier results.

**Variable** — a letter that stands for a number that can change.

**$y$-intercept** — the point where a graph crosses the vertical axis.

**Zero product rule** — the rule that if a product is zero then at least one
factor is zero.
