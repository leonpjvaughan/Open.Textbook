# Glossary — Functions

**Average gradient** — the gradient of the chord between two points on a curve.

**Bijective** — both injective and surjective.

**Chain rule** — the rule for differentiating a function of a function.

**Chord** — a straight line joining two points on a curve.

**Composite function** — a function formed by applying one function to the
output of another.

**Concave down** — curving so that the second derivative is negative.

**Concave up** — curving so that the second derivative is positive.

**Derivative** — the rate of change of a function, or the gradient of its graph.

**Domain** — the set of inputs a function accepts.

**Exponential function** — a function in which the variable is the power, such
as $2^x$.

**Function** — a rule that gives exactly one output for each permitted input.

**Horizontal line test** — a test that shows whether a function is injective.

**Injective** — having a different output for every input.

**Instantaneous rate of change** — the rate of change at one particular moment.

**Inverse function** — the function that undoes another.

**Logarithm** — the power to which a base must be raised to give a number.

**Maximum** — the greatest value a function takes near a point.

**Minimum** — the least value a function takes near a point.

**One-to-one** — another name for injective.

**Onto** — another name for surjective.

**Point of inflection** — a point where a curve changes from concave up to
concave down, or the reverse.

**Power rule** — the rule that the derivative of $x^n$ is $nx^{n-1}$.

**Product rule** — the rule for differentiating the product of two functions.

**Quotient rule** — the rule for differentiating one function divided by
another.

**Range** — the set of outputs a function produces.

**Relation** — a set of ordered pairs that links values of one quantity to
values of another.

**Second derivative** — the derivative of the derivative.

**Second derivative test** — a test that uses the second derivative to classify
a stationary point.

**Stationary point** — a point where the gradient of a curve is zero.

**Surjective** — having every possible output reached by some input.

**Vertical line test** — a test that shows whether a relation is a function.
