# 14.1 Translations — Practise with help

## Warm-up: remember

1. Work out $-3 + 5$ and $4 - 7$.
2. A point is 4 units left of the origin and 2 units above it. Write its coordinates.

<details markdown="1">
<summary>Answers and feedback</summary>

1. $-3 + 5 = 2$ and $4 - 7 = -3$. Adding a negative number moves left on the number
   line, and subtracting moves left again. A translation uses the same arithmetic.
2. $(-4,2)$. The horizontal coordinate comes first, and left is negative.

If either answer felt uncertain, revisit the number line in Chapter 1 before you carry on.

</details>

:::figure warm-up-gate


## Practise with help

**1.** Translate the point $(3,-2)$ by the vector $\binom{4}{5}$.

<details markdown="1">
<summary>Hint</summary>

The top number changes the $x$-coordinate and the bottom number changes the
$y$-coordinate.

<details markdown="1">
<summary>Next step</summary>

Add 4 to the $x$-coordinate and add 5 to the $y$-coordinate.

<details markdown="1">
<summary>Full working</summary>

$$(3 + 4,\; -2 + 5) = (7,3)$$

The image is $(7,3)$. The point moved 4 right and 5 up.

</details>
</details>
</details>

**2.** Translate the point $(-1,4)$ by the vector $\binom{-3}{-6}$.

<details markdown="1">
<summary>Hint</summary>

Both numbers are negative, so the point moves left and down.

<details markdown="1">
<summary>Next step</summary>

Subtract 3 from the $x$-coordinate and subtract 6 from the $y$-coordinate.

<details markdown="1">
<summary>Full working</summary>

$$(-1 - 3,\; 4 - 6) = (-4,-2)$$

The image is $(-4,-2)$.

</details>
</details>
</details>

**3.** A translation takes $P(1,2)$ to $P'(5,5)$. Find the translation vector.

<details markdown="1">
<summary>Hint</summary>

The horizontal shift is $a$ and the vertical shift is $b$. Subtract the object
coordinate from the image coordinate, one axis at a time.

<details markdown="1">
<summary>Next step</summary>

For the horizontal part, work out $5 - 1$.

<details markdown="1">
<summary>Full working</summary>

$$a = 5 - 1 = 4 \qquad b = 5 - 2 = 3$$

The vector is $\binom{4}{3}$.

</details>
</details>
</details>

**4.** A translation takes $M(3,-1)$ to $M'(-2,4)$. Find the image of the origin
$O(0,0)$ under the same translation.

<details markdown="1">
<summary>Hint</summary>

Find the vector first, then apply it to the origin.

<details markdown="1">
<summary>Next step</summary>

The vector is $\binom{-2-3}{4-(-1)}$, which is $\binom{-5}{5}$.

<details markdown="1">
<summary>Full working</summary>

The vector is $\binom{-5}{5}$. Apply it to the origin:

$$O' = (0 - 5,\; 0 + 5) = (-5,5)$$

So the origin moves to $(-5,5)$.

</details>
</details>
</details>

**5.** Translate the triangle with corners $(0,0)$, $(2,0)$ and $(1,3)$ by the vector
$\binom{2}{1}$.

<details markdown="1">
<summary>Hint</summary>

Translate each corner with the same vector.

<details markdown="1">
<summary>Next step</summary>

The first corner $(0,0)$ becomes $(0+2,\;0+1) = (2,1)$.

<details markdown="1">
<summary>Full working</summary>

$$(0,0) \to (2,1) \qquad (2,0) \to (4,1) \qquad (1,3) \to (3,4)$$

The image triangle has corners $(2,1)$, $(4,1)$ and $(3,4)$. It is congruent to the
object.

</details>
</details>
</details>

**6.** A student translates $(3,5)$ by the vector $\binom{2}{-1}$ and writes down
$(2,4)$. Explain what went wrong, and give the correct image.

<details markdown="1">
<summary>Hint</summary>

Which coordinate should the 2 change, and which should the $-1$ change?

<details markdown="1">
<summary>Next step</summary>

The top number of the vector always changes the $x$-coordinate.

<details markdown="1">
<summary>Full working</summary>

The student swapped the two coordinates. The top number 2 must change the
$x$-coordinate, and the bottom number $-1$ must change the $y$-coordinate.

$$(3 + 2,\; 5 - 1) = (5,4)$$

The correct image is $(5,4)$.

</details>
</details>
</details>

## A question from Chapter 12

**7.** A surveyor stands at the origin of a coordinate grid and walks 6 units right and
3 units up. Write the walk as a translation vector, and give the surveyor's new position.

<details markdown="1">
<summary>Hint</summary>

The vector records the horizontal move on top and the vertical move below.

<details markdown="1">
<summary>Next step</summary>

Right is positive, so the top number is 6. Up is positive, so the bottom number is 3.

<details markdown="1">
<summary>Full working</summary>

The vector is $\binom{6}{3}$. Starting from the origin,

$$(0 + 6,\; 0 + 3) = (6,3)$$

The surveyor finishes at $(6,3)$.

</details>
</details>
</details>
