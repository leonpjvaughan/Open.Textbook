# 4.2 Representing relations in tables and graphs — Learn

**Prerequisites:** Section 4.1 — expressions; plotting coordinates.

**Objectives:** complete a table from an expression; plot the ordered pairs;
read a relationship from a graph.

By the end of this section you can move between a formula, a table and a graph,
and read the break-even point off the graph.

## A relation is an input and an output

A **relation** connects each input to an output. The input is the number you
choose, and the output is the number the rule gives back.

For the candle business:

- the input is the number of candles made;
- the cost is $240 + 4n$;
- the income is $10n$.

Each rule is a relation, and each one can be written as a formula, shown in a
table, or drawn as a graph. The three views carry the same information.

## From a formula to a table

Substitute each input into the formula and record the output.

For the cost $C = 240 + 4n$:

| Candles $n$ | $0$ | $10$ | $20$ | $30$ | $40$ |
|---|---|---|---|---|---|
| Cost $C$ (€) | $240$ | $280$ | $320$ | $360$ | $400$ |

For the income $R = 10n$:

| Candles $n$ | $0$ | $10$ | $20$ | $30$ | $40$ |
|---|---|---|---|---|---|
| Income $R$ (€) | $0$ | $100$ | $200$ | $300$ | $400$ |

The number of candles is the **independent variable**, because you choose it. The
cost and the income are the **dependent variables**, because they follow from it.

## From a table to a graph

Each column of the table gives a pair of numbers, and a pair is a point. The cost
at $20$ candles is €320, so the point $(20, 320)$ lies on the cost graph.

- the independent variable goes on the horizontal axis;
- the dependent variable goes on the vertical axis;
- each pair $(n, C)$ is one plotted point;
- the points join to a straight line, because the rule adds the same amount for
  every candle.

The cost line starts at $(0, 240)$, because €240 is paid even when no candles are
made. The income line starts at $(0, 0)$, because no candles means no money in.

**Example 1.** The cost line passes through $(0, 240)$ and $(40, 400)$. The income
line passes through $(0, 0)$ and $(40, 400)$.

The two lines meet at $(40, 400)$. At that point the cost and the income are both
€400, so the business has broken even.

Below $40$ candles the cost line is above the income line, so the business makes
a loss. Above $40$ candles the income line is above the cost line, so the
business makes a profit.

## Reading a graph

A graph answers "what if" questions without any arithmetic.

**Example 2.** Read the income at $35$ candles from the graph.

The point on the income line above $n = 35$ has a vertical value of about $350$.
The formula gives $10 \times 35 = 350$, which is €350 and confirms the reading.

> **Watch out.** Put the input on the horizontal axis and the output on the
> vertical axis, and label both. A graph with the axes the wrong way round still
> looks like a graph, but every reading off it is wrong. A straight-line rule also
> joins with a straight line: drawing a curve through points that lie in a line
> hides the constant rate of change.

## Progress check

Back to the chapter problem. Complete the table for the cost of $n$ candles, then
plot the cost and the income on one graph.

| $n$ | $0$ | $10$ | $20$ | $30$ | $40$ | $50$ |
|---|---|---|---|---|---|---|
| Cost (€) | | | | | | |
| Income (€) | | | | | | |

Read the number of candles at which the two lines meet. That reading is an
estimate. Section 4.6 solves the equation that gives the exact answer.

## You should now be able to

- complete a table of values from a formula;
- plot the ordered pairs and join them with the correct line;
- say which variable is independent and which is dependent;
- read a value, and an intersection, from a graph.
