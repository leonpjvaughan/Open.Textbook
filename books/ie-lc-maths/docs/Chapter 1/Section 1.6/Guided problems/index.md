# 1.6 Solving problems with indices — Practise with help

## Warm-up: remember

1. Write $16$ as a power of $2$.
2. Simplify $2^3 \times 2^4$.

<details markdown="1">
<summary>Answers and feedback</summary>

1. $16 = 2^4$.
2. $2^3 \times 2^4 = 2^7$. Adding the indices is the multiplying law.

</details>

## Practise with help

**1.** Solve $2^x = 16$.

<details markdown="1">
<summary>Hint</summary>

Write $16$ as a power of $2$.

<details markdown="1">
<summary>Next step</summary>

$16 = 2^4$, so $2^x = 2^4$.

<details markdown="1">
<summary>Full working</summary>

$$x = 4$$

The bases are equal, so the indices are equal.

</details>
</details>
</details>

**2.** Solve $3^x = 243$.

<details markdown="1">
<summary>Hint</summary>

Keep dividing $243$ by $3$.

<details markdown="1">
<summary>Next step</summary>

$243 = 3 \times 81 = 3^5$.

<details markdown="1">
<summary>Full working</summary>

$$3^x = 3^5 \qquad x = 5$$

Check: $3^5 = 243$.

</details>
</details>
</details>

**3.** Solve $2^{x+2} = 32$.

<details markdown="1">
<summary>Hint</summary>

Write $32$ as a power of $2$, then compare indices.

<details markdown="1">
<summary>Next step</summary>

$32 = 2^5$, so $x + 2 = 5$.

<details markdown="1">
<summary>Full working</summary>

$$2^{x+2} = 2^5 \qquad x + 2 = 5 \qquad x = 3$$

Check: $2^{3+2} = 2^5 = 32$.

</details>
</details>
</details>

**4.** Solve $5^{2x} = 25$.

<details markdown="1">
<summary>Hint</summary>

Write $25$ as a power of $5$.

<details markdown="1">
<summary>Next step</summary>

$25 = 5^2$, so $2x = 2$.

<details markdown="1">
<summary>Full working</summary>

$$5^{2x} = 5^2 \qquad 2x = 2 \qquad x = 1$$

</details>
</details>
</details>

**5.** Solve $4^x = 2^{x+3}$.

<details markdown="1">
<summary>Hint</summary>

Write $4$ as $2^2$ so both sides have base $2$.

<details markdown="1">
<summary>Next step</summary>

$4^x = 2^{2x}$, so $2x = x + 3$.

<details markdown="1">
<summary>Full working</summary>

$$4^x = (2^2)^x = 2^{2x}$$

$$2^{2x} = 2^{x+3} \qquad 2x = x + 3 \qquad x = 3$$

Check: $4^3 = 64$ and $2^{3+3} = 2^6 = 64$.

</details>
</details>
</details>

**6.** €800 is invested at $3\%$ per year. Find the value after $2$ years, to the
nearest cent.

<details markdown="1">
<summary>Hint</summary>

A $3\%$ rise multiplies by $1.03$ each year.

<details markdown="1">
<summary>Next step</summary>

Use $800 \times 1.03^2$.

<details markdown="1">
<summary>Full working</summary>

$$800 \times 1.03^2 = 800 \times 1.0609 = 848.72$$

The value is €848.72 to the nearest cent. The index $2$ counts the years.

</details>
</details>
</details>

## A question from Section 1.4

**7.** Solve $|x| = 5$.

<details markdown="1">
<summary>Hint</summary>

Which numbers are $5$ units from $0$?

<details markdown="1">
<summary>Next step</summary>

There are two, one on each side of $0$.

<details markdown="1">
<summary>Full working</summary>

$$x = 5 \quad \text{or} \quad x = -5$$

An equation with an absolute value can have two solutions, and so can one with an
unknown index.

</details>
</details>
</details>

## The chapter problem

**8.** Carpet costs €32.40 per square metre, and the price rises by $4\%$ each
year. Work out the price after $3$ years, to the nearest cent.

<details markdown="1">
<summary>Hint</summary>

Use $32.40 \times 1.04^3$.

<details markdown="1">
<summary>Next step</summary>

$1.04^3 = 1.124864$.

<details markdown="1">
<summary>Full working</summary>

$$32.40 \times 1.124864 = 36.4455936$$

The price is €36.45 per square metre after three years.

That rise is about €4.05. The estimator's rounding error was €84.87, more than
twenty times larger. Rounding early costs far more than a few years of price
rises.

</details>
</details>
</details>
