# 1.4 Absolute value — Learn

**Prerequisites:** the number line; ordering negative numbers; solving a simple
linear equation.

**Objectives:** work out the absolute value of a number; use $|a - b|$ as a
distance; solve $|x| = a$ and $|x| < a$.

By the end of this section you can measure how far apart two numbers are, and
solve an equation that hides a distance.

## Size without sign

The **absolute value** of a number is its distance from $0$ on the number line.
The distance is never negative, so the absolute value is never negative either.

The absolute value of $x$ is written $|x|$.

$$|7| = 7 \qquad |-7| = 7 \qquad |0| = 0$$

Both $7$ and $-7$ are $7$ units from $0$. The sign says which side, and the
absolute value says how far.

## Distance between two numbers

The distance between $a$ and $b$ on the number line is

$$|a - b|$$

Subtracting gives the signed change from $b$ to $a$. The absolute value removes
the sign, leaving the size of the change.

**Example 1.** Work out the distance between $-4$ and $7$.

$$|7 - (-4)| = |11| = 11$$

The gap is $11$ units. Subtracting in the other order gives $|-11| = 11$, which
is the same distance.

## Solving |x| = a

The equation $|x| = a$ asks which numbers are $a$ units from $0$. When $a > 0$
there are two answers, one on each side:

$$x = a \quad \text{or} \quad x = -a$$

When $a = 0$ there is one answer, $x = 0$. When $a < 0$ there is no answer,
because a distance cannot be negative.

**Example 2.** Solve $|x - 2| = 5$.

The distance from $x$ to $2$ is $5$, so $x$ is $5$ units either side of $2$:

$$x - 2 = 5 \quad \text{or} \quad x - 2 = -5$$

So $x = 7$ or $x = -3$. Check: $|7 - 2| = 5$ and $|-3 - 2| = |-5| = 5$.

## Solving |x| < a

The inequality $|x| < a$ asks which numbers are less than $a$ units from $0$.
The answer is the open interval between $-a$ and $a$:

$$-a < x < a$$

The endpoints are not included, because the inequality is strict. For
$|x| \leq a$ the endpoints are included.

**Example 3.** Solve $|x| < 4$.

$$-4 < x < 4$$

Every number between $-4$ and $4$ is less than $4$ units from $0$. The numbers
$-4$ and $4$ themselves are exactly $4$ units away, so they are not included.

> **Watch out.** The equation $|x| = -5$ has no solution, and $|x| < -5$ has no
> solution either. The absolute value is a distance, and no distance is negative.
> Check the sign on the right before you start solving.

## Progress check

Back to the chapter problem. The correct quote is €533.937096 and the estimator's
quote is €449.064. The carpet costs €485.39736 before profit.

Work out the size of the error, $|533.937096 - 449.064|$, and the loss,
$|485.39736 - 449.064|$. Both are absolute values, and both are distances on the
number line.

The error is bigger than the loss, because the quote also carried the profit
margin. Section 1.7 uses both figures.

## You should now be able to

- work out the absolute value of any number;
- explain why an absolute value is never negative;
- use $|a - b|$ to find the distance between two numbers;
- solve $|x| = a$ and $|x - k| = a$ by splitting into two cases;
- solve $|x| < a$ and write the answer as an interval.
