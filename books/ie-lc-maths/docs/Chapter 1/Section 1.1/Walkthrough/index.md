# 1.1 The number systems ℕ, ℤ, ℚ and ℝ — Learn

**Prerequisites:** counting with whole numbers; ordering negative numbers; writing
a decimal as a fraction.

**Objectives:** name the number systems $\mathbb{N}$, $\mathbb{Z}$, $\mathbb{Q}$
and $\mathbb{R}$; decide which system a number belongs to; write a terminating or
recurring decimal as a fraction.

By the end of this section you can place any number you meet into one of four
families, and say how the families fit inside each other.

## The counting numbers

The first numbers you met were the counting numbers:

$$1,\ 2,\ 3,\ 4,\ \dots$$

They are called the **natural numbers**, written $\mathbb{N}$. You use them to
count whole things: three apples, seven days, one hundred euro.

Add zero and the negative whole numbers, and you have the **integers**:

$$\dots,\ -3,\ -2,\ -1,\ 0,\ 1,\ 2,\ 3,\ \dots$$

The integers are written $\mathbb{Z}$. They can be positive, negative or zero,
and they have no fractional part. A temperature of $-4^\circ C$ and a bank balance
of $-\text{€}50$ are both integers.

Every natural number is an integer, because you can reach it by counting. The
reverse is not true: $-4$ is an integer but not a natural number.

## Fractions and decimals

A **rational number** is any number that can be written as one integer divided by
another:

$$\frac{a}{b} \quad \text{where } a \text{ and } b \text{ are integers and } b \neq 0$$

The rational numbers are written $\mathbb{Q}$. The word comes from *ratio*, which
is what a fraction is.

Every integer is rational, because $7 = \dfrac{7}{1}$. So the integers sit inside
the rational numbers.

Rational numbers have two decimal habits.

- A **terminating decimal** stops, such as $0.75$ or $3.125$.
- A **recurring decimal** repeats a block of digits for ever, such as
  $0.333\dots$ or $0.272727\dots$.

Both kinds are rational. A terminating decimal is a fraction with a denominator
that is a power of ten. A recurring decimal needs a short piece of algebra, which
Example 3 shows.

## The real numbers

Draw every rational number on a number line and you still leave gaps. The number
$\sqrt{2}$ sits in one of those gaps, and it is not a fraction. Numbers that are
not rational are called **irrational**, and together the rational and irrational
numbers make the **real numbers**, written $\mathbb{R}$.

$$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}$$

The symbol $\subset$ means "is contained in". Each family sits inside the next
one. Section 1.2 looks at the irrational numbers in detail.

## Worked examples

**Example 1.** Which systems contain $-6$?

$-6$ is a whole number, so it is an integer. It is negative, so it is not a
natural number. It can be written as $\dfrac{-6}{1}$, so it is rational. Every
rational number is real. The smallest system that contains $-6$ is the integers.

**Example 2.** Write $0.75$ as a fraction in its lowest terms.

$$0.75 = \frac{75}{100} = \frac{3}{4}$$

Divide top and bottom by $25$. Because the decimal terminates, the fraction has a
power of ten on the bottom before you simplify.

**Example 3.** Write $0.777\dots$ as a fraction.

Let $x = 0.777\dots$. Multiply by $10$, because one digit repeats:

$$10x = 7.777\dots$$

Subtract the first line from the second. The repeating parts cancel:

$$10x - x = 7.777\dots - 0.777\dots \qquad 9x = 7 \qquad x = \frac{7}{9}$$

The method works because multiplying by $10$ lines the repeating blocks up, so the
subtraction removes them.

**Example 4.** Is $\sqrt{9}$ rational or irrational?

$\sqrt{9} = 3$, which is a whole number. So $\sqrt{9}$ is rational. A square root
is irrational only when the number under it is not a perfect square.

> **Watch out.** A decimal with many digits is not automatically irrational.
> $0.272727\dots$ looks busy, but the block $27$ repeats, so the number is
> rational. Irrational decimals never repeat and never stop. Look for a repeating
> block before you decide.

## Progress check

Back to the chapter problem. The room measures $4.35$ m by $3.28$ m, and both
measurements are terminating decimals.

Write each measurement as a fraction in its lowest terms. Then multiply the two
fractions to find the exact area, and say which of $\mathbb{N}$, $\mathbb{Z}$,
$\mathbb{Q}$ and $\mathbb{R}$ contains that area.

Keep the exact fractions. The estimator in the chapter problem rounded early, and
Section 1.7 shows what that cost.

## You should now be able to

- name the four number systems $\mathbb{N}$, $\mathbb{Z}$, $\mathbb{Q}$ and
  $\mathbb{R}$;
- say whether a number is natural, an integer, rational or irrational;
- write a terminating decimal as a fraction;
- write a recurring decimal as a fraction using the subtraction method;
- explain why every integer is rational and every rational number is real.
