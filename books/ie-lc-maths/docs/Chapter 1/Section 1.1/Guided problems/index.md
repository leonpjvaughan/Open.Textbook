# 1.1 The number systems ℕ, ℤ, ℚ and ℝ — Practise with help

## Warm-up: remember

1. Write $0.5$ as a fraction in its lowest terms.
2. Write these numbers in order from smallest to largest: $-3$, $2$, $-7$, $0$.

<details markdown="1">
<summary>Answers and feedback</summary>

1. $0.5 = \dfrac{5}{10} = \dfrac{1}{2}$.
2. $-7$, $-3$, $0$, $2$. A number line helps: the further left, the smaller.

</details>

## Practise with help

**1.** Which number systems contain $12$? Name the smallest one.

<details markdown="1">
<summary>Hint</summary>

Start with the most familiar family: is $12$ a counting number?

<details markdown="1">
<summary>Next step</summary>

Write $12$ as a fraction over $1$ to test whether it is rational.

<details markdown="1">
<summary>Full working</summary>

$12$ is a counting number, so it is natural. Every natural number is an integer,
because it has no fractional part. Every integer is rational, because
$12 = \dfrac{12}{1}$. Every rational number is real.

The smallest system that contains $12$ is $\mathbb{N}$, the natural numbers.

</details>
</details>
</details>

**2.** Which number systems contain $-0.25$?

<details markdown="1">
<summary>Hint</summary>

Is $-0.25$ a whole number? Can you write it as one integer over another?

<details markdown="1">
<summary>Next step</summary>

$-0.25 = \dfrac{-25}{100}$.

<details markdown="1">
<summary>Full working</summary>

$-0.25$ is not a whole number, so it is not natural and not an integer. It is
rational, because $-0.25 = \dfrac{-25}{100} = \dfrac{-1}{4}$, one integer over
another. Every rational number is real.

The smallest system that contains $-0.25$ is $\mathbb{Q}$, the rational numbers.

</details>
</details>
</details>

**3.** Write $0.6$ as a fraction in its lowest terms.

<details markdown="1">
<summary>Hint</summary>

Write the decimal over its place value. The $6$ is in the tenths place.

<details markdown="1">
<summary>Next step</summary>

$0.6 = \dfrac{6}{10}$. Now divide top and bottom by a common factor.

<details markdown="1">
<summary>Full working</summary>

$$0.6 = \frac{6}{10} = \frac{3}{5}$$

Divide top and bottom by $2$. The decimal terminates, so the denominator was a
power of ten before you simplified.

</details>
</details>
</details>

**4.** Write $0.444\dots$ as a fraction in its lowest terms.

<details markdown="1">
<summary>Hint</summary>

Let $x = 0.444\dots$, then multiply by $10$ so the repeating parts line up.

<details markdown="1">
<summary>Next step</summary>

$10x = 4.444\dots$ and $x = 0.444\dots$. Subtract the second from the first.

<details markdown="1">
<summary>Full working</summary>

$$10x - x = 4.444\dots - 0.444\dots \qquad 9x = 4 \qquad x = \frac{4}{9}$$

The repeating part cancelled in the subtraction, which is why multiplying by $10$
works. So $0.444\dots = \dfrac{4}{9}$.

</details>
</details>
</details>

**5.** Is $\sqrt{25}$ rational or irrational? Give a reason.

<details markdown="1">
<summary>Hint</summary>

Work out the square root before you decide.

<details markdown="1">
<summary>Next step</summary>

Which whole number multiplied by itself gives $25$?

<details markdown="1">
<summary>Full working</summary>

$\sqrt{25} = 5$, because $5 \times 5 = 25$. The value is a whole number, so it is
rational.

A square root is irrational only when the number under it is not a perfect
square. Here $25$ is a perfect square.

</details>
</details>
</details>

**6.** A room measures $4.35$ m by $3.28$ m. Write $4.35$ as a fraction in its
lowest terms.

<details markdown="1">
<summary>Hint</summary>

$4.35$ has two decimal places, so write it over $100$.

<details markdown="1">
<summary>Next step</summary>

$4.35 = \dfrac{435}{100}$. Look for a common factor.

<details markdown="1">
<summary>Full working</summary>

$$4.35 = \frac{435}{100} = \frac{87}{20}$$

Divide top and bottom by $5$. The fraction is exact, so the measurement carries
all its precision.

In the chapter problem, this exact value is what the estimator should have used.

</details>
</details>
</details>

## A question from the chapter problem

**7.** Write $3.28$ as a fraction in its lowest terms, then multiply your answer
by the fraction for $4.35$ to find the exact area of the room.

<details markdown="1">
<summary>Hint</summary>

$3.28 = \dfrac{328}{100}$. Divide top and bottom by a common factor.

<details markdown="1">
<summary>Next step</summary>

$3.28 = \dfrac{82}{25}$. Now multiply $\dfrac{87}{20} \times \dfrac{82}{25}$.

<details markdown="1">
<summary>Full working</summary>

$$3.28 = \frac{328}{100} = \frac{82}{25}$$

Multiply the two fractions:

$$\frac{87}{20} \times \frac{82}{25} = \frac{7134}{500} = \frac{3567}{250}$$

The exact area is $\dfrac{3567}{250} = 14.268$ m$^2$. Section 1.7 uses this exact
area to find the correct quote.

</details>
</details>
</details>
