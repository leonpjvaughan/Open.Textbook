# 6.1 Relations and functions — Practise with help

## Warm-up: remember

1. In the ordered pair $(3, 2)$, which number is the input and which is the output?
2. Work out the value of $2x + 1$ when $x = 4$.

<details markdown="1">
<summary>Answers and feedback</summary>

1. The input is the first number, $3$. The output is the second number, $2$. Every ordered
   pair is written input first.
2. $2(4) + 1 = 9$. Substituting into a rule is the same skill you use on a function.

</details>

## Practise with help

**1.** Is $\{(1, 3), (2, 5), (3, 7)\}$ a function? Give a reason.

<details markdown="1">
<summary>Hint</summary>

Check each input in turn. Does any input appear more than once?

<details markdown="1">
<summary>Next step</summary>

The inputs are $1$, $2$ and $3$. Each appears once.

<details markdown="1">
<summary>Full working</summary>

Yes. Each input appears once, so each input has exactly one output. The relation is a
function.

</details>
</details>
</details>

**2.** Is $\{(4, 1), (4, 2), (5, 3)\}$ a function? Give a reason.

<details markdown="1">
<summary>Hint</summary>

Look for a repeated input.

<details markdown="1">
<summary>Next step</summary>

The input $4$ appears twice, with the outputs $1$ and $2$.

<details markdown="1">
<summary>Full working</summary>

No. The input $4$ has two outputs, $1$ and $2$. A function gives each input exactly one
output, so this relation is not a function.

</details>
</details>
</details>

**3.** A table pairs the inputs $2$, $4$, $6$ with the outputs $1$, $2$, $3$. Is the
relation a function?

<details markdown="1">
<summary>Hint</summary>

Read across the table to make the ordered pairs.

<details markdown="1">
<summary>Next step</summary>

The pairs are $(2, 1)$, $(4, 2)$ and $(6, 3)$.

<details markdown="1">
<summary>Full working</summary>

Yes. Each input appears once and has one output. The relation is a function, even though
the outputs are all different.

</details>
</details>
</details>

**4.** A mapping diagram sends $1$ to $5$, $2$ to $5$ and $3$ to $7$. Is the relation a
function?

<details markdown="1">
<summary>Hint</summary>

Follow the arrows out of each input.

<details markdown="1">
<summary>Next step</summary>

Input $1$ has one arrow, input $2$ has one arrow, and input $3$ has one arrow.

<details markdown="1">
<summary>Full working</summary>

Yes. Every input has exactly one arrow, so the relation is a function. Two arrows point at
the output $5$, which is allowed. The input $2$ does not have two arrows.

</details>
</details>
</details>

**5.** The graph of $y = x^2$ is drawn on a grid. Use the vertical line test to decide
whether it is a function.

<details markdown="1">
<summary>Hint</summary>

Imagine a vertical line sliding across the grid.

<details markdown="1">
<summary>Next step</summary>

At every $x$ value, the line meets the curve once.

<details markdown="1">
<summary>Full working</summary>

The curve is a function. Every vertical line crosses it at most once. The lowest point is
touched once, and every other vertical line crosses once.

</details>
</details>
</details>

**6.** The circle $x^2 + y^2 = 25$ is drawn on a grid. Use the vertical line test to decide
whether it is a function.

<details markdown="1">
<summary>Hint</summary>

Try the vertical line $x = 0$.

<details markdown="1">
<summary>Next step</summary>

At $x = 0$ the circle meets the line at $y = 5$ and $y = -5$.

<details markdown="1">
<summary>Full working</summary>

The circle is not a function. The vertical line $x = 0$ crosses it twice, so the input $0$
has two outputs, $5$ and $-5$.

</details>
</details>
</details>

**7.** The coffee temperature is $T(t) = 20 + 70(0.5)^{t/5}$. Is $T$ a function of $t$?
Work out $T(10)$ as part of your answer.

<details markdown="1">
<summary>Hint</summary>

Each time gives one temperature. For $T(10)$, substitute $t = 10$.

<details markdown="1">
<summary>Next step</summary>

$T(10) = 20 + 70(0.5)^{10/5} = 20 + 70(0.5)^2$.

<details markdown="1">
<summary>Full working</summary>

Yes, $T$ is a function of $t$, because each time gives exactly one temperature.

$$T(10) = 20 + 70(0.5)^2 = 20 + 70(0.25) = 20 + 17.5 = 37.5$$

After $10$ minutes the coffee is $37.5^\circ C$.

</details>
</details>
</details>

## A question from Chapter 4

**8.** Solve $3x + 1 = 13$.

<details markdown="1">
<summary>Hint</summary>

Subtract $1$, then divide by $3$.

<details markdown="1">
<summary>Next step</summary>

$3x = 12$.

<details markdown="1">
<summary>Full working</summary>

$x = 4$.

This is the same calculation as asking "which input gives the output $13$ for the function
$f(x) = 3x + 1$?". That question is answered by an inverse function, which is the subject
of Section 6.3.

</details>
</details>
</details>
