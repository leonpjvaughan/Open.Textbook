# 6.1 Relations and functions — Learn

**Prerequisites:** plotting points on a coordinate grid; substituting a number into a
formula.

**Objectives:** write a relation as a set of ordered pairs; decide whether a relation is a
function; use the vertical line test on a graph.

By the end of this section you can look at a table, a list of pairs or a graph and say
whether it describes a function.

## Relations

A **relation** is any set of ordered pairs. Each pair joins an input to an output. The
first number is the input and the second is the output.

$$\{(1, 4),\ (2, 5),\ (3, 6)\}$$

The **domain** is the set of inputs, here $\{1, 2, 3\}$. The **range** is the set of
outputs, here $\{4, 5, 6\}$.

A relation can be given in four ways, and all four carry the same information:

- a list of ordered pairs, as above;
- a table, with one row for the inputs and one for the outputs;
- a graph, with the inputs along the $x$-axis and the outputs along the $y$-axis;
- a mapping diagram, with arrows from each input to its output.

## Functions

A **function** is a relation in which every input has exactly one output. That single
condition is the whole definition.

The relation $\{(1, 4), (2, 5), (3, 6)\}$ is a function: the inputs $1$, $2$ and $3$ each
appear once, and each has one output.

The relation $\{(1, 2), (1, 3), (2, 4)\}$ is not a function. The input $1$ appears twice,
with the outputs $2$ and $3$. One input cannot lead to two different outputs.

> **The function rule.** A relation is a function when no input has two outputs.

**Example 1.** Decide whether each relation is a function.

- $\{(2, 7), (3, 7), (4, 9)\}$ — yes. The output $7$ is used twice, but that is allowed.
  Two inputs may share an output; one input may not have two outputs.
- $\{(5, 1), (6, 2), (5, 8)\}$ — no. The input $5$ has the outputs $1$ and $8$.

**Example 2.** A table shows the input $1$ giving the output $4$, the input $2$ giving $4$,
and the input $3$ giving $6$. Is this a function?

Yes. Each input has exactly one output. The output $4$ appears twice, which is fine.

## The vertical line test

On a graph, a function has a simple test. Draw a vertical line anywhere on the diagram.
Count where it crosses the curve.

> **The vertical line test.** A graph is a function when every vertical line crosses it at
> most once.

A vertical line stands for one input, and the crossing points are its outputs. A line that
crosses twice has found one input with two outputs, so the graph is not a function.

**Example 3.** The curve $y = x^2$ is a function. A vertical line crosses it once, except
at the vertex where it touches. The circle $x^2 + y^2 = 25$ is not a function. A vertical
line through the middle crosses it twice, at $y = 5$ and $y = -5$, so the input $0$ has two
outputs.

> **Watch out.** Two inputs sharing an output does not break the function rule. A
> horizontal line through $y = 4$ may cross the parabola $y = x^2$ twice, at $x = 2$ and
> $x = -2$. That is allowed for a function, because each input still has one output. Only a
> repeated input breaks the rule, and the vertical line test is the one that finds it.

## The cooling coffee

The chapter problem is a function. The input is the time $t$ in minutes and the output is
the temperature $T$ in degrees Celsius:

$$T(t) = 20 + 70(0.5)^{t/5}$$

Each time gives exactly one temperature, so this is a function. The input $t = 0$ gives
$T = 90$, and the input $t = 5$ gives $T = 55$.

## Progress check

Back to the chapter problem. Read the rule $T(t) = 20 + 70(0.5)^{t/5}$ as a function.

Work out $T(0)$ and $T(5)$. Then answer this question: is the time a function of the
temperature? That is, does each temperature give exactly one time? Keep your answer.
Section 6.2 finds the domain and range, and Section 6.3 turns the rule around.

## You should now be able to

- write a relation as a set of ordered pairs, a table, a graph or a mapping diagram;
- decide whether a relation is a function by checking each input;
- use the vertical line test on a graph;
- explain why two inputs may share an output but one input may not.
