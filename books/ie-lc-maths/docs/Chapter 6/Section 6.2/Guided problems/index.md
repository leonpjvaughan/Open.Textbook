# 6.2 Domain, range and notation — Practise with help

## Warm-up: remember

1. Solve $x - 5 = 0$.
2. Work out the value of $x^2$ when $x = -4$.

<details markdown="1">
<summary>Answers and feedback</summary>

1. $x = 5$. This is the value that makes the bottom of a fraction zero, so it is the value
   a domain excludes.
2. $(-4)^2 = 16$. The square of a negative number is positive, which is why a square root
   needs a value that is not negative.

</details>

## Practise with help

**1.** For $f(x) = 4x - 1$, work out $f(3)$.

<details markdown="1">
<summary>Hint</summary>

Replace $x$ by $3$.

<details markdown="1">
<summary>Next step</summary>

$f(3) = 4(3) - 1$.

<details markdown="1">
<summary>Full working</summary>

$$f(3) = 4(3) - 1 = 12 - 1 = 11$$

The bracket holds the input, so $3$ takes the place of every $x$.

</details>
</details>
</details>

**2.** For $f(x) = x^2 - 2$, work out $f(-5)$.

<details markdown="1">
<summary>Hint</summary>

Square the input before subtracting.

<details markdown="1">
<summary>Next step</summary>

$(-5)^2 = 25$.

<details markdown="1">
<summary>Full working</summary>

$$f(-5) = (-5)^2 - 2 = 25 - 2 = 23$$

The square is worked out first, and $(-5)^2$ is positive.

</details>
</details>
</details>

**3.** State the domain of $f(x) = \dfrac{1}{x + 7}$.

<details markdown="1">
<summary>Hint</summary>

The fraction fails when the bottom is zero.

<details markdown="1">
<summary>Next step</summary>

Solve $x + 7 = 0$.

<details markdown="1">
<summary>Full working</summary>

$x + 7 = 0$ gives $x = -7$. The domain is every real number except $-7$. You may write it
as $x \ne -7$.

</details>
</details>
</details>

**4.** State the domain of $f(x) = \sqrt{x + 2}$.

<details markdown="1">
<summary>Hint</summary>

The value under the root must not be negative.

<details markdown="1">
<summary>Next step</summary>

$x + 2 \ge 0$.

<details markdown="1">
<summary>Full working</summary>

Subtract $2$: $x \ge -2$. The domain is $[-2, \infty)$. The value $-2$ is allowed, because
$\sqrt{0} = 0$.

</details>
</details>
</details>

**5.** For $f(x) = 5 - x$, state the range when the domain is $0 \le x \le 4$.

<details markdown="1">
<summary>Hint</summary>

Find the output at each end of the domain.

<details markdown="1">
<summary>Next step</summary>

$f(0) = 5$ and $f(4) = 1$.

<details markdown="1">
<summary>Full working</summary>

The rule decreases as $x$ increases, so the largest output is $5$ and the smallest is $1$.
The range is $1 \le y \le 5$.

</details>
</details>
</details>

**6.** For $f(x) = x^2$, work out $f(x + 1)$.

<details markdown="1">
<summary>Hint</summary>

The whole input is $x + 1$. Put it inside brackets before squaring.

<details markdown="1">
<summary>Next step</summary>

$f(x + 1) = (x + 1)^2$.

<details markdown="1">
<summary>Full working</summary>

$$f(x + 1) = (x + 1)^2 = x^2 + 2x + 1$$

A common error is to write $x^2 + 1$, which squares only the $x$. The bracket squares the
whole input.

</details>
</details>
</details>

**7.** The coffee temperature is $T(t) = 20 + 70(0.5)^{t/5}$ for $t \ge 0$. State the
range.

<details markdown="1">
<summary>Hint</summary>

What is the largest value of $T$? What value does $T$ approach as $t$ grows?

<details markdown="1">
<summary>Next step</summary>

At $t = 0$, $T = 90$. As $t$ grows, $(0.5)^{t/5}$ shrinks towards $0$.

<details markdown="1">
<summary>Full working</summary>

The largest value is $90$, at $t = 0$. As $t$ grows, $T$ falls towards $20$ but never
reaches it. The range is $20 < T \le 90$.

</details>
</details>
</details>

## A question from Chapter 4

**8.** Solve $2x - 7 = 3$.

<details markdown="1">
<summary>Hint</summary>

Add $7$ to both sides, then divide by $2$.

<details markdown="1">
<summary>Next step</summary>

$2x = 10$.

<details markdown="1">
<summary>Full working</summary>

$x = 5$.

This is the same as asking "which input gives the output $3$ for $f(x) = 2x - 7$?". The
answer is $f^{-1}(3) = 5$, and finding inverse functions is Section 6.3.

</details>
</details>
</details>
