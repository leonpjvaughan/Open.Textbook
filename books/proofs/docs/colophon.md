# About this book

## What this book is

This is a reference book of proofs. Every page shows why one fact is true, in
the shortest way a reader can follow rather than the shortest way there is.
Most of them have something you can move, so the reason is visible rather than
only readable.

This is not a course. There are no chapters and no questions to practise. You
can read a proof on its own, or follow a link to it from the page that stated
the fact.

## Who made it

This book is part of **Open.Textbook**, an independent project by Leon
Vaughan, who wrote and assembled it.

## Where the content comes from

Every claim about which course a proof belongs to rests on a published
specification, and each one is named below.

The claims in this book rest on these documents:

- [Mathematics: GCSE subject content (November 2013)](https://www.gov.uk/government/publications/gcse-mathematics-subject-content-and-assessment-objectives)
- [Mathematics: AS and A level content (April 2016)](https://www.gov.uk/government/publications/gce-as-and-a-level-mathematics)
- [AQA GCSE Mathematics 8300 specification](https://www.aqa.org.uk/subjects/mathematics/gcse/mathematics-8300)
- [AQA A-level Mathematics 7357 specification](https://www.aqa.org.uk/subjects/mathematics/as-and-a-level/mathematics-7357)

These sources were last checked on 2026-10-12.

No awarding body endorses this book, and no curriculum body supplies it.

## Reporting a mistake

If you find a mistake, report it as an issue on the project's GitHub page:
<https://github.com/leonpjvaughan/Open.Textbook/issues/new>.

That route needs a free GitHub account. The project has no email address,
because it does not run a mail service.

In your report, say which page you were reading, what you expected, and what
you saw. That is enough to find the mistake and fix it.
