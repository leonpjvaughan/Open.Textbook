# Glossary — Modelling a Changing World

**Carrying capacity** — the greatest population an environment can support in a
logistic model.

**Closed form** — a formula that gives any term directly, without using the one
before.

**Continuous model** — a model in which the quantity changes smoothly, described
by a differential equation.

**Decay rate** — the constant that measures how quickly a quantity decreases.

**Differential equation** — an equation that links a rate of change to the
quantities it describes.

**Discrete model** — a model in which the quantity changes in separate steps,
described by a difference equation.

**Doubling time** — the time a growing quantity takes to become twice its size.

**Equilibrium value** — a value at which the quantity stops changing.

**Euler's method** — a step-by-step method for solving a differential equation
approximately.

**Exponential growth** — growth at a rate proportional to the current value.

**First-order difference equation** — an equation that links each term to the one
before it.

**Fixed point** — a value that a recurrence leaves unchanged.

**General solution** — a solution that contains an arbitrary constant and covers
every case.

**Growth rate** — the constant that measures how quickly a quantity increases.

**Half-life** — the time a decaying quantity takes to fall to half its size.

**Initial condition** — the value of a quantity at the start, used to fix the
constant in a solution.

**Iterating** — applying a rule again and again, using each answer as the next
input.

**Logistic model** — a growth model in which the rate slows as the quantity
approaches the carrying capacity.

**Order** — the highest derivative or difference that appears in an equation.

**Particular solution** — the solution that satisfies a given initial condition.

**Point of inflexion** — a point where a curve changes from convex to concave, or
the reverse.

**Rate of change** — how quickly one quantity changes as another changes.

**Recurrence relation** — a rule that gives each term of a sequence from the one
before it.

**Separable** — able to be rearranged so that each variable sits on its own side
of a differential equation.

**Stable** — returning to the equilibrium value after a small change.

**Unstable** — moving away from the equilibrium value after a small change.
