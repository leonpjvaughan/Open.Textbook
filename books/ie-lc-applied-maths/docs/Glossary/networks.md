# Glossary — Modelling with Networks and Graphs

**Adjacency matrix** — a grid of $0$s and $1$s that records which vertices of a
network are joined.

**Arc** — another name for an edge, often used when the edge has a direction.

**Backward recursion** — solving a multi-stage problem by working from the final
stage back to the start.

**Bellman's principle of optimality** — the rule that every part of an optimal
route is itself optimal.

**Bridge** — an edge whose removal disconnects the network.

**Circuit** — a closed trail that returns to its starting vertex.

**Complete network** — a network in which every pair of vertices is joined by an
edge.

**Connected** — having a path between every pair of vertices.

**Cut property** — the rule that the cheapest edge across a cut belongs to some
minimum spanning tree.

**Cycle** — a closed path that returns to its starting vertex without repeating a
vertex.

**Degree** — the number of edges meeting a vertex.

**Dense** — having many of the possible edges present.

**Digraph** — a network whose edges have a direction.

**Dijkstra's algorithm** — a method that finds the shortest path from one vertex
to every other.

**Directed edge** — an edge with a direction, so you can travel along it one way
only.

**Disconnected** — having at least one pair of vertices with no path between
them.

**Edge** — a line joining two vertices of a network.

**End vertex** — a vertex of degree $1$.

**Eulerian circuit** — a closed trail that uses every edge exactly once.

**Eulerian trail** — a trail that uses every edge exactly once and starts and
ends at different vertices.

**Forest** — a network with no cycles.

**Graph** — a set of vertices joined by edges.

**Handshake lemma** — the result that the degrees of a network add to twice the
number of edges.

**In-degree** — the number of directed edges arriving at a vertex.

**Isolated** — having degree $0$.

**Kruskal's algorithm** — a method that builds a minimum spanning tree by adding
the cheapest edge that joins two trees.

**Leaf** — another name for an end vertex, of degree $1$.

**Link** — another name for an edge.

**Loop** — an edge that starts and ends at the same vertex.

**Minimum spanning tree** — a spanning tree with the smallest possible total
weight.

**Multi-stage** — arranged in stages, where each decision leads to the next
stage.

**Multiple edges** — two or more edges joining the same pair of vertices.

**Network** — a set of vertices joined by edges, with a meaning attached to each.

**Node** — another name for a vertex.

**Optimal** — best possible for the quantity you are measuring.

**Out-degree** — the number of directed edges leaving a vertex.

**Path** — a walk that does not repeat any vertex.

**Prim's algorithm** — a method that grows a minimum spanning tree from one
starting vertex.

**Shortest path** — the path between two vertices with the smallest total weight.

**Sparse** — having few of the possible edges present.

**Spanning tree** — a tree that includes every vertex of the network.

**State** — the position or condition you are in at a given stage of a
multi-stage problem.

**Trail** — a walk that does not repeat any edge.

**Tree** — a connected network with no cycles.

**Undirected** — having edges with no direction.

**Vertex** — a point of a network, where edges meet.

**Walk** — a sequence of edges that moves from vertex to vertex.

**Weight** — a number attached to an edge, such as a distance or a cost.

**Weighted network** — a network in which every edge has a weight.
