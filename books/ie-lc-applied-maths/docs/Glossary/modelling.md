# Glossary — Mathematical Modelling

**Assumption** — something you take as true to build a model, without proving it.

**Conclusion** — the answer you draw from a model, stated within its limits.

**Context** — the real situation a model describes.

**Decomposing** — breaking a large problem into smaller parts you can handle one
at a time.

**Evaluation** — judging how well a model answers the question and where it
fails.

**Extrapolation** — using a model outside the range of the data it was built
from.

**Formulating** — turning a real situation into a precise mathematical question.

**Input** — a quantity you put into a model to produce an output.

**Manageable** — small enough to solve with the time and tools you have.

**Measurable** — able to be given a number and a unit.

**Model** — a simplified mathematical description of a real situation.

**Overfitting** — fitting the data so closely that the model follows noise and
predicts new cases badly.

**Proportional** — changing by a fixed multiplier, so doubling one quantity
doubles the other.

**Refining** — improving a model after you test it against the situation.

**Residual** — the difference between a measured value and the value a model
predicts.

**Sensitivity** — how much a model's answer changes when an assumption or an
input changes.

**Solution** — the answer the model gives once you compute it.

**Total squared error** — the sum of the squares of the residuals, used to
compare models.

**Translating** — writing a situation in mathematical symbols.

**Variability** — how much repeated measurements or real values differ from one
another.
